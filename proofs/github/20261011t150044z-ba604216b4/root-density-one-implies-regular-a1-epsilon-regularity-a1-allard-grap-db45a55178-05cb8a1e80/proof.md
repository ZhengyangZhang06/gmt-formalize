0. Geometry of Φ. As ι, ι' are isometries with orthogonal ranges (and n + k = dim E, so E = ι(ℝⁿ) ⊕ ι'(ℝᵏ)), |Φ(v) − Φ(v')|² = |v − v'|² + |f(v) − f(v')|²; with Lip f ≤ 1/4 and f(0) = 0: |v − v'| ≤ |Φ(v) − Φ(v')| ≤ (17/16)^{1/2}|v − v'|, |Φ(v) − z| ≤ (17/16)^{1/2}|v| < 1.04|v|, Φ is injective, and Lⁿ(Z) ≤ Hⁿ(Φ(Z)) for Z ⊆ ℝⁿ (Φ^{−1} is 1-Lipschitz on F). By Rademacher's theorem f is differentiable Lⁿ-a.e., with ‖Df‖ ≤ 1/4 there; J(v) := (det(I + Df(v)ᵀDf(v)))^{1/2} ≥ 1 is the area Jacobian of Φ. Let Ω' := B̆ⁿ_{4a/5}(0); for v ∈ Ω', |Φ(v) − z| < 1.04·0.8a < a, so Φ(v) ∈ F ∩ B_a(z) = spt μ ∩ B_a(z) ⊆ W.
1. Hⁿ⌞(F ∩ B_a(z)) ≤ μ. F ∩ B_a(z) ⊆ spt μ ∩ W, and Hⁿ((spt μ ∩ W) ∖ M) = 0 by support_null; θ ≥ 1 on M. So for Borel Y, Hⁿ(Y ∩ F ∩ B_a(z)) ≤ Hⁿ(Y ∩ M) ≤ ∫_{Y∩M}θ dHⁿ = μ(Y). Consequently, if N ⊆ E is μ-null (or Hⁿ-null) then Lⁿ({v ∈ Ω' : Φ(v) ∈ N}) ≤ Hⁿ(N ∩ F ∩ B_a(z)) = 0.
2. Lower density. For ξ ∈ spt μ ∩ B_a(z) ⊆ W and s > 0 small enough that B_s(ξ) ⊆ W and κs ≤ ln 2 (κ ≥ 0), monotonicity (D) gives μ(B_s(ξ)) ≥ e^{−κs}ω_nsⁿ ≥ ½ω_nsⁿ.
3. Tangent planes along the graph (parent 8.5; Simon (10)). Let G be the set of v ∈ Ω' such that, with ξ_v := Φ(v): (i) f is differentiable at v; (ii) ξ_v ∈ M and T_{ξ_v}M = graph Df(v) (in Lean: approxTangentPlane n M ξ_v = LinearMap.range(ι + ι'∘Df(v))); (iii) ξ_v is a μ-Lebesgue point of x ↦ p_x: lim_{s↓0} μ(B_s(ξ_v))^{−1}∫_{B_s(ξ_v)}|p_x − p_{ξ_v}|²dμ = 0. Then Lⁿ(Ω' ∖ G) = 0: (i) fails on an Lⁿ-null set (Rademacher); (ii) fails, for v ∈ Ω' with (i), only if Φ(v) lies in the Hⁿ-null set (spt μ ∩ W) ∖ M (support_null) or in the Hⁿ-null exceptional set of graph_tangent (applied with the base point z in place of graph_tangent's parameter a, Lipschitz constant L := 1/4, the given ι, ι', f, and W), so by 1 on an Lⁿ-null set; (iii) fails only if Φ(v) lies in the μ-null set of non-Lebesgue points in B_a(z) of the bounded μ-measurable map x ↦ p_x (tangent_projection_measurable; fix a' > a with B_{a'}(z) ⊆ W, possible as B_a(z) is compact and W open, and apply Lebesgue's differentiation theorem for the finite Borel measure μ⌞B̆_{a'}(z) on E (Besicovitch; Mathlib ae_tendsto_average_norm_sub), whose small balls about points of B_a(z) coincide with those of μ), so by 1 on an Lⁿ-null set.
 For v ∈ G let S_v be the n-plane given by (D_K) at ξ_v ∈ spt μ ∩ B_a(z): ∫_{B_s(ξ_v)}|p_x − p_{S_v}|²dμ ≤ K⁺s^{n+1} for 0 < s ≤ s₀. Then p_{S_v} = p_{graph Df(v)}: for small s > 0 (s ≤ s₀ and as in 2), averaging the pointwise inequality |p_{ξ_v} − p_{S_v}|² ≤ 2|p_x − p_{ξ_v}|² + 2|p_x − p_{S_v}|² over B_s(ξ_v) with respect to μ gives |p_{ξ_v} − p_{S_v}|² ≤ 2μ(B_s(ξ_v))^{−1}∫_{B_s(ξ_v)}|p_x − p_{ξ_v}|²dμ + 2μ(B_s(ξ_v))^{−1}K⁺s^{n+1}, where the first term → 0 by (iii) and the second is ≤ 4K⁺s/ω_n → 0 by 2; so p_{S_v} = p_{ξ_v} = p_{graph Df(v)} by (ii).
4. Projections of graphs (parent 8.6). For linear A₁, A₂ : ℝⁿ → ℝᵏ with ‖A₁‖, ‖A₂‖ ≤ 1/4: |A₁ − A₂| ≤ 2|p_{A₁} − p_{A₂}|. Proof: for u ∈ ℝⁿ, p_A(ιu) = ιw + ι'Aw where w minimizes |u − w|² + |Aw|², i.e. w = (I + AᵀA)^{−1}u; so ι'*p_Aι = A(I + AᵀA)^{−1}. Then ι'*(p_{A₁} − p_{A₂})ι = (A₁ − A₂)Y₁ + A₂Y₁(A₂ᵀA₂ − A₁ᵀA₁)Y₂ with Y_i := (I + A_iᵀA_i)^{−1}, ‖Y_i‖ ≤ 1, ‖Y_i^{−1}‖ ≤ 1 + 1/16. Using |XY| ≤ ‖X‖|Y|, |XY| ≤ |X|‖Y‖ and |X| ≤ |XY|‖Y^{−1}‖: |(A₁ − A₂)Y₁| ≥ (16/17)|A₁ − A₂|, and |A₂Y₁(A₂ᵀ(A₂ − A₁) + (A₂ − A₁)ᵀA₁)Y₂| ≤ (1/4)(2·(1/4))|A₁ − A₂| = (1/8)|A₁ − A₂|. Hence |ι'*(p_{A₁} − p_{A₂})ι| ≥ (16/17 − 1/8)|A₁ − A₂| ≥ ½|A₁ − A₂|, and |ι'*(p_{A₁} − p_{A₂})ι| ≤ |p_{A₁} − p_{A₂}| (ι, ι' are isometries).
5. Campanato estimate (parent 8.7; Simon (11)). Put s₁ := min{s₀/2, a/8}. Let v ∈ G with |v| < a/2 and 0 < s ≤ s₁. For v' ∈ Bⁿ_s(v): |v'| < a/2 + a/8 < 4a/5 (so v' ∈ Ω'), and |Φ(v') − ξ_v| ≤ 1.04|v' − v| < 2s; also |ξ_v − z| < 1.04·a/2 < 0.53a, so B_{2s}(ξ_v) ⊆ B_a(z) (2s ≤ a/4). For a.e. v' ∈ Bⁿ_s(v) we have v' ∈ G, hence p_{Φ(v')} = p_{Df(v')} (3(ii)). By 4 (‖Df‖ ≤ 1/4), 3 (p_{S_v} = p_{Df(v)}), J ≥ 1, the area formula for the injective Lipschitz map Φ (Simon Ch. 2, 3.5; library injective_area_formula_lipschitz), Φ(Bⁿ_s(v)) ⊆ F ∩ B_{2s}(ξ_v), 1, and (D_K) at ξ_v with radius 2s ≤ s₀ (the integrand x ↦ |p_x − p_{S_v}|² is μ-a.e.-measurable by (P3), hence a.e.-measurable for Hⁿ⌞(F ∩ B_a(z)) ≤ μ; the library's weighted_area_formula_lipschitz_injOn accepts any nonnegative weight):
 ∫_{Bⁿ_s(v)}|Df(v') − Df(v)|²dv' ≤ 4∫_{Bⁿ_s(v)}|p_{Φ(v')} − p_{S_v}|²J(v')dv' = 4∫_{Φ(Bⁿ_s(v))}|p_x − p_{S_v}|²dHⁿ ≤ 4∫_{F∩B_{2s}(ξ_v)}|p_x − p_{S_v}|²dHⁿ ≤ 4∫_{B_{2s}(ξ_v)}|p_x − p_{S_v}|²dμ ≤ 4K⁺(2s)^{n+1}.
6. Hölder continuity of Df on G (parent 8.7). Let v₁, v₂ ∈ G with |v₁|, |v₂| < a/2 and 0 < s := |v₁ − v₂| ≤ s₁, and m := (v₁ + v₂)/2. Then Bⁿ_{s/2}(m) ⊆ Bⁿ_s(v₁) ∩ Bⁿ_s(v₂), and averaging |Df(v₁) − Df(v₂)|² ≤ 2|Df(v') − Df(v₁)|² + 2|Df(v') − Df(v₂)|² over v' ∈ Bⁿ_{s/2}(m) gives, by 5 applied at v₁ and at v₂ with radius s, |Df(v₁) − Df(v₂)|² ≤ (ω_n(s/2)ⁿ)^{−1}·2·2·4K⁺(2s)^{n+1} = C₁₉²K⁺s with C₁₉² := 2^{2n+5}/ω_n. So |Df(v₁) − Df(v₂)| ≤ C₁₉(K⁺|v₁ − v₂|)^{1/2} for v₁, v₂ ∈ G ∩ B̆ⁿ_{a/2} with |v₁ − v₂| ≤ s₁ (K⁺ ≥ 0, so the square root is defined).
7. C¹ regularity (parent 8.8). Let Ω := B̆ⁿ_{a/2}(0). G ∩ Ω has full measure in Ω, hence is dense in Ω, and by 6 the restriction of Df to G ∩ Ω is uniformly continuous; let g : Ω → Hom(ℝⁿ, ℝᵏ) be its unique continuous extension (uniformly continuous, with g = Df on G ∩ Ω). As f is Lipschitz, its distributional derivative is the a.e. derivative Df, so Df = g Lⁿ-a.e. on Ω. For a standard mollifier ϱ_t and Ω_t := {v ∈ Ω : dist(v, ℝⁿ ∖ Ω) > t}, the smooth maps f_t := f ∗ ϱ_t satisfy Df_t = (Df) ∗ ϱ_t = g ∗ ϱ_t on Ω_t (for Lipschitz f, D(f ∗ ϱ_t)h = lim_{τ→0}((f(· + τh) − f)/τ) ∗ ϱ_t = (Df h) ∗ ϱ_t by dominated convergence: the difference quotients are bounded by Lip f·|h| and converge a.e. to Df·h by Rademacher's theorem); g ∗ ϱ_t → g locally uniformly on Ω (g uniformly continuous), and f_t → f uniformly (f continuous, Lipschitz). If f_t → f pointwise and Df_t → g locally uniformly on an open set with g continuous, then f is C¹ there with Df = g (fundamental theorem of calculus on segments: f_t(v + h) − f_t(v) = ∫₀¹Df_t(v + τh)h dτ → ∫₀¹g(v + τh)h dτ for [v, v + h] ⊆ Ω, whence f(v + h) − f(v) − g(v)h = o(|h|)). Therefore f is C¹ on Ω = ball (0 : Euclid n) (a/2), i.e. ContDiffOn ℝ 1 f (ball 0 (a/2)). ∎

4. For a.e. v: T_{Φ(v)}M = graph Df(v) (graph_tangent), and the Lebesgue point property forces S_v = graph Df(v).
5. |A₁ − A₂| ≤ 2|p_{A₁} − p_{A₂}| for ‖A_i‖ ≤ 1/4.
6. Campanato estimate ∫_{Bⁿ_s(v)}|Df − Df(v)|² ≤ 4K⁺(2s)^{n+1}, via the area formula.
7. Hölder bound |Df(v₁) − Df(v₂)| ≤ C₁₉(K⁺|v₁ − v₂|)^{1/2} on a full-measure set, and its continuous extension g.
8. Mollification: Df_t = g ∗ ϱ_t → g locally uniformly, so f is C¹ on B̆ⁿ_{a/2}.
