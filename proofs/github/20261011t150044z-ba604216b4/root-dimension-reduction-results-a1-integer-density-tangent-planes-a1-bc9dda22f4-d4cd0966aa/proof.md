## Proof

Source: parent proof steps 1–2 (the chord [[b, a]] of the pairing argument), Simon 7.3.3, proof of (2), formula (10) (chapter-07.txt lines 563–566: "it is easy to check that such a 1-dimensional minimizing cone necessarily has the form m[[ℓ]]").
1. (Choice of ℓ and u.) Put ℓ := |a − b| and u := ℓ⁻¹(a − b). Since a ≠ b we have a − b ≠ 0, hence ℓ > 0 (norm_pos_iff), and |a − b| = ℓ holds by definition.
2. (Unit direction, endpoint.) |u| = |ℓ⁻¹|·|a − b| = ℓ⁻¹ℓ = 1 (norm_smul, ℓ > 0), and b + ℓu = b + (ℓℓ⁻¹)(a − b) = b + (a − b) = a.
3. (The chord lies in the closed unit ball.) Let s ∈ [0, ℓ] and put λ := s/ℓ; then 0 ≤ λ ≤ 1 because 0 ≤ s ≤ ℓ and ℓ > 0. By the definition of u, b + su = b + λ(a − b) = (1 − λ)b + λa. By the triangle inequality and homogeneity of the norm, |b + su| ≤ |1 − λ|·|b| + |λ|·|a| = (1 − λ) + λ = 1, using 1 − λ ≥ 0, λ ≥ 0 and |a| = |b| = 1.
4. (a and b are not on a common line through 0.) Suppose a, b ∈ span{e} for some e ∈ ℝ^P, say a = αe and b = βe with α, β ∈ ℝ (Submodule.mem_span_singleton). Then |α|·|e| = |a| = 1 and |β|·|e| = |b| = 1. In particular |e| ≠ 0 (otherwise 0 = 1), so cancelling |e| gives |α| = |β|, i.e. α = β or α = −β. If α = β then a = b; if α = −β then b = βe = −αe = −a. Both contradict the hypotheses a ≠ b and b ≠ −a.
5. (At most one meeting parameter.) Let e ∈ ℝ^P and s₁, s₂, t₁, t₂ ∈ ℝ with b + s₁u = t₁e and b + s₂u = t₂e, and suppose s₁ ≠ s₂. Subtracting the two equations, (s₁ − s₂)u = (t₁ − t₂)e ∈ span{e}; since s₁ − s₂ ≠ 0, u ∈ span{e} (Submodule.smul_mem_iff). Then b = t₁e − s₁u ∈ span{e} and, by step 2, a = b + ℓu ∈ span{e}. This contradicts step 4. Hence s₁ = s₂.
6. (Conclusion.) ℓ and u of step 1 satisfy ℓ > 0 and |a − b| = ℓ (step 1), |u| = 1 and b + ℓu = a (step 2), |b + su| ≤ 1 for all s ∈ [0, ℓ] (step 3) and the uniqueness property of step 5. ∎

## Key steps

1. ℓ := |a − b| > 0 and u := ℓ⁻¹(a − b) give |u| = 1 and b + ℓu = a.
2. For s ∈ [0, ℓ], b + su = (1 − s/ℓ)b + (s/ℓ)a is a convex combination of unit vectors, so |b + su| ≤ 1.
3. Unit vectors a, b on a common line ℝe would satisfy a = ±b, which is excluded.
4. Two meeting points with s₁ ≠ s₂ would put u, then b and a = b + ℓu, into span{e}; hence s₁ = s₂.
