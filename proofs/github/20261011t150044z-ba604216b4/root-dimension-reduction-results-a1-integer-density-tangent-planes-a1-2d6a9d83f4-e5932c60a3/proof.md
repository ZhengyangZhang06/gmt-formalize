## Proof

Source: parent step 7 (the weighted area formula on the carrier, Simon Ch. 3, 2.4–2.5, through the sibling result carrier_area_formula) and the Jacobian computation of steps 5 and 7. Conventions: H² := μHE[2]; μ = θ·H²⌞M with θ ≥ 1 on M, so H²(M ∩ S) ≤ μ(S) for Borel S and every μ-null set meets M in an H²-null set; Ω := {⟨x,a⟩ > 0}; x̂ := x/|x|. (F1) (a, e) is an orthonormal basis of Q, πx = ⟨x,a⟩a + ⟨x,e⟩e, |πx|² = ⟨x,a⟩² + ⟨x,e⟩². (F2) ⟨Ax, x⟩ = 0, |Ax| = |πx|, πx ≠ 0 on Ω. (F3) On Ω, f is C^∞ with ∇f(x) = Ax/|πx|² (derivative of arctan(⟨x,e⟩/⟨x,a⟩)); |·| is C^∞ on ℝ^P ∖ {0} with gradient x̂.
1. (The map.) Let κ : Euclid 2 → ℝ × ℝ be the composition of ofLp : Euclid 2 → (Fin 2 → ℝ) with MeasurableEquiv.finTwoArrow; κ is a linear measurable bijection preserving Lebesgue measure (`PiLp.volume_preserving_ofLp` / `EuclideanSpace.volume_preserving_symm_measurableEquiv_toLp`, `MeasureTheory.volume_preserving_finTwoArrow`). Put Φ := κ⁻¹ ∘ F̃ : ℝ^P → Euclid 2. Z_s is open (it is Ω intersected with strict inequalities between functions continuous on the open set Ω; it is empty if s ≤ 0) and Z_s ⊆ Ω ⊆ ℝ^P ∖ {0}, so Φ is C^∞, in particular C¹, on Z_s, with DΦ(x)v = κ⁻¹(⟨x̂, v⟩, ⟨∇f(x), v⟩). For y ∈ Euclid 2, Φ⁻¹{y} = F̃⁻¹{κ y}.
2. (Hypotheses of the carrier area formula.) M is Borel and countably 2-rectifiable (fields of R); for compact K, H²(M ∩ K) ≤ ∫_{M∩K} θ dH² < ∞ (θ ≥ 1 on M; field locallyIntegrable_mult with K ⊆ univ); Z_s is open; Φ is C¹ on Z_s; n = 2 ≥ 1.
3. (Exceptional set.) Let E_0 := {x ∈ M : finrank T_x ≠ 2 or x ∉ T_x}. By the field `orients`, for H²⌞M-a.e. x there is Q' with HasApproximateTangentSpaceAt 2 M x Q'; then T_x = Q' (approxTangentPlane chooses an approximate tangent space, unique by SimonGMT `HasApproximateTangentSpaceAt.unique`) and finrank T_x = 2 (`HasApproximateTangentSpaceAt.finrank_eq`). By hypothesis p_{T_x}x = x, i.e. x ∈ T_x, for μ-a.e. x, hence for H²⌞M-a.e. x. So (H²⌞M)(E_0) = 0.
4. (Jacobian.) The sibling formula uses J*(x) := (det Γ(x))^{1/2}, Γ(x)_{ij} := ⟨DΦ(x)u_i, DΦ(x)u_j⟩, (u_i) := stdOrthonormalBasis of T_x indexed by Fin(finrank T_x) (off E_0, finrank T_x = 2, so this index type is Fin 2 after reindexing along finrank T_x = 2; the determinant is unchanged by the reindexing). Let x ∈ (M ∩ Z_s) ∖ E_0. Then T_x is 2-dimensional, x ≠ 0 and x̂ ∈ T_x; choose a unit τ ∈ T_x with τ ⊥ x̂, so (x̂, τ) is an orthonormal basis of T_x. Since ⟨x̂, Ax⟩ = 0, p_{T_x}(Ax) = ⟨x̂, Ax⟩x̂ + ⟨τ, Ax⟩τ = ⟨τ, Ax⟩τ and w(x) = |⟨τ, Ax⟩|. Since ⟨κ⁻¹p, κ⁻¹p'⟩ = p_1p'_1 + p_2p'_2 for p, p' ∈ ℝ × ℝ (κ⁻¹ sends (p_1, p_2) to the vector of Euclid 2 with these coordinates), Γ_{ij} = ⟨x̂,u_i⟩⟨x̂,u_j⟩ + ⟨∇f(x),u_i⟩⟨∇f(x),u_j⟩ = (LᵀL)_{ij}, where L is the 2×2 matrix with rows (⟨x̂,u_j⟩)_j and (⟨∇f(x),u_j⟩)_j; det Γ = (det L)². Writing u_j = O_{0j}x̂ + O_{1j}τ with O orthogonal, L = L₀O where L₀ has rows (⟨x̂,x̂⟩, ⟨x̂,τ⟩) = (1, 0) and (⟨∇f(x),x̂⟩, ⟨∇f(x),τ⟩) = (0, ⟨∇f(x),τ⟩) (⟨∇f(x), x̂⟩ = ⟨Ax, x̂⟩/|πx|² = 0). So det L = ±⟨∇f(x), τ⟩ and J*(x) = |⟨∇f(x), τ⟩| = |⟨Ax, τ⟩|/|πx|² = w(x)/|πx|² = J(x). By step 3, J* = J for H²-a.e. x ∈ M ∩ Z_s.
5. (μ as a weighted measure.) For every φ : ℝ^P → [0, ∞], ∫_{Z_s} φ dμ = ∫_{M ∩ Z_s} θ·φ dH² (μ = (H²⌞M).withDensity θ with θ measurable and finite; restrict to Z_s and use `lintegral_withDensity_eq_lintegral_mul_non_measurable`).
6. (Measurability.) x ↦ p_{T_x} is a.e.-strongly measurable for H²⌞M (`Submission.imrep_approxTangent_starProjection_aesm`), so x ↦ w(x) = |p_{T_x}(Ax)| is a.e.-measurable for H²⌞M; θ is measurable; F̃ is measurable (|·| is continuous and x ↦ arctan(⟨x,e⟩/⟨x,a⟩) is a composition of continuous maps with the measurable real division), so b∘F̃ is measurable for measurable b.
7. (Transport of the area formula.) Let h : ℝ^P → [0, ∞] be a.e.-measurable for H²⌞M. `Submission.idtp_carrier_area_formula` (n := 2, M, Z := Z_s, F := Φ, h) gives that y ↦ Σ_{x ∈ M ∩ Z_s ∩ Φ⁻¹{y}} h(x) is a.e.-measurable on Euclid 2 and ∫_{Euclid 2} Σ_{x ∈ M∩Z_s∩Φ⁻¹{y}} h(x) dy = ∫_{M∩Z_s} J*(x)·h(x) dH²(x). Since Φ⁻¹{κ⁻¹p} = F̃⁻¹{p} and κ⁻¹ : ℝ × ℝ → Euclid 2 is a measure-preserving measurable bijection, the function p ↦ Σ_{x ∈ M∩Z_s∩F̃⁻¹{p}} h(x) is a.e.-measurable on ℝ × ℝ and its integral equals the left side. By step 4, the right side equals ∫_{M∩Z_s} J(x)h(x) dH²(x).
8. (H.) Let b be measurable and h := θ·(b∘F̃)·ofReal(w), a.e.-measurable for H²⌞M by step 6. For x ∈ M ∩ Z_s ∩ F̃⁻¹{p}, F̃(x) = p, so the fibre sum of h over p is Σ θ(x)·b(p)·w(x) = b(p)·H(p) (ENNReal.tsum_mul_left). The right side of step 7 is ∫_{M∩Z_s} θ·(b∘F̃)·J·w dH² = ∫_{Z_s} b(F̃(x))·J(x)w(x) dμ (step 5) = ∫_{Z_s} b(F̃(x))·G(x) dμ, because J·w = w²/|πx|² = G and ofReal(J)·ofReal(w) = ofReal(Jw) (J, w ≥ 0). With b ≡ 1, step 7 shows that H is a.e.-measurable.
9. (N.) With h := θ·(b∘F̃) the fibre sum is b(p)·N(p) and the right side is ∫_{Z_s} b(F̃(x))·J(x) dμ. With b ≡ 1, N is a.e.-measurable. ∎

## Key steps

1. Φ := κ⁻¹∘(|x|, f) : ℝ^P → Euclid 2 is C¹ on the open set Z_s ⊆ Ω, and κ : Euclid 2 → ℝ×ℝ is a measure-preserving linear bijection.
2. H²-a.e. on M, T_x is 2-dimensional and contains x (orients and radial tangency).
3. At such x, in the orthonormal basis (x̂, τ) of T_x the Jacobian of Φ along T_x is |⟨∇f, τ⟩| = |p_{T_x}Ax|/|πx|² = J(x).
4. Apply idtp_carrier_area_formula with h = θ·(b∘F̃)·w resp. h = θ·(b∘F̃); fibre sums factor as b(p)H(p), b(p)N(p), and μ = θ·H²⌞M turns the right sides into ∫_{Z_s} b(F̃)G dμ, ∫_{Z_s} b(F̃)J dμ.
