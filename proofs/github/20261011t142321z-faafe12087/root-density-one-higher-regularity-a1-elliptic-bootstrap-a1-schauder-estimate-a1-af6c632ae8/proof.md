## Proof

Source: this is the Schauder step that the parent proof cites from Giaquinta-Martinazzi [GM] Theorems 5.17/5.19 (Hoelder coefficients satisfying (3.17), data in C^{0,sigma}, sigma = alpha). For C^{1,alpha} solutions it is proved here by L. Simon's blow-up method (L. Simon, Schauder estimates by scaling, Calc. Var. PDE 5 (1997) 391-407; the scalar divergence-form case is written out in S. Vita, Notes on Schauder estimates by scaling for elliptic PDEs in divergence form, arXiv:2510.01765, La Matematica 5 (2026)). Below, the Caccioppoli inequality (step 3) and the Liouville theorem (step 4) are proved directly for systems; the Legendre condition is what lets the scalar arguments go through unchanged. The method needs no Sobolev spaces: Caccioppoli, a Liouville theorem, Arzela-Ascoli and an absorption argument.
Notation. L = L(R^n, R^l), operator norm ||.||. For v in R^l, p in R^n, v (x) p in L is h -> <p, h> v, with ||v (x) p|| = |v| |p|. B_r(y) is the open ball. For a set A and a map F on A, [F]_{alpha;A} := sup{ ||F(x) - F(y)|| / |x - y|^alpha : x != y in A } in [0, infinity]; for Phi with values in linear forms, [Phi]_{alpha;A} := sup{ |Phi(x)[P] - Phi(y)[P]| / |x - y|^alpha : x != y in A, ||P|| <= 1 }. 'w is a weak solution of (a, Phi) on an open Omega' means: integral of a[Dw][Dzeta] = integral of Phi[Dzeta] for all zeta in C^1_c(R^n; R^l) with tsupport in Omega. Integrals of integrands supported in a compact subset of Omega may be taken over R^n.
0. Trivial case. If M < 0, (H5) fails at x0, so any C works. Assume M >= 0.
1. Two elementary facts. (1a) For zeta in C^1_c(R^n; R^l) and a fixed linear form c on L, the integral of c[Dzeta] over R^n is 0: c[Dzeta] = sum_{i,b} c[e_i (x) e_b] d_b zeta^i, and each d_b zeta^i integrates to 0 by Fubini and the fundamental theorem of calculus on lines parallel to e_b (compact support). (1b) Interpolation: if w is C^1 on B_rho(x), e is a unit vector and 0 < t < rho, then w(x + te) - w(x) = t Dw(x)e + integral_0^t (Dw(x + se) - Dw(x)) e ds, hence |Dw(x)e| <= 2 sup_{B_rho(x)} |w| / t + t^alpha [Dw]_{alpha;B_rho(x)}, and taking the sup over e, ||Dw(x)|| <= 2 sup_{B_rho(x)} |w| / t + t^alpha [Dw]_{alpha;B_rho(x)}.
2. Scaling. Let (a, Phi, w) satisfy (H6)-(H8) on an open ball B_R'(x0') and let B_rho(y) be contained in B_R'(x0'). For z in B_1(0) put wt(z) := w(y + rho z), at(z) := a(y + rho z), Phit(z) := rho Phi(y + rho z). Then wt is C^1 on B_1, Dwt(z) = rho Dw(y + rho z), [Dwt]_{alpha;B_s(z0)} = rho^{1+alpha} [Dw]_{alpha;B_{rho s}(y + rho z0)}, at satisfies (H1) with lam and (H2) with M, the Hoelder constant of at is rho^alpha times that of a, [Phit]_{alpha;B_1} = rho^{1+alpha} [Phi]_{alpha;B_rho(y)}, and wt is a weak solution of (at, Phit) on B_1: given zetat in C^1_c with tsupport in B_1, put zeta(x) := zetat((x - y)/rho), so tsupport zeta lies in B_rho(y), Dzeta(x) = rho^{-1} Dzetat((x - y)/rho), and the change of variables x = y + rho z (dx = rho^n dz) turns (H8) into rho^{n-2} integral at[Dwt][Dzetat] dz = rho^{n-2} integral Phit[Dzetat] dz.
3. Caccioppoli inequality for constant coefficients. Let A be a constant bilinear form on L with A[P][P] >= lam ||P||^2 and |A[P][Q]| <= Lam ||P|| ||Q||, and let V be C^1 on B_{2rho}(y) and a weak solution of (A, 0) there. Then for every c in R^l: integral over B_rho(y) of ||DV||^2 <= C3 rho^{-2} integral over B_{2rho}(y) of |V - c|^2, with C3 := 64 c_psi^2 Lam^2 / lam^2 (the right side may be infinite). Proof: fix once and for all psi in C^infinity(R) with 0 <= psi <= 1, psi = 1 on (-infinity, 1], psi = 0 on [3, infinity) (e.g. built from Real.smoothTransition), c_psi := sup |psi'|. Put eta(x) := psi(|x - y|^2 / rho^2): eta is C^infinity, eta = 1 on B_rho(y), tsupport eta lies in closedBall(y, sqrt(3) rho), contained in B_{2rho}(y), and |Deta| <= 2 sqrt(3) c_psi / rho <= 4 c_psi / rho. Test with zeta := eta^2 (V - c), which is C^1 with compact support in B_{2rho}(y): Dzeta = eta^2 DV + 2 eta (V - c) (x) Deta. Then 0 = integral A[DV][Dzeta] = integral eta^2 A[DV][DV] + 2 integral eta A[DV][(V - c) (x) Deta], so lam integral eta^2 ||DV||^2 <= 2 Lam integral eta ||DV|| |V - c| |Deta| <= (lam/2) integral eta^2 ||DV||^2 + (2 Lam^2 / lam) integral |V - c|^2 |Deta|^2 (Young). All integrals are finite (continuous integrands with compact support). Absorbing gives integral over B_rho(y) of ||DV||^2 <= integral eta^2 ||DV||^2 <= (4 Lam^2 / lam^2)(16 c_psi^2 / rho^2) integral over B_{2rho}(y) of |V - c|^2.
4. Liouville theorem. Let A be as in step 3 and let W be C^1 on R^n with [DW]_{alpha;R^n} <= Lam' < infinity (0 < alpha < 1) and W a weak solution of (A, 0) on R^n. Then DW is constant.
   4a. Mollification. Take phi in C^infinity_c(B_1(0)), phi >= 0, integral phi = 1 (normalized ContDiffBump), phi_eps(x) := eps^{-n} phi(x/eps), W_eps(x) := integral phi_eps(z) W(x - z) dz. W_eps is C^infinity (HasCompactSupport.contDiff_convolution_left; W is continuous, hence locally integrable), DW_eps(x) = integral phi_eps(z) DW(x - z) dz (differentiation under the integral, DW continuous), so [DW_eps]_{alpha;R^n} <= Lam' and DW_eps(x) -> DW(x) as eps -> 0 for each x. W_eps is a weak solution: for zeta in C^1_c, by Fubini (continuous integrand with compact support in (x, z)) and the substitution x = x' + z, integral A[DW_eps(x)][Dzeta(x)] dx = integral phi_eps(z) (integral A[DW(x')][D(zeta(. + z))(x')] dx') dz = 0, since zeta(. + z) is an admissible test function.
   4b. Derivatives of smooth solutions are solutions. If V is C^infinity and a weak solution of (A, 0) on R^n, so is d_s V := DV(.) e_s: V_h := (V(. + h e_s) - V)/h is a weak solution (translate the test function: integral A[DV(x + h e_s)][Dzeta(x)] dx = integral A[DV(x)][Dzeta(x - h e_s)] dx = 0, and linearity), and DV_h -> D(d_s V) uniformly on tsupport zeta as h -> 0 (V is C^2; the limit of DV_h(x) is D^2V(x)[e_s][.], which equals D(d_s V)(x) = D^2V(x)[.][e_s] by symmetry of the second derivative of a C^2 map, ContDiffAt.isSymmSndFDerivAt), so integral A[D(d_s V)][Dzeta] = lim integral A[DV_h][Dzeta] = 0. By induction every iterated partial derivative d_{s_1} ... d_{s_k} W_eps is a weak solution.
   4c. Iterated Caccioppoli. For k >= 1 let Q_k(rho) := sum over (s_1..s_k) in {1..n}^k of integral over B_rho(0) of ||D(d_{s_1} ... d_{s_k} W_eps)||^2. Claim: Q_k(rho) <= (n C3)^k rho^{-2k} integral over B_{2^k rho}(0) of ||DW_eps - P||^2 for every constant P in L and rho > 0. For k = 1: for each s, step 3 with V = d_s W_eps and c = P e_s gives integral over B_rho of ||D d_s W_eps||^2 <= C3 rho^{-2} integral over B_{2rho} of |d_s W_eps - P e_s|^2 <= C3 rho^{-2} integral over B_{2rho} of ||DW_eps - P||^2; sum over s. For k -> k+1: for each (s_0, s_1..s_k), step 3 with V = d_{s_0} d_{s_1} ... d_{s_k} W_eps and c = 0 gives integral over B_rho of ||DV||^2 <= C3 rho^{-2} integral over B_{2rho} of |V|^2 <= C3 rho^{-2} integral over B_{2rho} of ||D(d_{s_1} ... d_{s_k} W_eps)||^2; summing over s_0 (factor n) and over (s_1..s_k): Q_{k+1}(rho) <= n C3 rho^{-2} Q_k(2rho) <= (n C3)^{k+1} rho^{-2(k+1)} integral over B_{2^{k+1} rho} of ||DW_eps - P||^2.
   4d. Vanishing of high derivatives. Take P := DW_eps(0) and k := n + 1. On B_{2^k rho}(0), ||DW_eps(x) - P|| <= Lam' |x|^alpha <= Lam' (2^k rho)^alpha, so Q_{n+1}(rho) <= c' rho^{n + 2 alpha - 2n - 2} = c' rho^{2 alpha - n - 2}, which tends to 0 as rho -> infinity. Q_{n+1} is nondecreasing in rho, hence identically 0, and every partial derivative of W_eps of order n + 2 vanishes identically (continuous, with zero L^2 norm on every ball).
   4e. Polynomial argument. Fix x in R^n and let p(t) := DW_eps(tx) - DW_eps(0), t in R, a C^infinity map into L. Its (n+1)-th derivative is D^{n+1}(DW_eps)(tx)[x,...,x] = 0 (all partials of order n + 2 vanish, i.e. the (n+2)-multilinear map D^{n+2}W_eps(y) vanishes on all tuples of basis vectors, hence is 0 by multilinearity), so p is a polynomial in t of degree <= n with p(0) = 0 (Taylor's formula with zero remainder, coordinatewise): p(t) = sum_{i=1}^{n} c_i t^i. Also ||p(t)|| <= Lam' |x|^alpha |t|^alpha. If some c_i != 0, let i0 be the largest such index; then ||p(t)|| / |t|^{i0} -> ||c_{i0}|| > 0 as t -> infinity, while ||p(t)|| / |t|^{i0} <= Lam' |x|^alpha |t|^{alpha - i0} -> 0 because i0 >= 1 > alpha; contradiction. So p = 0 and DW_eps(x) = DW_eps(0) for all x.
   4f. For all x, x': DW(x) - DW(x') = lim_{eps -> 0} (DW_eps(x) - DW_eps(x')) = 0. So DW is constant.
5. Key local estimate (blow-up). Claim: for every delta > 0 there is C_delta = C_delta(n, l, alpha, lam, M, delta) in N (in particular C_delta >= 0) such that, whenever at, Phit, wt on B_1 := B_1(0) satisfy (i) at[P][P] >= lam ||P||^2, |at[P][Q]| <= M ||P|| ||Q|| and |at(z)[P][Q] - at(z')[P][Q]| <= M |z - z'|^alpha ||P|| ||Q|| on B_1, (ii) wt is C^1 on B_1 with [Dwt]_{alpha;B_1} < infinity, (iii) wt is a weak solution of (at, Phit) on B_1, then [Dwt]_{alpha;B_{1/2}} <= delta [Dwt]_{alpha;B_1} + C_delta (sup_{B_1} |wt| + [Phit]_{alpha;B_1}).
   Proof by contradiction. If the claim fails for some delta > 0, then no k in N works as C_delta, i.e. for every k in N there are (a_k, Phi_k, w_k) satisfying (i)-(iii) with [Dw_k]_{alpha;B_{1/2}} > delta [Dw_k]_{alpha;B_1} + k (sup_{B_1}|w_k| + [Phi_k]_{alpha;B_1}). Then s_k := [Dw_k]_{alpha;B_{1/2}} lies in (0, infinity) (it is <= [Dw_k]_{alpha;B_1} < infinity). Replacing (w_k, Phi_k) by (w_k / s_k, Phi_k / s_k) (the equation is linear in (w, Phi); (i)-(iii) persist) we may assume [Dw_k]_{alpha;B_{1/2}} = 1, [Dw_k]_{alpha;B_1} < 1/delta, sup_{B_1}|w_k| < 1/k, [Phi_k]_{alpha;B_1} < 1/k.
   5a. Choose x_k != y_k in B_{1/2} with ||Dw_k(x_k) - Dw_k(y_k)|| >= (1/2)|x_k - y_k|^alpha and put rho_k := |x_k - y_k| in (0, 1).
   5b. For x in B_{1/2}, B_{1/2}(x) is contained in B_1, so (1b) with t in (0, 1/2) gives ||Dw_k(x)|| <= 2/(k t) + t^alpha / delta. With t = k^{-1/2} (k >= 5): eps_k := sup_{B_{1/2}} ||Dw_k|| <= 2 k^{-1/2} + k^{-alpha/2} / delta -> 0.
   5c. rho_k -> 0: otherwise for some sigma > 0 and infinitely many k, (1/2) sigma^alpha <= (1/2) rho_k^alpha <= ||Dw_k(x_k) - Dw_k(y_k)|| <= 2 eps_k -> 0, a contradiction. Discard finitely many k so that rho_k < 1/2.
   5d. Blow-up. For z in D_k := B_{1/(2 rho_k)}(0) (then x_k + rho_k z lies in B_{1/2}(x_k), contained in B_1) put W_k(z) := rho_k^{-1-alpha} [w_k(x_k + rho_k z) - w_k(x_k) - rho_k Dw_k(x_k) z]. Then W_k is C^1 on D_k, W_k(0) = 0, DW_k(z) = rho_k^{-alpha} [Dw_k(x_k + rho_k z) - Dw_k(x_k)], DW_k(0) = 0, [DW_k]_{alpha;D_k} <= [Dw_k]_{alpha;B_1} < 1/delta, hence ||DW_k(z)|| <= |z|^alpha / delta and |W_k(z)| <= |z|^{1+alpha} / delta on D_k (integrate along [0, z]). With e_k := (y_k - x_k)/rho_k (|e_k| = 1, e_k in D_k): ||DW_k(e_k)|| = rho_k^{-alpha} ||Dw_k(y_k) - Dw_k(x_k)|| >= 1/2.
   5e. Rescaled equation. Let A_k := a_k(x_k), P_k := Dw_k(x_k) (||P_k|| <= eps_k), ah_k(z) := a_k(x_k + rho_k z) and Psi_k(z) := rho_k^{-alpha} [Phi_k(x_k + rho_k z) - Phi_k(x_k)] - rho_k^{-alpha} [a_k(x_k + rho_k z) - a_k(x_k)][P_k] (a linear form on L). For zeta in C^1_c(R^n; R^l) with tsupport in D_k, test (iii) for w_k with zeta_k(x) := zeta((x - x_k)/rho_k) (tsupport in B_{1/2}(x_k), contained in B_1), change variables x = x_k + rho_k z, use Dw_k(x) = P_k + rho_k^alpha DW_k(z) and Dzeta_k(x) = rho_k^{-1} Dzeta(z), and subtract the vanishing integrals of A_k[P_k][Dzeta] and Phi_k(x_k)[Dzeta] (step 1a); after division by rho_k^{n-1+alpha}: integral ah_k(z)[DW_k(z)][Dzeta(z)] dz = integral Psi_k(z)[Dzeta(z)] dz. Bounds: |Psi_k(z)[P]| <= ([Phi_k]_{alpha;B_1} + M ||P_k||) |z|^alpha ||P|| <= (1/k + M eps_k) |z|^alpha ||P||, and |ah_k(z)[P][Q] - A_k[P][Q]| <= M rho_k^alpha |z|^alpha ||P|| ||Q||.
   5f. Compactness. The bilinear forms A_k satisfy |A_k[P][Q]| <= M ||P|| ||Q||; in the finite-dimensional space of bilinear forms on L (e.g. via their components on a basis of L) a subsequence converges to some A, which satisfies A[P][P] >= lam ||P||^2 and |A[P][Q]| <= M ||P|| ||Q||. Pass to a further subsequence with e_k -> e, |e| = 1. For each integer L0 >= 2 and k large (closedBall(0, L0) contained in D_k), the restrictions of W_k and DW_k to closedBall(0, L0) are uniformly bounded (by L0^{1+alpha}/delta and L0^alpha/delta) and equicontinuous (W_k is (L0^alpha/delta)-Lipschitz on the convex ball, DW_k is (1/delta, alpha)-Hoelder). By the Arzela-Ascoli theorem and a diagonal argument over L0 in N, a subsequence satisfies W_k -> W and DW_k -> V uniformly on compact subsets of R^n, with W, V continuous. Passing to the limit in W_k(z) - W_k(z') = integral_0^1 DW_k(z' + t(z - z'))(z - z') dt shows that W is C^1 with DW = V. Moreover [DW]_{alpha;R^n} <= 1/delta, DW(0) = 0, and ||DW(e)|| >= 1/2 because ||DW_k(e_k) - DW(e)|| <= |e_k - e|^alpha / delta + ||DW_k(e) - DW(e)|| -> 0.
   5g. Limit equation. For zeta in C^1_c with tsupport in B_{L0}(0) and k large: |integral ah_k[DW_k][Dzeta] - integral A[DW][Dzeta]| <= integral (|ah_k[DW_k][Dzeta] - A_k[DW_k][Dzeta]| + |(A_k - A)[DW_k][Dzeta]| + |A[DW_k - DW][Dzeta]|) -> 0 by the bounds of 5e-5f and uniform convergence on the compact support, and |integral Psi_k[Dzeta]| <= (1/k + M eps_k) L0^alpha integral ||Dzeta|| -> 0. Hence integral A[DW][Dzeta] = 0 for every zeta in C^1_c(R^n; R^l).
   5h. Step 4 (with Lam' = 1/delta, Lam = M) shows that DW is constant, so DW(e) = DW(0) = 0, contradicting ||DW(e)|| >= 1/2. This proves the claim.
6. Absorption on the unit ball. Let (a, Phi, w) satisfy (H1)-(H8) on B_1 := B_1(0) (i.e. x0 = 0, R = 1, constants lam, M). Put Gam := sup_{B_1} |w| + [Phi]_{alpha;B_1} <= 2M (by (H5), (H4)) and Q := sup{ rho^{1+alpha} [Dw]_{alpha;B_{rho/2}(y)} : y in B_1, 0 < rho <= 1 - |y| } (these are exactly the balls B_rho(y) contained in B_1). By (H7), Q <= [Dw]_{alpha;B_1} < infinity. Fix delta := 1/16 and let C_delta be the constant of step 5.
   6a. For every ball B_rho(y) contained in B_1 (so rho <= 1), step 2 (scaling to B_1: the scaled coefficient has Hoelder constant M rho^alpha <= M, the scaled Phi has [Phit]_{alpha;B_1} = rho^{1+alpha}[Phi]_{alpha;B_rho(y)} <= [Phi]_{alpha;B_1}, sup |wt| <= sup_{B_1} |w|, and [Dwt]_{alpha;B_1} < infinity) and step 5 give rho^{1+alpha} [Dw]_{alpha;B_{rho/2}(y)} <= delta rho^{1+alpha} [Dw]_{alpha;B_rho(y)} + C_delta Gam.
   6b. Fix a ball B_rho(y0) contained in B_1 and x in B_{rho/2}(y0). Then B_{rho/2}(x) is contained in B_rho(y0), hence in B_1, so by the definition of Q (radius rho/2, center x), (rho/2)^{1+alpha} [Dw]_{alpha;B_{rho/4}(x)} <= Q; and 6a with (x, rho/4) gives (rho/4)^{1+alpha} [Dw]_{alpha;B_{rho/8}(x)} <= delta (rho/4)^{1+alpha} [Dw]_{alpha;B_{rho/4}(x)} + C_delta Gam. Hence [Dw]_{alpha;B_{rho/8}(x)} <= H(rho) := delta (2/rho)^{1+alpha} Q + C_delta Gam (4/rho)^{1+alpha}.
   6c. Sup bound: for x in B_{rho/2}(y0), (1b) on B_{rho/8}(x) with t = rho/16 gives ||Dw(x)|| <= 32 Gam / rho + (rho/16)^alpha H(rho).
   6d. Hoelder bound on B_{rho/2}(y0): for x != y in B_{rho/2}(y0), if |x - y| < rho/8 then y is in B_{rho/8}(x) and ||Dw(x) - Dw(y)|| <= H(rho) |x - y|^alpha; if |x - y| >= rho/8 then ||Dw(x) - Dw(y)|| <= 2 sup_{B_{rho/2}(y0)} ||Dw|| <= 2 (8/rho)^alpha [32 Gam / rho + (rho/16)^alpha H(rho)] |x - y|^alpha. Since rho^{1+alpha} H(rho) = delta 2^{1+alpha} Q + C_delta 4^{1+alpha} Gam <= 4 delta Q + 16 C_delta Gam, multiplying by rho^{1+alpha} yields rho^{1+alpha} [Dw]_{alpha;B_{rho/2}(y0)} <= max(4 delta Q + 16 C_delta Gam, 64 * 8^alpha Gam + 2 * 2^{-alpha} (4 delta Q + 16 C_delta Gam)) <= 8 delta Q + (512 + 32 C_delta) Gam.
   6e. Taking the sup over (y0, rho): Q <= 8 delta Q + (512 + 32 C_delta) Gam = Q/2 + (512 + 32 C_delta) Gam (as delta = 1/16); since Q < infinity, Q <= (1024 + 64 C_delta) Gam <= (2048 + 128 C_delta) M.
   6f. With (y0, rho) = (0, 1): [Dw]_{alpha;B_{1/2}} <= Q and, by 6c, ||Dw(x)|| <= 32 Gam + H(1) <= 64 M + 4 delta Q + 32 C_delta M = 64 M + Q/4 + 32 C_delta M for x in B_{1/2}. So both conclusions hold on B_{1/2}(0) with a constant C_1 depending only on (n, l, alpha, lam, M).
7. General R and x0. Given data on B_R(x0), apply step 2 with (y, rho) := (x0, R): wt(z) = w(x0 + Rz), at(z) = a(x0 + Rz), Phit(z) = R Phi(x0 + Rz) satisfy (H1)-(H8) on B_1(0) with lam and M' := M max(1, R^alpha, R^{1+alpha}) (bounds: |at| <= M, Hoelder constant of at is M R^alpha, Hoelder constant of Phit is M R^{1+alpha}, |wt| <= M, and (H7) persists). Step 6 with M' gives C_1(M') with ||Dwt|| <= C_1 and [Dwt]_{alpha;B_{1/2}} <= C_1. Since Dw(x0 + Rz) = R^{-1} Dwt(z), for x, y in B_{R/2}(x0): ||Dw(x)|| <= C_1 / R and ||Dw(x) - Dw(y)|| <= R^{-1} C_1 |(x - y)/R|^alpha = R^{-1-alpha} C_1 |x - y|^alpha. Hence C := C_1(M') max(R^{-1}, R^{-1-alpha}) works; it depends only on n, l, alpha, lam, M, R. QED

## Key steps

1. zero-mean identity for constant linear forms and the interpolation inequality
2. scaling of the weak equation to the unit ball
3. Caccioppoli inequality for constant Legendre coefficients
4. Liouville: mollify, iterate Caccioppoli on derivatives, polynomial with sublinear gradient growth is affine
5. blow-up contradiction argument giving [Dw]_{B_1/2} <= delta [Dw]_{B_1} + C_delta (sup|w| + [Phi])
6. absorption via Q = sup rho^{1+alpha} [Dw]_{B_{rho/2}(y)} < infinity and delta = 1/16
7. rescaling from B_1 to B_R(x0)
