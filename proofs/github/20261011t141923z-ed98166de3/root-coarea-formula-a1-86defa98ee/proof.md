## Proof

Source: Simon, Introduction to GMT, Ch. 2 §6, 6.1-6.3 and 6.6 with the printed arguments (pp. 65-67). The book proves the linear case 6.2 and says of the general formula 6.3: (Its proof uses an approximation argument based on the linear case 6.2. See [Har79] or [Fed69] for the details); 6.6 is obtained (by applying 6.3 to a suitable increasing sequence of simple functions). A complete proof for C¹ maps on C¹ submanifolds is supplied below; it uses the linear algebra of 6.2, the implicit function theorem, the area formula and Fubini, and a direct covering estimate for the critical set. No erratum. Depends on the siblings area_formula and submanifold_tangent.

Statement (frozen CoareaFormula). N, m, k ∈ ℕ, k ≥ 1, n := m + k; M ⊆ ℝᴺ an n-dimensional C¹ Simon submanifold; U ⊆ ℝᴺ open with M ⊆ U; f : ℝᴺ → ℝᵐ of class C¹ on U; g : ℝᴺ → [0,∞] AEMeasurable for Hⁿ⌊M (Hⁿ = μHE[n]). Then y ↦ ∫_{M∩f⁻¹{y}} g dHᵏ (Hᵏ = μHE[k]) is AEMeasurable for Lᵐ = volume, and ∫_M g·J*f dHⁿ = ∫_{ℝᵐ} ∫_{M∩f⁻¹{y}} g dHᵏ dLᵐ(y), where J*f(x) := coareaJacobian M f x = √det(L_xL_x*), L_x := Df(x)|_{T_xM} : T_xM → ℝᵐ.

PART I. PRINTED ARGUMENT (cleaned transcription).
6.1: for the orthogonal projection p : ℝⁿ → ℝᵐ, Fubini gives ∫_{ℝᵐ} Hᵏ(p⁻¹(y) ∩ A) dLᵐ(y) = Hⁿ(A). 6.2: for a linear λ : ℝⁿ → ℝᵐ of rank m, let F = λ⁻¹(0) and choose an orthogonal q with q(F^⊥) = ℝᵐ × {0}, q(F) = {0} × ℝᵏ; then λ = σ∘p∘q with σ a linear isomorphism of ℝᵐ; by 6.1 and the change of variables z = σ(y), |det σ| Lⁿ(A) = ∫ Hᵏ(A ∩ λ⁻¹(z)) dLᵐ(z), and λλ* = σσ* gives |det σ| = √det(λλ*); so √det(λλ*) Lⁿ(A) = ∫_{ℝᵐ} Hᵏ(A ∩ λ⁻¹(y)) dLᵐ(y) (trivially valid, both sides 0, if rank λ < m). 6.3: for C¹ f : M → ℝᵐ and Borel A ⊆ M, ∫_A J*f dHⁿ = ∫_{ℝᵐ} Hᵏ(A ∩ f⁻¹(y)) dLᵐ(y) (approximation argument based on 6.2, [Har79], [Fed69]). 6.6: for g ≥ 0 Hⁿ-measurable on M, ∫_M g J*f dHⁿ = ∫_{ℝᵐ} ∫_{f⁻¹(y)} g dHᵏ dLᵐ(y) (apply 6.3 to an increasing sequence of simple functions).

PART II. COMPLETE PROOF.

Step 0 (preliminaries).
0.1 By submanifold_tangent: T_xM = range Dψ(x′) for every local representation ψ with ψ(x′) = x (dimension n); M is Borel; x ↦ P_x is continuous on M. Since L_xL_x* = Df(x)P_xDf(x)* as an endomorphism of ℝᵐ, J*f is continuous on M. Put C := {x ∈ M : J*f(x) = 0} (relatively closed in M, Borel) and R := M∖C (relatively open in M, Borel).
0.2 Linear algebra. (a) For L : T → ℝᵐ linear (T an inner product space), LL* is positive semidefinite, det(LL*) ≥ 0, and det(LL*) > 0 ⟺ L is surjective. (b) Lemma L: let T be an n-dimensional inner product space, L : T → ℝᵐ surjective, Θ : ℝᵐ × ℝᵏ → T a linear isomorphism with L(Θ(a,b)) = a for all (a,b), and Θ₂ := Θ(0,·) : ℝᵏ → T. Then √det(LL*)·√det(Θ*Θ) = √det(Θ₂*Θ₂). Proof: let Q := ker L (dim k) and Q^⊥ its orthogonal complement in T (dim m). L|_{Q^⊥} : Q^⊥ → ℝᵐ is an isomorphism and L* has range in Q^⊥, so √det(LL*) = |det L|_{Q^⊥}| (orthonormal bases). Θ₂ maps ℝᵏ isomorphically onto Q (LΘ(0,b) = 0). With respect to ℝᵐ ⊕ ℝᵏ and Q^⊥ ⊕ Q, Θ is block lower triangular with diagonal blocks α := π_{Q^⊥}Θ(·,0) and Θ₂, so √det(Θ*Θ) = |det Θ| = |det α|·|det Θ₂| (orthonormal bases); and L∘α = id_{ℝᵐ} because L(Θ(a,0)) = a and L vanishes on Q, so |det α| = 1/|det L|_{Q^⊥}|. Combining gives the claim, with |det Θ₂| = √det(Θ₂*Θ₂). (Cf. SimonGMT CoareaLinearAlgebra.lean and coarea_linear for 6.2.)

Step 1 (critical set: Hᵏ(C ∩ f⁻¹{y}) = 0 for Lᵐ-a.e. y).
1.1 Euclidean lemma. Let V ⊆ ℝⁿ be open, G : V → ℝᵐ of class C¹, C_G := {x ∈ V : rank DG(x) < m} (relatively closed in V), and Q ⊆ V compact. Then μHE[k](Q ∩ C_G ∩ G⁻¹{y}) = 0 for Lᵐ-a.e. y.
Proof. If m = 0, C_G = ∅. Let m ≥ 1 and K′ := Q ∩ C_G (compact); if K′ = ∅ there is nothing to prove, so assume K′ ≠ ∅. Choose ρ₀ > 0 with K₁ := {x : dist(x,K′) ≤ ρ₀} ⊆ V (compact since K′ is compact and nonempty), L_G := max_{K₁}‖DG‖, ω(r) := sup{‖DG(z) − DG(x)‖ : x ∈ K′, |z − x| ≤ r} → 0 as r → 0 (uniform continuity on K₁). For x ∈ K′ and r ≤ ρ₀, the mean value inequality gives G(B̄(x,r)) ⊆ G(x) + DG(x)(B̄(0,r)) + B̄(0, ω(r)r). As rank DG(x) ≤ m − 1, pick a unit vector e orthogonal to range DG(x) and complete it to an orthonormal basis; then G(B̄(x,r)) lies in a box of side 2ω(r)r in direction e and sides 2(L_G + ω(r))r in the other m − 1 directions, so Lᵐ(G(B̄(x,r))) ≤ 2ᵐ ω(r)(L_G + ω(r))^{m−1} rᵐ. For 0 < r ≤ ρ₀ let x_1, …, x_p be a maximal r-separated subset of K′: the balls B̄(x_i, r) cover K′, and the disjoint balls B(x_i, r/2) lie in K₁, so p ≤ Lⁿ(K₁)/(ω_n(r/2)ⁿ). For every y, the sets B̄(x_i,r) ∩ K′ ∩ G⁻¹{y} with y ∈ G(B̄(x_i,r)) cover K′ ∩ G⁻¹{y} and have diameter ≤ 2r, so pre^k_{2r}(K′ ∩ G⁻¹{y}) ≤ S_r(y) := Σ_{i≤p} (2r)^k 1_{G(B̄(x_i,r))}(y) (Mathlib normalization of hausdorffMeasure_apply; S_r is Borel since G(B̄(x_i,r)) is compact), and ∫ S_r dLᵐ ≤ p(2r)^k 2ᵐω(r)(L_G + ω(r))^{m−1}rᵐ ≤ Lⁿ(K₁) 2^{n+k+m} ω(r)(L_G + ω(r))^{m−1}/ω_n → 0 as r → 0 (n = m + k). For fixed δ > 0 and r ≤ δ/2, pre^k_δ ≤ pre^k_{2r} ≤ S_r; along r_j → 0, Fatou gives ∫ liminf_j S_{r_j} = 0, so pre^k_δ(K′ ∩ G⁻¹{y}) = 0 for a.e. y; taking δ = 1/l, l ∈ ℕ, μH[k](K′ ∩ G⁻¹{y}) = sup_l pre^k_{1/l}(K′ ∩ G⁻¹{y}) = 0 for a.e. y, and μHE[k] is a constant multiple of μH[k].
1.2 Transfer to M. Let ψ : V → W ∩ M be a local representation (C¹) and G := f∘ψ (C¹ on V since ψ(V) ⊆ M ⊆ U). Since Dψ(x) maps ℝⁿ isomorphically onto T_{ψ(x)}M (0.1), rank DG(x) = rank L_{ψ(x)}, so by 0.2(a) ψ(C_G) = C ∩ ψ(V). For a compact exhaustion Q_1 ⊆ Q_2 ⊆ … of V, ψ is Lipschitz on each Q_j (C¹), so μHE[k](ψ(Q_j) ∩ C ∩ f⁻¹{y}) = μHE[k](ψ(Q_j ∩ C_G ∩ G⁻¹{y})) ≤ Lip(ψ|Q_j)^k μHE[k](Q_j ∩ C_G ∩ G⁻¹{y}) = 0 for a.e. y (Mathlib LipschitzOnWith.hausdorffMeasure_image_le). Countably many representations cover M (Lindelöf) and C ⊆ ∪ of countably many ψ_i(Q_{i,j}); hence μHE[k](C ∩ f⁻¹{y}) = 0 for Lᵐ-a.e. y.

Step 2 (straightening charts on R). Claim: every x₀ ∈ R has a neighbourhood O ∩ M ⊆ R (O open) parametrized by Ψ : Ω → ℝᴺ, Ω ⊆ ℝᵐ × ℝᵏ open, such that Ψ is C¹, injective, DΨ(ω) injective, Ψ(Ω) = O ∩ M, f(Ψ(a,b)) = a for (a,b) ∈ Ω, and Ψ (transported to ℝⁿ by the linear isometry ℝᵐ × ℝᵏ ≅ ℝⁿ, Euclidean product norm) is a Simon local representation of M on (Ω, O).
Construction. Take a representation ψ : V → W ∩ M with x₀ = ψ(x₀′), G := f∘ψ. DG(x₀′) = L_{x₀}∘Dψ(x₀′) is surjective (J*f(x₀) > 0, 0.2(a), 0.1). Let K₀ := ker DG(x₀′) (dim k), ι : ℝᵏ → K₀ a linear isometry, π_{K₀} the orthogonal projection, and Φ(x) := (G(x), ι⁻¹π_{K₀}(x − x₀′)). DΦ(x₀′) is invertible, so by the C¹ inverse function theorem there is an open V₁ ∋ x₀′, V₁ ⊆ V, such that Φ : V₁ → Ω := Φ(V₁) is a C¹ diffeomorphism onto an open set, with inverse Λ; shrinking V₁ we may assume J*f > 0 on ψ(V₁) (continuity, 0.1). Put Ψ := ψ∘Λ. By 4.2 (SimonGMT exists_open_image_eq_inter) ψ(V₁) = O ∩ M for an open O ⊆ W. Then Ψ is C¹ and injective, DΨ = Dψ(Λ)DΛ is injective, Ψ(Ω) = O ∩ M ⊆ R, f(Ψ(a,b)) = G(Λ(a,b)) = a. Properness: for compact Q ⊆ O, V ∩ ψ⁻¹(Q) is compact and contained in V₁ (ψ(V ∩ ψ⁻¹Q) ⊆ O ∩ M = ψ(V₁), injectivity), so Ω ∩ Ψ⁻¹(Q) = Φ(V ∩ ψ⁻¹(Q)) is compact.

Step 3 (coarea on one straightening chart). For Ψ, Ω as in Step 2, every Borel E ⊆ Ψ(Ω) and every Borel g : ℝᴺ → [0,∞]: y ↦ ∫_{E∩f⁻¹{y}} g dHᵏ is Borel and ∫_E g J*f dHⁿ = ∫_{ℝᵐ} ∫_{E∩f⁻¹{y}} g dHᵏ dLᵐ(y).
3.1 E′ := Ψ⁻¹(E) ∩ Ω is Borel. By the weighted area formula for the representation Ψ (SimonGMT IsSimonLocalRepresentation.weighted_area_formula, or the sibling AreaFormula; Lⁿ on ℝⁿ corresponds to Lᵐ ⊗ Lᵏ under the isometry), ∫_E g J*f dHⁿ = ∫_{E′} g(Ψ) (J*f∘Ψ) JΨ d(a,b), JΨ := √det(DΨ*DΨ).
3.2 For fixed a, Ω_a := {b : (a,b) ∈ Ω} is open and Ψ_a := Ψ(a,·) is C¹, injective, with injective derivative D_bΨ(a,b) = DΨ(a,b)(0,·). Moreover Ψ_a(E′_a) = E ∩ f⁻¹{a}, E′_a := {b : (a,b) ∈ E′}: ⊆ since f∘Ψ(a,b) = a; ⊇ since p ∈ E ∩ f⁻¹{a} is p = Ψ(a′,b) with (a′,b) ∈ E′ and a′ = f(p) = a. The k-dimensional weighted area formula for Ψ_a (injective, injective derivative; SimonGMT weighted_area_formula_volume_of_injective_derivative) gives ∫_{E∩f⁻¹{a}} g dHᵏ = ∫_{E′_a} g(Ψ(a,b)) J_bΨ(a,b) db, J_bΨ := √det(D_bΨ*D_bΨ).
3.3 Pointwise identity: for (a,b) ∈ Ω, with x = Ψ(a,b), T = T_xM = range DΨ(a,b) (submanifold_tangent applied to the representation Ψ), L = L_x and Θ := DΨ(a,b) regarded as an isomorphism ℝᵐ × ℝᵏ → T: L∘Θ = D(f∘Ψ)(a,b) = (a′,b′) ↦ a′, so Lemma L gives J*f(Ψ(a,b))·JΨ(a,b) = J_bΨ(a,b).
3.4 By Tonelli on ℝᵐ × ℝᵏ, ∫_{E′} g(Ψ)(J*f∘Ψ)JΨ = ∫_{ℝᵐ} (∫_{E′_a} g(Ψ(a,b))J_bΨ(a,b) db) da, the inner integral being a Borel function of a; by 3.2 it equals ∫_{E∩f⁻¹{a}} g dHᵏ. With 3.1 this proves Step 3.

Step 4 (Borel g). Choose straightening charts Ψ_i (i ∈ ℕ) whose images cover R (Lindelöf; Step 2) and put E_i := Ψ_i(Ω_i)∖∪_{l<i}Ψ_l(Ω_l): disjoint Borel sets with union R. For Borel g ≥ 0, by Step 3 and monotone convergence, ∫_R g J*f dHⁿ = Σ_i ∫_{E_i} g J*f dHⁿ = Σ_i ∫ ∫_{E_i∩f⁻¹{y}} g dHᵏ dy = ∫ ∫_{R∩f⁻¹{y}} g dHᵏ dy, and y ↦ ∫_{R∩f⁻¹{y}} g dHᵏ is Borel. Since J*f = 0 on C, ∫_M g J*f dHⁿ = ∫_R g J*f dHⁿ; and ∫_{M∩f⁻¹{y}} g dHᵏ = ∫_{R∩f⁻¹{y}} g dHᵏ + ∫_{C∩f⁻¹{y}} g dHᵏ where the last term is 0 whenever Hᵏ(C ∩ f⁻¹{y}) = 0, i.e. for a.e. y (Step 1). Hence for Borel g both conclusions hold (the fiber integral agrees a.e. with a Borel function).

Step 5 (AEMeasurable g). Let g be AEMeasurable for Hⁿ⌊M; choose Borel g₀ with g = g₀ Hⁿ⌊M-a.e. and a Borel Z ⊆ M with Hⁿ(Z) = 0 and g = g₀ on M∖Z. Then ∫_M g J*f dHⁿ = ∫_M g₀ J*f dHⁿ. For a.e. y, Hᵏ(Z ∩ f⁻¹{y}) = 0: Z ∩ C is handled by Step 1, and Step 4 with the Borel function 1_Z gives ∫ Hᵏ(Z ∩ R ∩ f⁻¹{y}) dy = ∫_{Z∩R} J*f dHⁿ = 0. Hence ∫_{M∩f⁻¹{y}} g dHᵏ = ∫_{M∩f⁻¹{y}} g₀ dHᵏ for a.e. y, and Step 4 for g₀ yields AEMeasurability of y ↦ ∫_{M∩f⁻¹{y}} g dHᵏ and ∫_M g J*f dHⁿ = ∫ ∫_{M∩f⁻¹{y}} g dHᵏ dy. In the frozen notation this is AEMeasurable (fun y ↦ ∫⁻ x in M ∩ f⁻¹' {y}, g x ∂μHE[k]) volume ∧ ∫⁻ x in M, g x * ENNReal.ofReal (coareaJacobian M f x) ∂μHE[m + k] = ∫⁻ y, ∫⁻ x in M ∩ f⁻¹' {y}, g x ∂μHE[k] ∂volume. (If M = ∅ both sides vanish; if m + k > N then M = ∅ since no injective linear map ℝⁿ → ℝᴺ exists.)

## Key steps

1. J*f is continuous on M; critical set C = {J*f = 0} and regular set R are Borel; linear Lemma L: √det(LL*)·|det Θ| = |det Θ₂| when L∘Θ = projection.
2. Critical set: Euclidean covering estimate (images of small balls lie in thin slabs, packing bound, Fatou) gives Hᵏ(C_G ∩ Q ∩ G⁻¹y) = 0 a.e.; transfer to M through charts and Lipschitz images.
3. Straightening charts on R via the inverse function theorem: Ψ with f(Ψ(a,b)) = a, a Simon local representation.
4. On one chart: area formula for Ψ, area formula on each fiber Ψ(a,·), Lemma L and Tonelli give the formula for Borel E and g.
5. Countable disjoint decomposition of R, critical part negligible, then reduction from a.e.-measurable g to Borel g using null sets.
