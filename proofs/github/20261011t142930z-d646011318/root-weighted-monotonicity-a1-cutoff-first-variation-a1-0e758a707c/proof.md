## Proof

Conventions. E := Ambient n ℓ = EuclideanSpace ℝ (Fin (n+ℓ)) = ℝ^{n+ℓ} with its Borel σ-algebra; B_s(ξ) := closedBall ξ s is the CLOSED ball; r = r(x) := |x − ξ|; λ is Lebesgue measure on ℝ and ∫_{(a,b]} means the integral over Ioc a b; φ' := deriv φ. μ := V.weight, p_x := (T_xV).starProjection, ∇h := gradient h, ∇^M h(x) = p_x(∇h(x)), q := q_ξ. This child carries out Steps 0, 1 and the first half of Step 3 of the parent proof; the first-variation identity of the sibling theorem radial_first_variation is supplied as the hypothesis (RFV).
1. (Room; parent Step 0.) W := (E ∖ tsupport h) ∪ U is open, and B_ρ(ξ) ⊆ W (a point of B_ρ(ξ) lying in tsupport h lies in U by hypothesis). B_ρ(ξ) is compact, so there is δ > 0 such that the closed δ-neighbourhood of B_ρ(ξ), which equals B_{ρ+δ}(ξ) (cthickening_closedBall), is contained in W (IsCompact.exists_cthickening_subset_open). [Equivalently, as in the parent proof: otherwise there are x_m ∈ tsupport h ∩ B_{ρ+1/m}(ξ) ∖ U, a subsequence converges to some x ∈ tsupport h ∩ B_ρ(ξ) with x ∉ U (tsupport h and E ∖ U are closed), contradicting tsupport h ∩ B_ρ(ξ) ⊆ U.] Put R := ρ + δ > ρ and B := B_R(ξ). Then K := tsupport h ∩ B ⊆ U, K is compact, and every x ∈ B ∖ U lies outside tsupport h.
2. (h and ∇h on B.) h is continuous at every x ∈ B: if x ∈ U because h ∈ C¹(U) and U is open; if x ∉ U then x ∉ tsupport h and h ≡ 0 on the open neighbourhood E ∖ tsupport h of x. Likewise ∇h is continuous at every x ∈ B: on the open set U, Dh is continuous (ContDiffOn.continuousOn_fderiv_of_isOpen) and ∇h is Dh composed with the inverse Riesz isomorphism (InnerProductSpace.toDual); if x ∉ tsupport h then Dh(y) = 0 for all y near x (fderiv_of_notMem_tsupport), so ∇h ≡ 0 near x. In particular h(x) = 0 and ∇h(x) = 0 for every x ∉ tsupport h. As B is compact there are A, A₁ ≥ 0 with |h| ≤ A and |∇h| ≤ A₁ on B (IsCompact.exists_bound_of_continuousOn); h and ∇h are continuous on the closed set B, hence a.e. strongly measurable for μ⌞B (ContinuousOn.aestronglyMeasurable).
3. (∇^M h.) By (FV3) x ↦ p_x is μ-a.e. strongly measurable, hence μ⌞B-a.e. strongly measurable; since the evaluation map (L, v) ↦ Lv is continuous (isBoundedBilinearMap_apply), ∇^M h(x) = p_x(∇h(x)) is μ⌞B-a.e. strongly measurable (Continuous.comp_aestronglyMeasurable). |∇^M h(x)| ≤ |∇h(x)| ≤ A₁ on B because orthogonal projections do not increase norms (Submodule.norm_starProjection_apply_le), and ∇^M h(x) = 0 for x ∉ tsupport h.
4. (q.) The orthogonal projection onto (T_xV)^⊥ is 1 − p_x (Submodule.starProjection_orthogonal'), so q(x) = |(x − ξ) − p_x(x − ξ)|²/|x − ξ|². Hence q is μ-a.e. strongly measurable (p_x(x − ξ) is, by (FV3) and continuity of evaluation; then differences, norms, squares and the quotient of a.e.-measurable real functions are a.e. measurable), and so is its restriction to B. Moreover 0 ≤ q ≤ 1 everywhere: |p^⊥v| ≤ |v|, and for x = ξ the quotient is 0/0 = 0. In particular |q(x)| ≤ 1 on B.
5. (H on K.) H ∈ L¹_loc(U, μ) (first conjunct of HasMeanCurvatureIn) and K ⊆ U is compact, so H is μ-integrable on K (LocallyIntegrableOn.integrableOn_compact_subset). Consequently, if c: E → ℝ is μ⌞K-a.e. strongly measurable and |c| ≤ C on K, then x ↦ h(x)c(x)⟨x − ξ, H(x)⟩ is μ-integrable on K: it is μ⌞K-a.e. strongly measurable and bounded on K by A·|C|·R·|H(x)|, which is integrable on K.
6. (G integrable on B.) By bilinearity, G(x) = ⟨x − ξ, ∇^M h(x)⟩ + h(x)⟨x − ξ, H(x)⟩. The first term is μ⌞B-a.e. strongly measurable and bounded on B by R·A₁, and μ(B) < ∞ (B compact, μ finite on compacts), so it is integrable on B. The second term coincides on B with 1_K·h⟨x − ξ, H⟩ (on B ∖ K, x ∉ tsupport h so h(x) = 0), which is integrable by 5 with c ≡ 1. Hence G is μ-integrable on B. Steps 1–6 give ρ < R and the measurability, boundedness and integrability conjuncts.
7. (The test field; parent Step 2.) Fix ε > 0 with (1 + ε)ρ < R, φ ∈ C¹(ℝ) with φ = 1 on (−∞, 1] and φ = 0 on [1 + ε, ∞), and τ ∈ (0, ρ]. φ' is continuous and φ'(t) = 0 for t > 1 + ε (φ ≡ 0 on the open set (1 + ε, ∞)). Since (1 + ε)τ ≤ (1 + ε)ρ < R, we have K_τ := tsupport h ∩ B_{(1+ε)τ}(ξ) ⊆ K ⊆ U. Put γ(t) := φ(t/τ); γ is C¹, γ(t) = 1 = γ(0) for t ≤ τ, γ(t) = 0 for t ≥ (1 + ε)τ. By the sibling lemma weighted_mono_radial_test_field (with a := τ, b := (1 + ε)τ), x ↦ (h(x)γ(r))(x − ξ) is a test field in U, so (RFV) holds for this γ. By the chain rule γ'(t) = φ'(t/τ)/τ, hence r·γ'(r) = (r/τ)φ'(r/τ).
8. (From U to E.) Let x ∉ U; then x ∉ K_τ, so either x ∉ tsupport h, in which case h(x) = 0 and ∇^M h(x) = 0, or r > (1 + ε)τ, in which case r/τ > 1 + ε and φ(r/τ) = φ'(r/τ) = 0. In either case both (RFV) integrands vanish at x, so both integrals over U equal the corresponding integrals over E (setIntegral_eq_integral_of_forall_compl_eq_zero).
9. (The pieces are integrable.) Let M₀, M₁ be the maxima of |φ|, |φ'| on [0, R/τ]; for x ∈ B, r/τ ∈ [0, R/τ]. Put T₁ := hφ(r/τ), T₂ := h(1 − q)·((r/τ)φ'(r/τ)), T₃ := φ(r/τ)⟨x − ξ, ∇^M h⟩, Q := hφ(r/τ)⟨x − ξ, H⟩. For x ∉ B we have r > R > (1 + ε)τ, so φ(r/τ) = φ'(r/τ) = 0 and T₁ = T₂ = T₃ = 0 there. On B they are μ⌞B-a.e. strongly measurable (steps 2–4; r is continuous) and bounded by A·M₀, A·(R/τ)·M₁ (using |1 − q| ≤ 1) and M₀·R·A₁ respectively; since μ(B) < ∞ they are μ-integrable. Q = 1_K·hφ(r/τ)⟨x − ξ, H⟩ (off K either h(x) = 0 or x ∉ B and then φ(r/τ) = 0), which is μ-integrable by 5 with c := φ(r/τ), C := M₀.
10. (Assembling; parent Step 3.) By 7, the left (RFV) integrand equals n·T₁ + T₂ + T₃ pointwise (expand h(nφ(r/τ) + (r/τ)φ'(r/τ)(1 − q)) + φ(r/τ)⟨x − ξ, ∇^M h⟩), and the right integrand is Q. By 8 and 9 (linearity of the integral for integrable functions), n∫T₁dμ + ∫T₂dμ + ∫T₃dμ = −∫Q dμ. Finally φ(r/τ)·G = T₃ + Q pointwise (⟨x − ξ, ∇^M h + hH⟩ = ⟨x − ξ, ∇^M h⟩ + h⟨x − ξ, H⟩), so ∫φ(r/τ)G dμ = ∫T₃dμ + ∫Q dμ, and therefore n∫hφ(r/τ)dμ + ∫h(1 − q)((r/τ)φ'(r/τ))dμ + ∫φ(r/τ)G dμ = 0, the last conjunct.

## Key steps

1. Room: B_ρ(ξ) lies in the open set (E ∖ tsupport h) ∪ U, so some B_R(ξ), R > ρ, does; then K := tsupport h ∩ B_R(ξ) ⊆ U is compact (parent Step 0)
2. h and ∇h are continuous at every point of B_R(ξ) (C¹ on U, ≡ 0 near points off tsupport h), hence bounded by A, A₁ and μ⌞B-measurable
3. (FV3) gives measurability of ∇^M h = p_x∇h and of q_ξ = |(1 − p_x)(x−ξ)|²/|x−ξ|² ∈ [0, 1]
4. H is μ-integrable on the compact K ⊆ U; hence G = ⟨x−ξ, ∇^M h⟩ + h⟨x−ξ, H⟩ is integrable on B_R(ξ) (parent Step 1)
5. For admissible (ε, φ, τ): γ = φ(·/τ) makes (h γ(r))(x−ξ) a test field (sibling radial_test_field), so (RFV) applies; rγ'(r) = (r/τ)φ'(r/τ) (parent Step 2)
6. Integrands vanish off U, so ∫_U = ∫_E; the pieces T₁, T₂, T₃, Q are integrable
7. Regroup: n∫hφ(r/τ) + ∫h(1−q)(r/τ)φ'(r/τ) + ∫φ(r/τ)G = 0 (parent Step 3)
