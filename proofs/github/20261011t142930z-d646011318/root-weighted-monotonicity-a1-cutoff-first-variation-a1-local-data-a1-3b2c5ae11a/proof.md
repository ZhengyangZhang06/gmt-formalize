## Proof

Conventions. E := Ambient n ℓ = EuclideanSpace ℝ (Fin (n+ℓ)) is a proper, second-countable Euclidean space with its Borel σ-algebra; μ := V.weight; B_s := closedBall ξ s (closed ball); p_x := (T_xV).starProjection, the orthogonal projection onto T_xV, a continuous linear map E → E; Dh(x) := fderiv ℝ h x; ∇h := gradient h, so ∇h(x) = (toDual ℝ E)⁻¹(Dh(x)), where toDual ℝ E is the Riesz linear isometric equivalence E ≃ E*; ∇^M h(x) = p_x(∇h(x)); q(x) = |p_{(T_xV)^⊥}(x − ξ)|²/|x − ξ|². Of H only its local μ-integrability on U is used.
1. (Room.) The set W := (E ∖ tsupport h) ∪ U is open, since tsupport h is closed and U is open. We have B_ρ ⊆ W: if x ∈ B_ρ lies in tsupport h then x ∈ tsupport h ∩ B_ρ ⊆ U, and otherwise x ∈ E ∖ tsupport h. B_ρ is compact because E is proper. So by IsCompact.exists_cthickening_subset_open there is δ > 0 with cthickening δ B_ρ ⊆ W. Since δ ≥ 0 and ρ ≥ 0, cthickening δ B_ρ = B_{δ+ρ} (cthickening_closedBall). Put R := δ + ρ. Then ρ < R, which is (a); also R ≥ 0 and B_R ⊆ W. If x ∈ tsupport h ∩ B_R, then x ∈ W but x ∉ E ∖ tsupport h, so x ∈ U. This is (b). Consequently every x ∈ B_R with x ∉ U satisfies x ∉ tsupport h.
2. (Continuity of h and ∇h on B_R.) Let x ∈ B_R.
- Case x ∈ U. U is a neighbourhood of x, so h is continuous at x (ContDiffOn.continuousOn, ContinuousOn.continuousAt). Dh is continuous on U by ContDiffOn.continuousOn_fderiv_of_isOpen (U open, order 1 ≥ 1), hence continuous at x. Since (toDual ℝ E)⁻¹ is continuous, ∇h = (toDual ℝ E)⁻¹ ∘ Dh is continuous at x.
- Case x ∉ U. By step 1, x ∉ tsupport h, so the open set E ∖ tsupport h is a neighbourhood of x. At every y in it, h(y) = 0 (image_eq_zero_of_notMem_tsupport) and Dh(y) = 0 (fderiv_of_notMem_tsupport), hence ∇h(y) = (toDual ℝ E)⁻¹(0) = 0. So h and ∇h coincide near x with the constant 0, and both are continuous at x.
Continuity at every point of B_R gives continuity of h and ∇h on B_R.
3. (Bounds and measurability of h and ∇h.) B_R is compact, so by IsCompact.exists_bound_of_continuousOn there are A, A₁ ∈ ℝ with |h(x)| ≤ A and |∇h(x)| ≤ A₁ for all x ∈ B_R. B_R is closed, hence measurable, and h, ∇h are continuous on B_R. So both are a.e. strongly measurable for μ⌞B_R (ContinuousOn.aestronglyMeasurable). This gives the h-parts of (c) and (d). Moreover μ(B_R) < ∞, because B_R is compact and μ is finite on compact sets.
4. (∇^M h.) The evaluation map (L, v) ↦ L v on (E →L[ℝ] E) × E is continuous (isBoundedBilinearMap_apply). The map x ↦ p_x is μ-a.e. strongly measurable by hypothesis, hence μ⌞B_R-a.e. strongly measurable, and ∇h is μ⌞B_R-a.e. strongly measurable by step 3. By Continuous.comp_aestronglyMeasurable₂, ∇^M h(x) = p_x(∇h(x)) is μ⌞B_R-a.e. strongly measurable. An orthogonal projection does not increase norms (Submodule.norm_starProjection_apply_le), so |∇^M h(x)| ≤ |∇h(x)| ≤ A₁ for x ∈ B_R.
5. (q.) For every x the orthogonal projection onto (T_xV)^⊥ is 1 − p_x (Submodule.starProjection_orthogonal'), so q(x) = |(1 − p_x)(x − ξ)|²/|x − ξ|².
- x ↦ 1 − p_x is μ-a.e. strongly measurable (a constant minus an a.e. strongly measurable map), and x ↦ x − ξ is continuous. By continuity of evaluation, as in step 4, x ↦ (1 − p_x)(x − ξ) is μ-a.e. strongly measurable, and so are its norm and the square of its norm.
- The denominator x ↦ |x − ξ|² is continuous, hence measurable.
- A quotient of two a.e.-measurable real functions is a.e.-measurable (AEMeasurable.div), and a.e.-measurable real-valued functions are a.e. strongly measurable. So q is μ-a.e. strongly measurable, hence μ⌞B_R-a.e. strongly measurable. This is the q-part of (c).
For every x, q(x) ≥ 0, being a quotient of squares. Also |p_{(T_xV)^⊥}(x − ξ)| ≤ |x − ξ| (Submodule.norm_starProjection_apply_le), so the numerator is at most the denominator. Since a/b ≤ 1 whenever a ≤ b and 0 ≤ b, including b = 0 where a/b = 0 (div_le_one_of_le₀), we get 0 ≤ q(x) ≤ 1, so |q(x)| ≤ 1. This is the q-part of (d).
6. (The ∇^M h term, (e).) F₁(x) := ⟨x − ξ, ∇^M h(x)⟩ is μ⌞B_R-a.e. strongly measurable: the inner product is continuous, x ↦ x − ξ is continuous, and ∇^M h is μ⌞B_R-a.e. strongly measurable by step 4 (Continuous.comp_aestronglyMeasurable₂). For x ∈ B_R, Cauchy–Schwarz gives |F₁(x)| ≤ |x − ξ|·|∇^M h(x)| ≤ R·A₁, using |x − ξ| ≤ R, |∇^M h(x)| ≤ A₁ and R ≥ 0. Since μ(B_R) < ∞, F₁ is μ-integrable on B_R (IntegrableOn.of_bound). This is (e).
7. (The H term.) K := tsupport h ∩ B_R is compact, being a closed subset of the compact B_R, and K ⊆ U by (b). As H is locally μ-integrable on U, H is μ-integrable on K (LocallyIntegrableOn.integrableOn_compact_subset). Let F₂(x) := h(x)⟨x − ξ, H(x)⟩.
- F₂ is μ⌞K-a.e. strongly measurable. h is μ⌞B_R-a.e. strongly measurable and μ⌞K ≤ μ⌞B_R. H is μ⌞K-a.e. strongly measurable because it is μ-integrable on K, so ⟨x − ξ, H(x)⟩ is too, by continuity of the inner product. Products preserve a.e. strong measurability.
- For x ∈ K we have |h(x)| ≤ A (so A ≥ 0) and |⟨x − ξ, H(x)⟩| ≤ |x − ξ||H(x)| ≤ R|H(x)|. Hence |F₂(x)| ≤ (A·R)|H(x)|, and x ↦ (A·R)|H(x)| is μ-integrable on K. By domination (Integrable.mono'), F₂ is μ-integrable on K.
- If x ∈ B_R ∖ K then x ∉ tsupport h, so h(x) = 0 and F₂(x) = 0. As B_R is measurable, F₂ is μ-integrable on B_R (IntegrableOn.of_forall_sdiff_eq_zero).
8. (G, (f), conclusion.) For every x, additivity of the inner product in its second argument and ⟨u, a v⟩ = a⟨u, v⟩ for real a (inner_add_right, inner_smul_right) give G(x) = ⟨x − ξ, ∇^M h(x)⟩ + ⟨x − ξ, h(x)H(x)⟩ = F₁(x) + F₂(x). By steps 6 and 7, F₁ + F₂ is μ-integrable on B_R. Integrability on the measurable set B_R transfers along this pointwise equality (IntegrableOn.congr_fun), which is (f). Steps 1, 3, 5, 6 and 8 give (a)–(f) with these R and A.
