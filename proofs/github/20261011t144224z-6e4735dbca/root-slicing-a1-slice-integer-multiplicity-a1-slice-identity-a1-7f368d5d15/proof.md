Fact F (frame sign): if τ, τ' are orthonormal bases of the same k-dimensional subspace, τ'_i = Σ_j B_ij τ_j with B orthogonal, then by multilinearity and alternation simple(τ') = det(B)·simple(τ) and det B = ±1. IsRectifiableTriple U k M θ ξ means: M ⊆ U; M is Hᵏ-null-measurable; M is countably k-rectifiable; θ > 0 on M; θ is Hᵏ-integrable on M ∩ K for every compact K ⊆ U; ξ is Hᵏ⌞M-a.e. strongly measurable; for Hᵏ-a.e. x ∈ M there is an orthonormal τ : Fin k → ℝ^P with HasWeightedApproximateTangentSpaceAt k M θ x (span τ) and ξ(x) = ±simple(τ). The weighted approximate tangent plane (Simon Ch. 3, 1.7) is unique at points where θ(x) ≠ 0 (SimonGMT `HasWeightedApproximateTangentSpaceAt.unique`); when it exists at x ∈ M we call it T_x. TG(f, G) abbreviates the tangential-gradient property: for Hⁿ-a.e. x ∈ M and every Q with HasWeightedApproximateTangentSpaceAt n M θ x Q, G(x) ∈ Q and for every u ∈ Q the map s ↦ f(x + s u) has derivative ⟨G(x), u⟩ at s = 0.
We follow the printed proof of Simon Ch. 6, Lemma 4.5(2), from (4) to the end, with Remark 4.2, evaluating the restriction terms in the representations supplied by IsSlice. The siblings `coarea` and `lipschitz_leibniz` apply to the present hypotheses verbatim. Fix ω ∈ D^m(U), K := tsupport ω (compact ⊆ U), and write ν(x) := |G(x)|⁻¹G(x) (so ν(x) = 0 when G(x) = 0).
1. (G vanishes on level sets; Simon's remark after (4).) For c ∈ ℝ apply `coarea` to the Borel g := 1_{f⁻¹{c}}: ∫_ℝ H^m(M ∩ f⁻¹{t} ∩ f⁻¹{c}) dt = ∫_M |G|1_{f=c} dHⁿ. The left integrand vanishes for t ≠ c, so the left side is 0 and G = 0 Hⁿ-a.e. on M ∩ f⁻¹{c}.
2. (Null transfer, NT.) As in the slice triple: for Z ⊆ M with Hⁿ(Z) = 0, applying `coarea` to g = 1_{toMeasurable Hⁿ Z} gives H^m(Z ∩ f⁻¹{t}) = 0 for a.e. t.
3. (The density g_ω.) Let θ̃, ξ̃ be Borel with θ = θ̃, ξ = ξ̃ Hⁿ-a.e. on M (θ is a.e. strongly measurable on M since M ⊆ U is covered by countably many compacts K_i ⊆ U on which θ is integrable). Define the Borel function g(x) := 1_K(x)1_{G(x)≠0}θ̃(x)ξ̃(x)(ν(x)♭∧ω(x)). By Fact U and ‖ν♭∧ω(x)‖ ≤ (m+1)‖ω(x)‖, |g| ≤ (m+1)sup‖ω‖·θ̃·1_K Hⁿ-a.e. on M, so g ∈ L¹(Hⁿ⌞M). Moreover θξ(G♭∧ω) = |G|·g Hⁿ-a.e. on M (both vanish where G = 0; elsewhere G♭∧ω = |G|ν♭∧ω by linearity, and ω = 0 off K).
4. (Remark 4.2.) Write g = g⁺ − g⁻ and φ_±(r) := ∫_{M∩f⁻¹{r}} g^± dH^m. By `coarea`, φ_± are a.e.-measurable with ∫_ℝ φ_± dr = ∫_M |G|g^± dHⁿ ≤ L‖g‖_{L¹(Hⁿ⌞M)} < ∞; so φ_± < ∞ a.e. and φ := φ₊ − φ₋ ∈ L¹(ℝ). For a < b apply `coarea` to the Borel g^±·1_{a<f<b}: on f⁻¹{r} this function equals 1_{(a,b)}(r)g^±, hence ∫_{M∩{a<f<b}} |G|g^± dHⁿ = ∫_a^b φ_±(r) dr and, subtracting the finite quantities, ∫_{M∩{a<f<b}} |G|g dHⁿ = ∫_a^b φ(r) dr.
5. (Identification with the slice.) Let Z := {x ∈ M : θ(x) ≠ θ̃(x) or ξ(x) ≠ ξ̃(x)} (Hⁿ-null). For t with H^m(Z ∩ f⁻¹{t}) = 0 (a.e. t by NT) and φ_±(t) < ∞: g is H^m-integrable on M ∩ f⁻¹{t}, it agrees H^m-a.e. there with 1_{G≠0}θξ(ν♭∧ω), and since {G ≠ 0} is Borel and M ∩ f⁻¹{t} ∩ {G ≠ 0} = M_t (`setIntegral_indicator`), φ(t) = ∫_{M_t} θ(x)ξ(x)(ν(x)♭∧ω(x)) dH^m = ∫_{M_t} θ(x)ξ_t(x)(ω(x)) dH^m = tauAction m M_t θ ξ_t ω (the factor 1_K is irrelevant because ω = 0 off K, and ξ_t(x)(α) = ξ(x)(ν(x)♭∧α) by definition and `rfl`).
6. (Lebesgue points.) By the Lebesgue differentiation theorem (`IsUnifLocDoublingMeasure.ae_tendsto_average` for Lebesgue measure on ℝ, with centres t − ε/2, radii ε/2 and K = 1), for a.e. t: ε⁻¹∫_{t−ε}^{t} φ(r) dr → φ(t) as ε ↓ 0. Let F_ω be the union of the L¹-null sets of Steps 5 and 6; it depends only on (M, θ, ξ, f, G, ω).
7. (Cut-offs; Simon's ψ.) Fix t ∉ F_ω and S ∈ D_m(U) with IsSlice T f t S: there are A ∈ D_n(U), B ∈ D_m(U), a representation (μ, v) of T and a representation (μ', v') of ∂T with A(η) = ∫_{A_t} v(η) dμ, B(ϖ) = ∫_{A_t} v'(ϖ) dμ' for all test forms, A_t := {x ∈ U : f(x) < t} (Borel), and S(ϖ) = A(dϖ) − B(ϖ). Tangential-gradient property for (h_ε, G_ε): let x ∈ M satisfy TG(f, G) and lie outside the Hⁿ-null sets of Step 1 for c = t − ε and c = t, and let Q be a weighted tangent plane at x and u ∈ Q. Then G_ε(x) ∈ Q. If f(x) ∉ [t−ε, t], ψ_ε is constant near f(x) and f is continuous, so s ↦ h_ε(x+su) is constant near 0: derivative 0 = ⟨G_ε(x), u⟩. If t−ε < f(x) < t, ψ_ε is affine with slope −1/ε near f(x), so the derivative is −ε⁻¹⟨G(x), u⟩ = ⟨G_ε(x), u⟩ (chain rule). If f(x) ∈ {t−ε, t}, then G(x) = 0, so f(x+su) − f(x) = o(s) and |h_ε(x+su) − h_ε(x)| ≤ ε⁻¹|f(x+su) − f(x)| = o(s): derivative 0 = ⟨G_ε(x), u⟩.
8. (Apply the Leibniz identity; Simon's (2)–(4).) `lipschitz_leibniz` with (μ, v), (μ', v'), h = h_ε, L_h = L/ε, G_h = G_ε gives ∫ h_εv'(ω) dμ' − ∫ h_εv(dω) dμ = ∫_M θξ(G_ε♭∧ω) dHⁿ = −ε⁻¹∫_{M∩{t−ε<f<t}} θξ(G♭∧ω) dHⁿ = −ε⁻¹∫_{M∩{t−ε<f<t}} |G|g dHⁿ = −ε⁻¹∫_{t−ε}^{t} φ(r) dr (Steps 3 and 4; G_ε♭∧ω = −ε⁻¹1_{(t−ε,t)}(f)G♭∧ω by linearity).
9. (ε ↓ 0.) As ε ↓ 0, h_ε → 1_{f<t} pointwise on ℝ^P (if f(x) < t then h_ε(x) = 1 once ε ≤ t − f(x); if f(x) ≥ t then h_ε(x) = 0), with |h_ε| ≤ 1; v'(ω) ∈ L¹(μ'), v(dω) ∈ L¹(μ), and both vanish off K ⊆ U, so 1_{f<t}v'(ω) = 1_{A_t}v'(ω) and 1_{f<t}v(dω) = 1_{A_t}v(dω). Since F_ω does not depend on S, this proves: for a.e. t, every S with IsSlice T f t S satisfies S(ω) = tauAction m M_t θ ξ_t ω. ∎

2. Borel L¹ density g = 1_K1_{G≠0}θ̃ξ̃(ν♭∧ω) with θξ(G♭∧ω) = |G|g; Remark 4.2: ∫_{M∩{a<f<b}}|G|g = ∫_a^b φ, φ ∈ L¹(ℝ).

4. Piecewise-linear cut-off h_ε = ψ_ε∘f with tangential gradient −ε⁻¹1_{t−ε<f<t}G; the Leibniz sibling with the IsSlice representations.
5. ε ↓ 0: dominated convergence gives B(ω) − A(dω) = −φ(t), i.e. S(ω) = tauAction m M_t θ ξ_t ω.
