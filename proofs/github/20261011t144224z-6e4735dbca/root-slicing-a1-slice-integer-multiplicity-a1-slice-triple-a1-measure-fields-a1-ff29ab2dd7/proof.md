## Proof

Conventions. ℝ^k = Eucl k = EuclideanSpace ℝ (Fin k), with inner product ⟨·,·⟩ and norm |·|. Hᵏ := μHE[k] (Mathlib's Euclidean Hausdorff measure on ℝ^P; on ℝᵏ it equals Lebesgue measure Lᵏ = volume, and H⁰ is counting measure). L¹ := volume on ℝ. For a measure μ and a set S, μ⌞S := μ.restrict S, and 'p holds μ-a.e. on S' means ∀ᵐ x ∂(μ⌞S), p x. n := m + 1. M_t := {x ∈ M : f(x) = t, G(x) ≠ 0}. For v ∈ ℝ^P, ι(v) := (alternatizeUncurryFinCLM ℝ ℝ^P ℝ) ∘L (smulRightL ℝ ℝ^P Λ^m (innerSL ℝ v)) : Λ^m → Λ^{m+1}; by `rfl` ι(v)α = alternatizeUncurryFin((innerSL ℝ v).smulRight α) =: v♭∧α, and by `alternatizeUncurryFin_apply` (v♭∧α)(v₀,…,v_m) = Σ_{i=0}^{m} (−1)^i ⟨v, v_i⟩ α(v₀,…,v̂_i,…,v_m). ξ_t(x) := ξ(x) ∘L ι(|G(x)|⁻¹G(x)). (CA) denotes the co-area hypothesis for (M, f, G): for every Borel g : ℝ^P → [0, ∞], t ↦ ∫_{M∩f⁻¹{t}} g dH^m is L¹-a.e.-measurable and ∫_ℝ ∫_{M∩f⁻¹{t}} g dH^m dt = ∫_M |G|ₑ g dHⁿ; it is verbatim the conclusion of slicing_im_coarea, the sibling on which the parent node slicing_im_slice_triple depends, and enters here as a hypothesis because children may depend only on their own siblings. TG(f, G) denotes the tangential-gradient property: for Hⁿ-a.e. x ∈ M and every subspace Q with HasWeightedApproximateTangentSpaceAt n M θ x Q, G(x) ∈ Q and s ↦ f(x + su) has derivative ⟨G(x), u⟩ at s = 0 for every u ∈ Q.
This is Steps 2, 4, 5 and 6 of the parent proof (slicing_im_slice_triple).
0. (Null transfer.) The sibling ae_transfer (slicing_im_st_ae_transfer), applied to (P, m, M, f, G) and (CA), gives (NT): if a predicate p holds Hⁿ⌞M-a.e., then for L¹-a.e. t it holds H^m⌞(M ∩ f⁻¹{t})-a.e., hence also H^m⌞S-a.e. for every S ⊆ M ∩ f⁻¹{t} (ae_restrict_of_ae_restrict_of_subset), in particular for S = M_t and S = M_t ∩ K. Countably many statements 'for L¹-a.e. t' combine (ae_all_iff).
1. (Exhaustion of U.) Let (B̄_k)_{k∈ℕ} enumerate the closed balls closedBall(q, ρ) with q ∈ ℚ^P, ρ ∈ ℚ, ρ > 0 and closedBall(q, ρ) ⊆ U (if there are none, U = ∅ and all K_i := ∅), and put K_i := ⋃_{k≤i} B̄_k. Each K_i is compact and K_i ⊆ U. Every x ∈ U lies in the open ball ball(q_k, ρ_k) of some B̄_k: choose r > 0 with ball(x, 2r) ⊆ U, then q rational with |q − x| < r/2 and ρ rational in (r/2, r). Hence every compact K ⊆ U is covered by finitely many of these open balls, so K ⊆ K_N for the largest index N used, and ⋃_i K_i = U. (Do not use K_i := {x : |x| ≤ i, dist(x, ℝ^P ∖ U) ≥ 1/i}: in Lean, infDist to the empty set is 0, so for U = ℝ^P these sets would be empty.)
2. (Borel modifications.) By the field integrableOn, θ is Hⁿ-integrable, hence Hⁿ⌞(M ∩ K_i)-a.e. strongly measurable, for every i. Since M ⊆ U = ⋃_i K_i, M = ⋃_i (M ∩ K_i), so θ is Hⁿ⌞M-a.e. strongly measurable (aestronglyMeasurable_iUnion_iff). Choose a strongly measurable θ̃ : ℝ^P → ℝ with θ̃ ≥ 0 and θ = θ̃ Hⁿ⌞M-a.e.: take the AEStronglyMeasurable.mk version θ₀ of θ (ae_eq_mk) and θ̃ := max(θ₀, 0), which is still strongly measurable and equals θ Hⁿ⌞M-a.e. because θ > 0 on M (field pos). Also, by the field aestronglyMeasurable, a strongly measurable ξ̃ : ℝ^P → Λ_n with ξ = ξ̃ Hⁿ⌞M-a.e. By the field nullMeasurableSet choose a measurable B ⊆ M with Hⁿ(M ∖ B) = 0 (NullMeasurableSet.exists_measurable_subset_ae_eq). Then the predicate p₁(x) :⟺ (x ∈ B ∧ θ(x) = θ̃(x) ∧ ξ(x) = ξ̃(x)) holds Hⁿ⌞M-a.e.; for the first conjunct, (Hⁿ⌞M){x ∉ B} = Hⁿ(M ∖ B) = 0 (Measure.restrict_apply₀').
3. (Transfer.) By (NT), for L¹-a.e. t, p₁ holds H^m⌞(M ∩ f⁻¹{t})-a.e.
4. (Finite slice integrals of θ̃.) Fix i. The function g_i := 1_{K_i}·ofReal∘θ̃ : ℝ^P → [0, ∞] is measurable. By (CA), J_i(t) := ∫_{M∩f⁻¹{t}} g_i dH^m is L¹-a.e.-measurable in t and
   ∫_ℝ J_i(t) dt = ∫_M |G|ₑ g_i dHⁿ ≤ L·∫_{M∩K_i} ofReal(θ̃) dHⁿ = L·∫_{M∩K_i} ofReal(θ) dHⁿ ≤ L·∫_{M∩K_i} |θ|ₑ dHⁿ < ∞,
   using |G| ≤ L, θ = θ̃ Hⁿ⌞M-a.e., and the integrability of θ on M ∩ K_i (field integrableOn with K := K_i). Hence J_i(t) < ∞ for L¹-a.e. t (ae_lt_top'). As K_i is measurable, J_i(t) = ∫_{M∩f⁻¹{t}∩K_i} ofReal(θ̃) dH^m (lintegral_indicator, Measure.restrict_restrict). By ae_all_iff, for L¹-a.e. t, J_i(t) < ∞ for all i simultaneously.
5. Fix t in the intersection of the full-measure sets of steps 3 and 4. We prove (a)–(c) for this t.
   (a) (nullMeasurableSet; parent Step 5.) M_t = (B ∩ f⁻¹{t} ∩ G⁻¹(ℝ^P ∖ {0})) ∪ ((M ∖ B) ∩ f⁻¹{t} ∩ G⁻¹(ℝ^P ∖ {0})). The first set is measurable (B measurable, f and G measurable). The second set is contained in Y := Bᶜ ∩ (M ∩ f⁻¹{t}), and H^m(Y) ≤ (H^m⌞(M ∩ f⁻¹{t}))(Bᶜ) = 0 by step 3 (Measure.le_restrict_apply). A union of a measurable set and an H^m-null set is H^m-null-measurable (MeasurableSet.nullMeasurableSet, NullMeasurableSet.of_null, NullMeasurableSet.union). So M_t is H^m-null-measurable.
   (b) (integrableOn; parent Step 4.) Let K ⊆ U be compact and choose i with K ⊆ K_i (step 1). Since M_t ∩ K_i ⊆ M ∩ f⁻¹{t}, step 3 gives θ = θ̃ H^m⌞(M_t ∩ K_i)-a.e.; θ̃ being strongly measurable, θ is H^m⌞(M_t ∩ K_i)-a.e. strongly measurable (AEStronglyMeasurable.congr). As θ = θ̃ ≥ 0 holds H^m⌞(M_t ∩ K_i)-a.e., |θ(x)|ₑ = ofReal(|θ̃(x)|) = ofReal(θ̃(x)) for H^m⌞(M_t ∩ K_i)-a.e. x, so
   ∫_{M_t∩K_i} |θ|ₑ dH^m = ∫_{M_t∩K_i} ofReal(θ̃) dH^m ≤ ∫_{M∩f⁻¹{t}∩K_i} ofReal(θ̃) dH^m = J_i(t) < ∞
   (lintegral_mono_set, using M_t ∩ K_i ⊆ M ∩ f⁻¹{t} ∩ K_i). Thus θ is H^m-integrable on M_t ∩ K_i, hence on the subset M_t ∩ K (IntegrableOn.mono_set).
   (c) (aestronglyMeasurable; parent Step 6.) First, v ↦ ι(v) ∈ (Λ^m →L Λ^{m+1}) is continuous. Do not argue this by viewing smulRightL ℝ ℝ^P Λ^m as a continuous map: at this Mathlib pin instance search fails on its codomain Λ^m →L (ℝ^P →L Λ^m). Instead: by rfl and alternatizeUncurryFin_apply, (ι(v)α)(σ) = Σ_i (−1)^i ⟨v, σ_i⟩ α(removeNth i σ). Hence ι(v) − ι(w) = ι(v − w) (ext; inner_sub_left, sub_mul, smul_sub, Finset.sum_sub_distrib), and ‖ι(u)‖ ≤ (m+1)|u| (ContinuousLinearMap.opNorm_le_bound together with ContinuousAlternatingMap.norm_alternatizeUncurryFin_le, ContinuousLinearMap.norm_smulRight_apply and innerSL_apply_norm). So ι is (m+1)-Lipschitz (LipschitzWith.of_dist_le_mul), hence continuous. The map ν(x) := |G(x)|⁻¹G(x) is measurable (G measurable; Measurable.norm, Measurable.inv, Measurable.smul), hence strongly measurable into ℝ^P, and x ↦ ι(ν(x)) is strongly measurable (Continuous.comp_stronglyMeasurable). Composition (A, B) ↦ A ∘L B, from (Λ^{m+1} →L ℝ) × (Λ^m →L Λ^{m+1}) to Λ^m →L ℝ, is continuous (isBoundedBilinearMap_comp.continuous). So ξ̃_t(x) := ξ̃(x) ∘L ι(ν(x)) is strongly measurable (StronglyMeasurable.prodMk, then Continuous.comp_stronglyMeasurable). This route has been compiled at this pin. By step 3 and M_t ⊆ M ∩ f⁻¹{t}, ξ = ξ̃ holds H^m⌞M_t-a.e., and at every such x, ξ_t(x) = ξ̃_t(x). Hence ξ_t = ξ̃_t H^m⌞M_t-a.e. and ξ_t is H^m⌞M_t-a.e. strongly measurable (AEStronglyMeasurable.congr).
6. (a)–(c) hold for every t in a set of full L¹-measure, which proves the claim. ∎

## Key steps

1. Null transfer through the sibling ae_transfer: Hⁿ-a.e. properties on M hold H^m-a.e. on M ∩ f⁻¹{t} ⊇ M_t for a.e. t.
2. Compact exhaustion K_i of U, Borel versions θ̃, ξ̃ of θ, ξ, and a Borel B ⊆ M with Hⁿ(M ∖ B) = 0.
3. Co-area with g_i = 1_{K_i}·ofReal(θ̃) and |G| ≤ L: the slice integrals ∫_{M∩f⁻¹{t}∩K_i} θ̃ dH^m are finite for all i and a.e. t.
4. M_t = (Borel set) ∪ (H^m-null set) is null-measurable; θ = θ̃ a.e. on M_t ∩ K_i gives integrability on M_t ∩ K.
5. ξ_t = ξ̃ ∘ ι(G/|G|) a.e. on M_t, a strongly measurable map, gives a.e. strong measurability of ξ_t.
