## Proof

Source. Step 8 of the parent proof (uniqueness, step 3). Both measures vanish off U and are locally finite Borel measures on the σ-compact open set U, hence regular there; so agreement on the open subsets of U gives agreement on all Borel sets. Details written out here.

1. Exhaustion of U. There are open sets W_1 ⊆ W_2 ⊆ … with W̄_j compact, W̄_j ⊆ U and ⋃_j W_j = U. For example W_j := {x : |x| < j, dist(x, ℝ^N ∖ U) > 1/j}, dropping the second condition if U = ℝ^N. Each W_j is open, and W̄_j ⊆ {x : |x| ≤ j, dist(x, ℝ^N ∖ U) ≥ 1/j}, which is compact and contained in U. Every x ∈ U lies in W_j for j large. Then μ(W_j) ≤ μ(W̄_j) < ∞, and μ'(W_j) = μ(W_j) since W_j is an open subset of U.

2. Agreement on W_j. Fix j and let μ_j := μ⌞W_j and μ'_j := μ'⌞W_j, i.e. μ_j(B) = μ(B ∩ W_j) and μ'_j(B) = μ'(B ∩ W_j). These are finite Borel measures on ℝ^N. For every open V ⊆ ℝ^N, V ∩ W_j is an open subset of U, so μ_j(V) = μ(V ∩ W_j) = μ'(V ∩ W_j) = μ'_j(V). In particular μ_j(ℝ^N) = μ'_j(ℝ^N) < ∞. The open sets form a π-system (closed under finite intersections) that generates the Borel σ-algebra of ℝ^N. So by the uniqueness theorem for finite measures agreeing on a generating π-system, μ_j = μ'_j. (This is Dynkin's π-λ theorem; in Mathlib, ext_of_generate_finite, using that the Borel σ-algebra is by definition generated by the open sets — Mathlib borel and BorelSpace.measurable_eq — and isPiSystem_isOpen.) Equivalently, finite Borel measures on a metric space are outer regular and therefore determined by their values on open sets; this is the regularity invoked in the parent proof.

3. Agreement on U. For every Borel set B, the sets B ∩ W_j increase to B ∩ U. By continuity from below and step 2,
μ(B ∩ U) = lim_j μ(B ∩ W_j) = lim_j μ_j(B) = lim_j μ'_j(B) = lim_j μ'(B ∩ W_j) = μ'(B ∩ U).

4. Conclusion. For every Borel B, μ(B ∖ U) ≤ μ(ℝ^N ∖ U) = 0, and similarly μ'(B ∖ U) = 0. So μ(B) = μ(B ∩ U) + μ(B ∖ U) = μ'(B ∩ U) + μ'(B ∖ U) = μ'(B). Two measures on the Borel σ-algebra that agree on every measurable set are equal: μ = μ'.

## Key steps

1. Exhaust U by open sets W_j with compact closures in U; μ(W_j) = μ'(W_j) < ∞.
2. μ⌞W_j and μ'⌞W_j are finite Borel measures agreeing on all open sets, hence equal (π-system uniqueness / outer regularity).
3. Continuity from below gives μ(B ∩ U) = μ'(B ∩ U); both measures vanish off U, so μ = μ'.
