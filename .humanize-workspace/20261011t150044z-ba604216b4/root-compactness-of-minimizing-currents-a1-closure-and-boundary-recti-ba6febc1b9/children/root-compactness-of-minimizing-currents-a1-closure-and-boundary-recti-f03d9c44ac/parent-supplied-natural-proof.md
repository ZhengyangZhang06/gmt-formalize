## Proof

Source: parent proof, V13 (Simon Ch. 3, Theorem 1.6 "⇐", chapter-03.txt lines 107–300, with the corrected constant ε := 2^{−1}16^{−n} needed for the contradiction in (10)). The parent's iteration "A ∖ ⋃F_k(ℝⁿ)" is replaced by running the same construction with an arbitrary error ε' > 0 (step 10), so that no locality of approximate tangent spaces for subsets is needed. Hⁿ := μHE[n], μ := Hⁿ⌞M (a finite Borel measure), p_V := orthogonal projection onto a subspace V (starProjection), ‖·‖ the operator norm, ω_n := Lⁿ(B_1).

0. Trivial cases. If Hⁿ(M) = 0, M is countably n-rectifiable (SimonGMT countablyRectifiable_of_measure_zero). If n = 0: H⁰ is the counting measure, so H⁰(M) < ∞ means M is finite; each point is the range of a constant (Lipschitz) map ℝ⁰ → ℝ^P (SimonGMT countablyRectifiable_range, countablyRectifiable_iUnion). If n > P: μHE[n] = 0 on ℝ^P (Mathlib MeasureTheory.Measure.euclideanHausdorffMeasure_zero_or_top with d₁ := P, d₂ := n, using that μHE[P] = Lebesgue measure is σ-finite: every bounded set has finite μHE[P]-measure, hence μHE[n]-measure 0), so Hⁿ(M) = 0. If n = P: M ⊆ ℝ^P = range of the identity of Euclid P (Lipschitz). Henceforth 1 ≤ n < P, ℓ := P − n ≥ 1, and HasApproximateTangentSpaceAt n M x Q(x) holds for μ-a.e. x (so dim Q(x) = n and π_x := Q(x)^⊥ has dimension ℓ).
1. Cones. For an ℓ-dimensional subspace π and α > 0 let X_α(π, x) := {y : dist(y − x, π) < α|y − x|} (open; x ∉ X_α(π, x)). Recall dist(v, π) = |v − p_π v|, so |dist(v, π) − dist(v, π')| ≤ ‖p_π − p_{π'}‖ |v|.
2. Densities at tangent points. Let x satisfy HasApproximateTangentSpaceAt n M x Q(x). Write ν_ρ := Hⁿ⌞(blowUpMap x ρ '' M), blowUpMap x ρ (y) = ρ⁻¹(y − x). By translation invariance and scaling of Hⁿ, ν_ρ(S) = ρ^{−n}μ(x + ρS). The definition says ∫ f dν_ρ → ∫ f dHⁿ⌞Q(x) as ρ ↓ 0 for all f ∈ C_c(ℝ^P). Approximating indicators by continuous compactly supported functions from below (open bounded sets O) and from above (compact sets F'): liminf ν_ρ(O) ≥ Hⁿ(Q(x) ∩ O), limsup ν_ρ(F') ≤ Hⁿ(Q(x) ∩ F'). With O := B_1, F' := B̄_1 and Hⁿ(Q(x) ∩ ∂B_1) = 0: (5) μ(B_ρ(x))/(ω_nρⁿ) → Hⁿ(Q(x) ∩ B_1)/ω_n = 1. With F' := X̄ ∩ B̄_1, X̄ := {y : dist(y, π_x) ≤ |y|/2} (closed), we have F' ∩ Q(x) = {0} (for v ∈ Q(x), dist(v, π_x) = |v|) and Hⁿ({0}) = 0 (n ≥ 1), so (6) μ(X_{1/2}(π_x, x) ∩ B_ρ(x))/(ω_nρⁿ) ≤ ν_ρ(F')/ω_n → 0.
3. Fix ε' > 0. Lusin. The map x ↦ p_{Q(x)} is μ-a.e. strongly measurable, hence μ-a.e. equal to a Borel map q; let M₁ ⊆ M be a Borel set of full μ-measure on which q(x) = p_{Q(x)} and HasApproximateTangentSpaceAt n M x Q(x) hold. μ is a finite Borel measure on ℝ^P, hence closed-inner regular; applying SimonGMT Chapter01 exists_isClosed_continuousOn_of_measurable to the finitely many matrix entries of q on M₁ and intersecting the closed sets obtained, we get a closed F ⊆ M₁ with μ(M ∖ F) ≤ ε'/4 on which x ↦ p_{Q(x)} (hence x ↦ p_{π_x} = I − p_{Q(x)}) is continuous; (5) and (6) hold at every x ∈ F.
4. Egorov. For x ∈ F and k ≥ 1 put f_k(x) := inf_{ρ∈ℚ∩(0,1/k)} μ(B_ρ(x))/(ω_nρⁿ) and q_k(x) := sup_{ρ∈ℚ∩(0,1/k)} μ(X_{1/2}(π_x, x) ∩ B_ρ(x))/(ω_nρⁿ). For fixed ρ, x ↦ μ(B_ρ(x)) is lower semicontinuous and, on F, x ↦ μ(X_{1/2}(π_x, x) ∩ B_ρ(x)) is lower semicontinuous (the set {(x, y) ∈ F × ℝ^P : dist(y − x, π_x) < |y − x|/2, |y − x| < ρ} is relatively open by continuity of x ↦ p_{π_x}; Fatou); countable infima/suprema of semicontinuous functions are Borel. Both quotients are left continuous in ρ (open balls and open cones increase to their union), so f_k and q_k are also the inf/sup over all ρ ∈ (0, 1/k); by (5), (6), f_k → 1 and q_k → 0 pointwise on F. Extend f_k, q_k by 0 off the closed set F (so they are Borel on ℝ^P). By Egorov's theorem (Mathlib MeasureTheory.tendstoUniformlyOn_of_ae_tendsto for the finite measure μ⌞F) and closed inner regularity, there is a closed E₁ ⊆ F with μ(F ∖ E₁) ≤ ε'/4 on which the convergence is uniform. Choose R₀ with μ(ℝ^P ∖ B̄_{R₀}(0)) ≤ ε'/4 and put E := E₁ ∩ B̄_{R₀}(0): E is compact and μ(M ∖ E) ≤ 3ε'/4 < ε'.
5. Uniform density bounds. Let ε := 2^{−1}16^{−n}. By uniform convergence there is δ > 0 such that for all x ∈ E and 0 < ρ < δ: μ(B_ρ(x)) ≥ (1 − ε)ω_nρⁿ and μ(X_{1/2}(π_x, x) ∩ B_ρ(x)) ≤ εω_nρⁿ.
6. Net of planes. The set of orthogonal projections of rank ℓ is compact in the space of linear maps, so there are ℓ-dimensional subspaces π_1, …, π_N such that every ℓ-dimensional π has ‖p_π − p_{π_j}‖ < 1/16 for some j. Put E_j := {x ∈ E : ‖p_{π_j} − p_{π_x}‖ < 1/16}; E = ⋃_jE_j.
7. Claim (10): for x ∈ E_j, X_{1/4}(π_j, x) ∩ E_j ∩ B_{δ/2}(x) = ∅. Otherwise pick y in it; y ≠ x and σ := |y − x| ∈ (0, δ/2). For z ∈ B_{σ/8}(y): dist(z − x, π_x) ≤ dist(y − x, π_x) + |z − y| ≤ dist(y − x, π_j) + ‖p_{π_j} − p_{π_x}‖σ + σ/8 < σ/4 + σ/16 + σ/8 = 7σ/16, while |z − x| > σ − σ/8 = 7σ/8; so dist(z − x, π_x) < |z − x|/2, and |z − x| < 9σ/8 < 2σ. Thus B_{σ/8}(y) ⊆ X_{1/2}(π_x, x) ∩ B_{2σ}(x). Since y, x ∈ E and σ/8, 2σ < δ, step 5 gives (1 − ε)ω_n(σ/8)ⁿ ≤ μ(B_{σ/8}(y)) ≤ μ(X_{1/2}(π_x, x) ∩ B_{2σ}(x)) ≤ εω_n(2σ)ⁿ, i.e. 1 − ε ≤ 16ⁿε = 1/2, contradicting ε ≤ 1/32. (With Simon's printed ε = 16^{−n} the right side would be 1 and there would be no contradiction; this is the documented erratum.)
8. Lipschitz graphs. Fix j and x₀ ∈ ℝ^P and let D := E_j ∩ B_{δ/4}(x₀), p_j := p_{π_j^⊥} (projection onto the n-plane π_j^⊥). For x, y ∈ D, |x − y| < δ/2, so by (10) y ∉ X_{1/4}(π_j, x) unless y = x, i.e. |p_j(y − x)| = dist(y − x, π_j) ≥ |y − x|/4. Hence p_j is injective on D and h : p_j(D) → π_j, h(p_j x) := p_{π_j}x, is 4-Lipschitz. Extend h to a Lipschitz map h̃ : π_j^⊥ → π_j (coordinates in an orthonormal basis of π_j and McShane extension of each coordinate, Mathlib LipschitzOnWith.extend_real / LipschitzOnWith.extend_pi; constant ≤ 4√ℓ). With a linear isometry ι : ℝⁿ → π_j^⊥, F_{j,x₀}(u) := ι(u) + h̃(ι(u)) is Lipschitz and D ⊆ F_{j,x₀}(ℝⁿ) (x = p_jx + p_{π_j}x).
9. Finite cover. E is compact, so finitely many balls B_{δ/4}(x₀^{(s)}) cover it; the finitely many Lipschitz maps F_{j,x₀^{(s)}} cover ⋃_{j,s}(E_j ∩ B_{δ/4}(x₀^{(s)})) = E. Therefore μ(M ∖ ⋃_{j,s}F_{j,x₀^{(s)}}(ℝⁿ)) ≤ μ(M ∖ E) < ε'.
10. Conclusion. Applying steps 3–9 with ε' := 1/m for each m ≥ 1 yields countably many Lipschitz maps (F_k)_{k∈ℕ}, ℝⁿ → ℝ^P, such that M₀ := M ∖ ⋃_kF_k(ℝⁿ) satisfies Hⁿ(M₀) ≤ 1/m for all m, i.e. Hⁿ(M₀) = 0. Since M ⊆ M₀ ∪ ⋃_kF_k(ℝⁿ), M is countably n-rectifiable (definition CountablyRectifiable). ∎

## Key steps

1. Dispose of Hⁿ(M) = 0, n = 0, n > P and n = P.
2. At tangent points, μ = Hⁿ⌞M has density 1 and vanishing density in the cone X_{1/2}(Q(x)^⊥, x).
3. Lusin and Egorov give a compact E ⊆ M with μ(M∖E) < ε', continuous x ↦ Q(x) on E and uniform density estimates below δ.
4. With ε := 2^{−1}16^{−n} and a finite 1/16-net of ℓ-planes, the cone condition (10) holds on each E_j.
5. Hence each E_j ∩ B_{δ/4}(x₀) is a 4-Lipschitz graph over π_j^⊥, extendable to a Lipschitz map ℝⁿ → ℝ^P; finitely many cover E.
6. Taking ε' = 1/m for all m covers M by countably many Lipschitz images up to an Hⁿ-null set.
