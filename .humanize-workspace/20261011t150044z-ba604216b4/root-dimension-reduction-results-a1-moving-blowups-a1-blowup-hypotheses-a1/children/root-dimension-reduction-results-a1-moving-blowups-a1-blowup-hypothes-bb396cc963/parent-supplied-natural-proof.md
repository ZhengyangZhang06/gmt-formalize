## Proof

Source: Part III (RET) of the selected node's supplied proof. It replaces the nearest-point projection onto N used for the compactness theorem with constraint (Simon 7.2.5(2), chapter-07.txt lines 166–174) by an explicit graph retraction, which agrees with the nearest-point projection to first order at x; embedded submanifolds are as in Simon Ch. 2, §4 (4.1) (IsEmbeddedSubmanifold). No dependencies. Mathlib tools: the inverse function theorem (ContDiffAt.toOpenPartialHomeomorph, ContDiffAt.localInverse, ContDiffAt.to_localInverse, OpenPartialHomeomorph.contDiffAt_symm), orthogonal projections (Submodule.starProjection, Submodule.starProjection_norm_le), LinearEquiv.ofInjective, and the mean value inequality (Convex.norm_image_sub_le_of_norm_fderiv_le).
Notation: B_s(y) := ball y s ⊆ ℝ^P = Euclid P; B^d_s(0) := ball 0 s ⊆ ℝ^d = Euclid d; Df(v) := fderiv ℝ f v; ‖·‖ the operator norm.
1. (Chart at x.) Since x ∈ N, IsEmbeddedSubmanifold 2 d N gives an open V ⊆ ℝ^d, an open W ⊆ ℝ^P with x ∈ W, and ψ : ℝ^d → ℝ^P which is C² on V and injective on V, with ψ(V) = W ∩ N, V ∩ ψ⁻¹(K) compact for every compact K ⊆ W, and Dψ(v) injective for every v ∈ V. As x ∈ W ∩ N = ψ(V), choose v₀ ∈ V with ψ(v₀) = x. Since V is open and ψ is C² on V, ψ is differentiable at every point of V and Dψ is continuous on V. Put L := Dψ(v₀) : ℝ^d → ℝ^P, an injective continuous linear map; Q := L(ℝ^d), a (closed, finite-dimensional) subspace; L₀ : ℝ^d ≅ Q the linear isomorphism induced by L (LinearEquiv.ofInjective), continuous in finite dimension. Let p : ℝ^P → ℝ^P be the orthogonal projection onto Q (Q.starProjection): p is continuous linear, ‖p‖ ≤ 1, and p(q) = q for q ∈ Q. Define A := L₀⁻¹∘p : ℝ^P → ℝ^d (continuous linear; p regarded with values in Q). Then A(Lw) = L₀⁻¹(Lw) = w for w ∈ ℝ^d, i.e. A∘L = id, and L∘A = p.
2. (Local inverse.) Define h : ℝ^d → ℝ^d, h(v) := A(ψ(v) − x). Then h is C² on V (ψ followed by an affine map), h(v₀) = A(0) = 0, and Dh(v₀) = A∘Dψ(v₀) = A∘L = id. By the inverse function theorem there is an open set V₀ with v₀ ∈ V₀ ⊆ V such that O := h(V₀) is open, h maps V₀ bijectively onto O, and the inverse k : O → V₀ is C¹ on O with Dk(h(v)) = Dh(v)⁻¹ (shrinking V₀ we may assume Dh(v) is invertible for every v ∈ V₀, invertibility being an open condition and Dh continuous; then OpenPartialHomeomorph.contDiffAt_symm shows that k is C¹ at every point of O). Thus k(h(v)) = v for v ∈ V₀, k(u) ∈ V₀ and h(k(u)) = u for u ∈ O, 0 = h(v₀) ∈ O, k(0) = v₀ and Dk(0) = Dh(v₀)⁻¹ = id.
3. (Graph parametrization.) Φ := ψ∘k : O → ℝ^P is C¹ on O (k is C¹ on O with values in V₀ ⊆ V, where ψ is C²); Φ(0) = ψ(v₀) = x; Φ(O) = ψ(k(O)) = ψ(V₀) ⊆ ψ(V) ⊆ N; and DΦ(0) = Dψ(v₀)∘Dk(0) = L∘id = L.
4. (ψ(V₀) is relatively open in N.) Let F := V ∖ V₀. Claim: if y ∈ W and y = lim_i ψ(f_i) with all f_i ∈ F, then y ∈ ψ(F). Indeed K := {y} ∪ {ψ(f_i) : i ∈ ℕ} is compact (a convergent sequence together with its limit) and K ⊆ W (ψ(f_i) ∈ ψ(V) ⊆ W), so all f_i lie in the compact set V ∩ ψ⁻¹(K), and a subsequence f_{i_l} converges to some f ∈ V ∩ ψ⁻¹(K). As f_{i_l} ∉ V₀ and V₀ is open, f ∉ V₀, so f ∈ F; ψ is continuous at f ∈ V (V open), so ψ(f) = lim ψ(f_{i_l}) = y. Hence W ∩ closure(ψ(F)) = ψ(F) (recall ψ(F) ⊆ W), and W₀ := W ∖ ψ(F) = W ∩ (ℝ^P ∖ closure ψ(F)) is open. x ∈ W₀: x ∈ W, and if x = ψ(f) with f ∈ F ⊆ V then f = v₀ by injectivity of ψ on V, contradicting v₀ ∈ V₀. Finally W₀ ∩ N = ψ(V₀): if y ∈ W₀ ∩ N ⊆ W ∩ N = ψ(V), then y = ψ(v) with v ∈ V and v ∉ F (otherwise y ∈ ψ(F)), so v ∈ V₀; conversely ψ(V₀) ⊆ ψ(V) = W ∩ N, and ψ(V₀) ∩ ψ(F) = ∅ by injectivity of ψ on V (V₀ ∩ F = ∅).
5. (Choice of δ and π.) O is open and 0 ∈ O: choose r₀ > 0 with B^d_{r₀}(0) ⊆ O. W₀ is open and x ∈ W₀: choose δ > 0 with B_δ(x) ⊆ W₀ and ‖A‖·δ < r₀ (e.g. also δ < r₀/(‖A‖ + 1)). Define π : ℝ^P → ℝ^P by π(y) := Φ(A(y − x)) for y ∈ B_δ(x) and π(y) := y otherwise. For y ∈ B_δ(x), |A(y − x)| ≤ ‖A‖·|y − x| ≤ ‖A‖·δ < r₀, so A(y − x) ∈ B^d_{r₀}(0) ⊆ O.
6. ((i)–(iii).) (i) On the open ball B_δ(x), π coincides with Φ∘a, where a(y) := A(y − x) is affine (C^∞) and maps B_δ(x) into O, on which Φ is C¹; hence π is C¹ on B_δ(x) (ContDiffOn.comp, ContDiffOn.congr). (ii) For y ∈ B_δ(x), π(y) = Φ(A(y − x)) ∈ Φ(O) ⊆ N, so π maps B_δ(x) into N. (iii) If y ∈ N ∩ B_δ(x), then y ∈ N ∩ W₀ = ψ(V₀) by step 4, so y = ψ(v) with v ∈ V₀; then A(y − x) = h(v) ∈ O and π(y) = ψ(k(h(v))) = ψ(v) = y. In particular π(x) = x.
7. ((iv).) π is C¹ on the open set B_δ(x), so π is differentiable at every y ∈ B_δ(x) and Dπ is continuous on B_δ(x) (ContDiffOn.continuousOn_fderiv_of_isOpen). By the chain rule (π = Φ∘a on a neighbourhood of y), Dπ(y) = DΦ(A(y − x))∘A for y ∈ B_δ(x); hence Dπ(x) = DΦ(0)∘A = L∘A = p and ‖Dπ(x)‖ ≤ 1. Let η > 0. By continuity of Dπ at x there is s with 0 < s ≤ δ and ‖Dπ(y) − Dπ(x)‖ ≤ η for all y ∈ B_s(x); then ‖Dπ(y)‖ ≤ ‖Dπ(x)‖ + η ≤ 1 + η on B_s(x). The ball B_s(x) is convex and π is differentiable on it, so the mean value inequality gives |π(y) − π(z)| ≤ (1 + η)|y − z| for all y, z ∈ B_s(x).
8. (Conclusion.) δ > 0 and π satisfy: π is C¹ on B_δ(x) (step 6(i)); π maps B_δ(x) into N (step 6(ii)); π(y) = y for y ∈ N ∩ B_δ(x) (step 6(iii)); and for every η > 0 there is s ∈ (0, δ] such that |π(y) − π(z)| ≤ (1 + η)|y − z| for all y, z ∈ B_s(x) (step 7). The case d = 0 is included: ℝ⁰ is a point, L = 0 is injective, Q = {0}, p = 0, A = 0, Φ ≡ x, π ≡ x on B_δ(x), and N ∩ B_δ(x) ⊆ ψ(V₀) = {x} by step 4. ∎

## Key steps

1. Take a chart ψ at x with ψ(v₀) = x, L := Dψ(v₀) injective, p the orthogonal projection onto Q = range L, and A := L⁻¹∘p (A∘L = id, L∘A = p).
2. The inverse function theorem for h := A(ψ − x) at v₀ gives V₀ ∋ v₀, O = h(V₀) ∋ 0 and a C¹ inverse k; Φ := ψ∘k parametrizes ψ(V₀) ⊆ N with DΦ(0) = L.
3. Properness of the chart makes ψ(V₀) relatively open in N: N ∩ W₀ = ψ(V₀) for an open W₀ ∋ x.
4. π(y) := Φ(A(y − x)) on a small B_δ(x) is C¹, maps into N, fixes N ∩ B_δ(x), and Dπ(x) = p has norm ≤ 1; continuity of Dπ and the mean value inequality give (1 + η)-Lipschitz bounds on small balls.
