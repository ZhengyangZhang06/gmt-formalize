## Proof

Source: step 6 of the selected proof ('|DH_i(u)v| ≤ Λ|DG_i(u)v| … JH_i ≤ Λ^kJG_i' and 'the derivative of a Lipschitz map at a density point of a set is determined by its values on that set') and the Jacobian bound used in step 7 (Simon Ch. 6, 2.29: M(f_#T) ≤ (ess sup |Df|)ⁿ M(T), and Ch. 2, 3.3–3.5). Notation: Lᵏ := volume on ℝᵏ; Hᵏ := μHE[k]; for a linear T on ℝᵏ, J(T) := (det[⟨Te_a, Te_b⟩])^{1/2}, so J_H(u) = J(DH(u)).
Part (i).
1. Let L := D(F∘G)(u) and M := DG(u). Claim: |Lv| ≤ Λ|Mv| for every v ∈ ℝᵏ. If F∘G is not differentiable at u, then L = 0 (fderiv_zero_of_not_differentiableAt) and the claim is trivial. Otherwise, for t > 0, |F(G(u + tv)) − F(G(u))| ≤ Λ|G(u + tv) − G(u)|; dividing by t and letting t → 0⁺, the left side tends to |Lv| and the right side to Λ|Mv| (both maps are differentiable at u; HasFDerivAt.lim or the little-o expansion along the ray), so |Lv| ≤ Λ|Mv|.
2. If L is not injective, choose c ≠ 0 with Lc = 0; writing c = Σ_b c_b e_b, Σ_b c_b Le_b = 0, so the Gram matrix Γ_L := [⟨Le_a, Le_b⟩] satisfies Γ_L·(c_b)_b = 0 with (c_b) ≠ 0, hence det Γ_L = 0 (Matrix.exists_mulVec_eq_zero_iff) and J(L) = 0 ≤ Λᵏ·J(M) (J(M) ≥ 0 as a square root). (For k = 0 both Gram matrices are empty, J(L) = J(M) = 1 and Λ⁰ = 1.)
3. Suppose L is injective. Then M is injective (Mv = 0 ⇒ |Lv| ≤ 0 ⇒ v = 0). Let S := closedBall (0 : ℝᵏ) 1, so 0 < Lᵏ(S) < ∞. A continuous linear injective map T is differentiable everywhere with fderiv ℝ T x = T (ContinuousLinearMap.fderiv) and injective on S, so the sibling gram_area_formula (codim1_lura_gram_area_formula) with f := T, s := S, g ≡ 1 gives Hᵏ(T(S)) = ∫⁻_S ofReal(J(T)) dLᵏ = ofReal(J(T))·Lᵏ(S). Apply this to T = L and T = M.
4. Let λ : ℝ^N →ₗ ℝᵏ be a linear left inverse of the injective M (LinearMap.exists_leftInverse_of_injective) and A := L ∘ λ. For y = Mv, y' = Mv' ∈ M(S): |A(y) − A(y')| = |L(v − v')| ≤ Λ|M(v − v')| = Λ|y − y'| (step 1), so A is Λ-Lipschitz on M(S), and A(M(S)) = L(S). By the Lipschitz image bound (SimonGMT Chapter02 euclideanHausdorffMeasure_image_le_of_lipschitzOn), Hᵏ(L(S)) ≤ Λᵏ·Hᵏ(M(S)). By step 3, ofReal(J(L))·Lᵏ(S) ≤ Λᵏ·ofReal(J(M))·Lᵏ(S); cancelling 0 < Lᵏ(S) < ∞ and using J ≥ 0 gives J(L) ≤ Λᵏ·J(M), i.e. J_{F∘G}(u) ≤ Λᵏ·J_G(u).
Part (ii).
5. D := H − H' is Lipschitz and continuous, so E := B ∩ {u : D(u) = 0} is Borel and Lᵏ(B ∖ E) = 0 (hypothesis). By Rademacher (LipschitzWith.ae_differentiableAt) H, H' and D are differentiable Lᵏ-a.e.; by the Lebesgue density theorem (Mathlib Besicovitch.ae_tendsto_measure_inter_div for Lᵏ and E), for (Lᵏ.restrict E)-a.e. u, Lᵏ(E ∩ B̄_r(u))/Lᵏ(B̄_r(u)) → 1 as r → 0⁺. Since Lᵏ.restrict B and Lᵏ.restrict E coincide (Lᵏ(B ∖ E) = 0, E ⊆ B), for (Lᵏ.restrict B)-a.e. u: u ∈ E, u is a density point of E, and H, H', D are differentiable at u.
6. At such u, DD(u) = 0. If k = 0 there is nothing to prove (ℝ⁰ = {0}). Let v be a unit vector and ε ∈ (0, 1). For all small t > 0 the open ball B_{εt}(u + tv) ⊆ B̄_{2t}(u) meets E: otherwise Lᵏ(E ∩ B̄_{2t}(u)) ≤ Lᵏ(B̄_{2t}(u)) − Lᵏ(B_{εt}(u + tv)) = (1 − (ε/2)ᵏ)·Lᵏ(B̄_{2t}(u)) (Haar scaling of balls, Measure.addHaar_ball / addHaar_closedBall), contradicting density 1 as t → 0⁺. Pick u_t ∈ E with |u_t − (u + tv)| < εt; then |u_t − u| < 2t and 0 = D(u_t) = D(u) + DD(u)(u_t − u) + o(t) = DD(u)(u_t − u) + o(t), so t|DD(u)v| ≤ |DD(u)(u_t − u)| + ‖DD(u)‖εt ≤ o(t) + ‖DD(u)‖εt. Dividing by t and letting t → 0⁺ gives |DD(u)v| ≤ ‖DD(u)‖ε for every ε ∈ (0, 1), hence DD(u)v = 0; as v was an arbitrary unit vector, DD(u) = 0.
7. Since H and H' are differentiable at u, DD(u) = DH(u) − DH'(u) (fderiv_sub). Hence DH(u) = DH'(u) for (Lᵏ.restrict B)-a.e. u. ∎

## Key steps

1. (i) |D(F∘G)(u)v| ≤ Λ|DG(u)v| from the difference quotients (or D(F∘G)(u) = 0 if F∘G is not differentiable at u).
2. (i) A non-injective linear map has singular Gram matrix, so J = 0; otherwise the area formula for linear maps gives Hᵏ(T(S)) = J(T)Lᵏ(S).
3. (i) L = A∘M with A Λ-Lipschitz on M(S); the Lipschitz image bound gives J(L)Lᵏ(S) ≤ ΛᵏJ(M)Lᵏ(S).
4. (ii) A.e. point of B is a density point of E = B ∩ {H = H'} where H, H', H − H' are differentiable (Rademacher, Lebesgue density).
5. (ii) At such a point every direction is approximated by points of E, so D(H − H')(u) = 0 and DH(u) = DH'(u).
