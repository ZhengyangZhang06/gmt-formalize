## Proof

Source: step 6 (V10, product structure) of the parent proof, for a general n-dimensional invariance subspace V (= V₀ there), with the measure σ of that step regarded as a measure on ℝ^P concentrated on V^⊥. Uses the sibling subspace_ball (accepted idtp_tdc_subspace_ball_measure): Hⁿ(Q ∩ B_ρ(y)) = ω_nρⁿ for an n-dimensional subspace Q, y ∈ Q, ρ > 0, where ω_n = unitBallVolume n.
Notation: p := V.starProjection, q := V^⊥.starProjection, so y = p y + q y, p y ∈ V, q y ∈ V^⊥, ‖y‖² = ‖p y‖² + ‖q y‖², and for t ∈ V: p(t + y) = t + p y, q(t + y) = q y. ω_n = vol(B_1(0) ⊆ ℝⁿ) ∈ (0, ∞) (a nonempty bounded open set). A rectangle is a set p⁻¹(A) ∩ q⁻¹(B) with A, B ⊆ ℝ^P Borel.
1. (Coordinates on V.) Let v_1, …, v_n be an orthonormal basis of V, L : ℝⁿ → ℝ^P, L(x) := Σ_bx_bv_b (a linear isometry onto V) and π : ℝ^P → ℝⁿ, π(y) := (⟨v_b, y⟩)_b (continuous linear). Then L(π(y)) = p y, π(L x) = x, π(t + y) = π(t) + π(y), and ‖π(y)‖ = ‖p y‖. By Isometry.map_euclideanHausdorffMeasure and EuclideanSpace.euclideanHausdorffMeasure_eq_volume, L_#vol = Hⁿ⌞(range L) = Hⁿ⌞V, i.e. vol(L⁻¹(A)) = Hⁿ(A ∩ V) for Borel A.
2. (Haar uniqueness for bounded B.) Fix a bounded Borel B ⊆ ℝ^P and let m_B := π_#(ν⌞q⁻¹(B)), a Borel measure on ℝⁿ with m_B(E) = ν(π⁻¹(E) ∩ q⁻¹(B)) for Borel E. (a) m_B is finite on compact sets: if E ⊆ B̄_R(0) and B ⊆ B̄_S(0), then π⁻¹(E) ∩ q⁻¹(B) ⊆ B̄_{R+S}(0), a compact set of finite ν-measure. (b) m_B is translation invariant: for x ∈ ℝⁿ and Borel E, π(L x + y) = x + π(y) and q(L x + y) = q y give {y : x + π(y) ∈ E, q y ∈ B} = {y : L x + y ∈ π⁻¹(E) ∩ q⁻¹(B)}; as L x ∈ V, the invariance of ν yields m_B({z : x + z ∈ E}) = ν(π⁻¹(E) ∩ q⁻¹(B)) = m_B(E). (c) By uniqueness of Haar measure (Measure.isAddLeftInvariant_eq_smul, Lebesgue measure being an additive Haar measure on ℝⁿ), m_B = κ_B·vol with κ_B = m_B.addHaarScalarFactor vol ∈ [0, ∞). Evaluating on the unit ball: κ_Bω_n = m_B(B_1(0)) = ν({y : ‖p y‖ < 1, q y ∈ B}).
3. (Definition of σ.) Let σ := ω_n⁻¹·q_#(ν⌞{y : ‖p y‖ < 1}), so σ(B) = ω_n⁻¹ν({y : ‖p y‖ < 1, q y ∈ B}) for Borel B. Then σ(ℝ^P∖V^⊥) = 0 because q y ∈ V^⊥ for every y; σ(K) < ∞ for compact K ⊆ B̄_S(0), because {y : ‖p y‖ < 1, q y ∈ K} ⊆ B̄_{1+S}(0); and κ_B = σ(B) for bounded Borel B by step 2(c).
4. (Rectangle formula.) For Borel A and bounded Borel B: p⁻¹(A) = π⁻¹(L⁻¹(A)), so ν(p⁻¹(A) ∩ q⁻¹(B)) = m_B(L⁻¹(A)) = σ(B)·vol(L⁻¹(A)) = σ(B)·Hⁿ(A ∩ V) by steps 1–3. For arbitrary Borel B apply this to B_j := B ∩ B_j(0), which increase to B, and pass to the limit by continuity from below on both sides (⨆_j(σ(B_j)·c) = (⨆_jσ(B_j))·c in [0, ∞], ENNReal.iSup_mul): ν(p⁻¹(A) ∩ q⁻¹(B)) = σ(B)·Hⁿ(A ∩ V) for all Borel A, B.
5. (The measure λ.) σ is σ-finite (finite on compact sets, ℝ^P σ-compact), which is what Measure.prod_apply needs (SFinite σ); Hⁿ⌞V = L_#vol is σ-finite as well (Hⁿ(V ∩ B_j(0)) = ω_njⁿ < ∞ by subspace_ball). Let λ := s_#((Hⁿ⌞V) ⊗ σ) with s(t, y) := t + y (continuous). For Borel A, Measure.map_apply and Measure.prod_apply give λ(A) = ∫⁻σ({y : (t, y) ∈ s⁻¹(A)}) d(Hⁿ⌞V)(t) = ∫⁻_{t∈V}σ({y : t + y ∈ A}) dHⁿ(t). Hence it suffices to prove ν = λ.
6. (Agreement on rectangles.) Let S = p⁻¹(A) ∩ q⁻¹(B). For t ∈ V and y ∈ V^⊥, p(t + y) = t and q(t + y) = y; since σ is concentrated on V^⊥, σ({y : t + y ∈ S}) = σ({y ∈ V^⊥ : t ∈ A, y ∈ B}) = 1_A(t)·σ(B) for t ∈ V. Therefore λ(S) = ∫⁻_{t∈V}1_A(t)σ(B) dHⁿ(t) = σ(B)·Hⁿ(V ∩ A) = ν(S) by step 4.
7. (Generation.) Rectangles are Borel and form a π-system (p⁻¹(A) ∩ q⁻¹(B) ∩ p⁻¹(A') ∩ q⁻¹(B') = p⁻¹(A ∩ A') ∩ q⁻¹(B ∩ B')). The σ-algebra 𝒢 they generate contains p⁻¹(A) = p⁻¹(A) ∩ q⁻¹(ℝ^P) and q⁻¹(B), so p and q are 𝒢-measurable, hence so is y ↦ p y + q y = y (Measurable.add into the second-countable ℝ^P); thus every Borel set belongs to 𝒢, and 𝒢 is the Borel σ-algebra.
8. (Conclusion.) The rectangles S_j := p⁻¹(B_j(0)) ∩ q⁻¹(B_j(0)) (j ∈ ℕ) cover ℝ^P and ν(S_j) ≤ ν(B̄_{2j}(0)) < ∞. By steps 6–7 and Measure.ext_of_generateFrom_of_iUnion, ν = λ, i.e. ν(A) = ∫⁻_{t∈V}σ({y : t + y ∈ A}) dHⁿ(t) for every Borel A; with step 3 this is the claim. ∎

## Key steps

1. For bounded Borel B, E ↦ ν(π⁻¹(E) ∩ q⁻¹(B)) is a translation-invariant locally finite measure on ℝⁿ ≅ V, so by Haar uniqueness it is σ(B)·vol with σ(B) = ω_n⁻¹ν({‖p y‖ < 1, q y ∈ B}).
2. Hence ν(p⁻¹(A) ∩ q⁻¹(B)) = σ(B)Hⁿ(A ∩ V) for all Borel A, B (bounded B first, then monotone limits); σ is concentrated on V^⊥ and finite on compact sets.
3. λ := ((Hⁿ⌞V) ⊗ σ) pushed forward by addition agrees with ν on the generating π-system of rectangles, finite on a countable cover, so ν = λ, which is the integral formula.
