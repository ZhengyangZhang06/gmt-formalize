1. (Integrability.) A continuous function with compact support K is bounded and vanishes off K, and ν(K) < ∞, so it is ν-integrable; the same holds for y ↦ g(v + y), which is supported in the compact set K − v.
2. (Derivative of the translated integral.) Fix a C^∞ function φ with compact support and put F(s) := ∫φ(y + s v) dν(y), s ∈ ℝ. Choose R_φ with tsupport φ ⊆ B̄_{R_φ}(0) and fix s₀ ∈ ℝ. For s ∈ (s₀ − 1, s₀ + 1) the functions y ↦ φ(y + s v) and y ↦ Dφ(y + s v)[v] vanish outside the closed ball K_{s₀} := B̄_{R_φ + (|s₀| + 1)‖v‖}(0) (if y + s v ∈ tsupport φ then ‖y‖ ≤ R_φ + |s|‖v‖) and are bounded by ‖φ‖_∞ and ‖Dφ‖_∞‖v‖ (Dφ is continuous with compact support, so ‖Dφ‖_∞ < ∞). For each y, s ↦ φ(y + s v) has derivative Dφ(y + s v)[v] (chain rule). Since ν(K_{s₀}) < ∞, the function ‖Dφ‖_∞‖v‖·1_{K_{s₀}} is an integrable bound for the s-derivatives, uniformly for s in the neighbourhood (s₀ − 1, s₀ + 1) = ball s₀ 1 of s₀, and y ↦ Dφ(y + s v)[v] is continuous hence measurable; differentiation under the integral sign (hasDerivAt_integral_of_dominated_loc_of_deriv_le, with the neighbourhood ball s₀ 1 ∈ 𝓝 s₀) gives that F is differentiable at s₀ with F'(s₀) = ∫Dφ(y + s₀v)[v] dν(y).
3. (F' = 0.) For fixed s₀, ψ(y) := φ(y + s₀v) is C^∞ with compact support (tsupport ψ = tsupport φ − s₀v) and Dψ(y)[v] = Dφ(y + s₀v)[v] (chain rule for a translation). By the hypothesis applied to ψ, F'(s₀) = ∫Dψ(y)[v] dν(y) = 0. (c) |g_k(x)| ≤ ∫ρ_k(t)|g(x − t)| dvol(t) ≤ ‖g‖_∞. (d) g_k(x) → g(x) for every x: given ε > 0 choose δ > 0 with |g(x') − g(x)| ≤ ε for |x' − x| < δ (continuity); for 1/k < δ, dist_convolution_le (support ρ_k ⊆ B_{1/k}(0), ρ_k ≥ 0, ∫ρ_k = 1) gives |g_k(x) − g(x)| ≤ ε.
6. (All of C_c.) By step 3 applied to g_k, ∫g_k(v + y) dν(y) = ∫g_k dν for every k. The integrands are dominated by ‖g‖_∞·1_{K₁ ∪ B̄_{R₀+1}(−v)} ({y : v + y ∈ K₁} = B̄_{R₀+1}(−v)), which is ν-integrable (compact set, step 1), and converge pointwise to g(v + y) and g(y) by step 5(d). By dominated convergence, ∫g(v + y) dν(y) = ∫g dν, i.e. ∫g d(τ_#ν) = ∫g dν for all g ∈ C_c.
7. (Uniqueness.) τ_#ν is finite on compact sets: (τ_#ν)(K) = ν(K − v) < ∞ because K − v is compact.
