## Proof

Source. Parent proof (0b) (x ∈ T_x via s ↦ e^s x; T_{tx} = T_x) and (0d) (homogeneity: ν(tx) = ν(x), t·Dν(tx)τ = Dν(x)τ, D_xν = 0), which is step 3 of the grandparent proof.

0. (Setting.) Fix an open O ⊇ M on which ν is C^∞. Then ν is continuous on O and differentiable at every point of O, and M ⊆ O. For y ∈ M write T_y := tangentSpace M y. By the sibling normal_complement (Submission.codim1_hcp_sc_tangent_normal_complement), T_y = {v ∈ A₀ : ν(y)·v = 0} for every y ∈ M. In particular each T_y is a linear subspace. Fix x ∈ M.

1. (x ∈ T_x.) Let γ(s) := e^s·x. γ is C^∞. For s ∈ (−1,1), γ(s) ∈ M by the cone property, since e^s > 0. Also γ(0) = x and γ'(0) = x. So x ∈ T_x.

2. (t·T_x ⊆ T_{tx}.) Let t > 0 and v ∈ T_x with witness γ. The curve tγ is C¹ on (−1,1) and maps (−1,1) into M (cone property). Moreover (tγ)(0) = tx and (tγ)'(0) = tv. So tv ∈ T_{tx}.

3. (T_{tx} = T_x.) Let t > 0. If v ∈ T_x then t⁻¹v ∈ T_x (subspace), so v = t·(t⁻¹v) ∈ T_{tx} by step 2. Conversely, tx ∈ M. Step 2 at the point tx with factor t⁻¹ gives t⁻¹w ∈ T_{t⁻¹·tx} = T_x for every w ∈ T_{tx}. Hence w ∈ T_x, since T_x is a subspace.

4. (ν(tx) = ±ν(x).) Let t > 0 and y := tx ∈ M. Then ν(y) ∈ A₀, and ν(y)·v = 0 for v ∈ T_y = T_x (step 3). Put λ := ν(x)·ν(y) and h := ν(y) − λν(x). Then h ∈ A₀ and ν(x)·h = λ − λ|ν(x)|² = 0, so h ∈ T_x by step 0. Hence |h|² = h·ν(y) − λ(h·ν(x)) = 0 − 0 = 0. So ν(y) = λν(x), and |λ| = |ν(y)| = 1, i.e. λ ∈ {−1, 1}.

5. (ν(tx) = ν(x).) Let g(t) := ν(tx)·ν(x) for t ∈ (0,∞). The map t ↦ tx is continuous with values in M ⊆ O, and ν is continuous on O, so g is continuous on (0,∞). By step 4, g takes values in {−1, 1}, and g(1) = 1. Suppose g(t₁) = −1 for some t₁ > 0. The closed interval between 1 and t₁ lies in (0,∞), and the intermediate value theorem gives t₂ there with g(t₂) = 0, which is impossible. So g ≡ 1, and ν(tx) = ν(x) for every t > 0 by step 4.

6. (t·Dν(tx)v = Dν(x)v.) Let t > 0 and v ∈ T_x with witness γ. For s ∈ (−1,1) we have γ(s) ∈ M, so step 5 at the point γ(s) gives ν(tγ(s)) = ν(γ(s)). The functions s ↦ ν(tγ(s)) and s ↦ ν(γ(s)) agree on the neighbourhood (−1,1) of 0. ν is differentiable at tγ(0) = tx and at γ(0) = x (both in O), and the inner maps have derivatives tv and v at 0. By the chain rule their derivatives at 0 are Dν(tx)(tv) and Dν(x)v. Functions agreeing near 0 have equal derivatives there, so t·Dν(tx)v = Dν(tx)(tv) = Dν(x)v.

7. (Dν(x)x = 0.) By step 5, t ↦ ν(tx) is constant (= ν(x)) on the open interval (0,∞), which contains 1. So its derivative at t = 1 is 0. By the chain rule (t ↦ tx has derivative x; ν is differentiable at x) this derivative is Dν(x)x. Hence fderiv ℝ ν x x = 0.

Steps 1, 7, 3, 5 and 6 are the five conjuncts of the conclusion. ∎

## Key steps

1. s ↦ e^s x is a C¹ curve in M through x with velocity x, so x ∈ T_x; tangent spaces are subspaces (normal_complement).
2. Scaling curves gives t·T_x ⊆ T_{tx}, and with linearity T_{tx} = T_x.
3. ν(tx) ∈ A₀ ∩ T_x^⊥ = ℝν(x) is a unit vector, so ν(tx) = ±ν(x); continuity in t on (0,∞) and IVT give ν(tx) = ν(x).
4. Differentiate ν(tγ(s)) = ν(γ(s)) at s = 0 along curves in M: t·Dν(tx)v = Dν(x)v.
5. Differentiate the constant map t ↦ ν(tx) at t = 1: Dν(x)x = 0.
