## Proof

Source: step 5 of the parent proof: "Choose α ∈ (0, 1) outside the union of the following null sets: the levels where for some i the slice is not IM or the slice identity fails (countably many null sets); the levels with Σ_i M(P_i(α)) = ∞; and the levels with μ_{S_{φ₁(i)}}(Σ_α) > 0 for some i (for each i these are countably many, because the Σ_α are pairwise disjoint subsets of … finite μ-measure)". Here the levels are t ∈ (a, b), the level sets are {h = t}, and the predicates good_i are abstract. λ denotes Lebesgue measure on ℝ.

1. (Failures of the predicates.) For each i, N_i := {t : ¬good_i(t)} is λ-null by hypothesis. So N := ⋃_i N_i is λ-null, as a countable union (Mathlib ae_all_iff).

2. (Summability.) Let λ_ab := λ⌞(a, b). Each g_i is λ_ab-a.e. measurable, so ∫_{(a,b)} Σ_i g_i dλ = Σ_i ∫_{(a,b)} g_i dλ < ∞ (lintegral_tsum), and Σ_i g_i is λ_ab-a.e. measurable. A non-negative a.e.-measurable function with finite integral is finite a.e. (ae_lt_top'). So N' := {t ∈ (a, b) : Σ_i g_i(t) = ∞} is λ-null.

3. (Atoms of the level sets.) Fix i and put ν_i := μ_i⌞{a < h < b}, a finite measure by hypothesis and hence s-finite.
 (a) Since h is measurable, the sets {h = t} are disjoint and measurable, and at most countably many of them have positive ν_i-measure. So C_i := {t : ν_i({h = t}) > 0} is countable (Mathlib Measure.countable_meas_level_set_pos).
 (b) For t ∈ (a, b), {h = t} ⊆ {a < h < b}, so μ_i({h = t}) = ν_i({h = t}). Hence μ_i({h = t}) = 0 for t ∈ (a, b) ∖ C_i.
 (c) C := ⋃_i C_i is countable, hence λ-null.

4. (Choice.) λ((a, b)) = b − a > 0, while N ∪ N' ∪ C is λ-null. So there is t ∈ (a, b) ∖ (N ∪ N' ∪ C). For this t: good_i(t) for all i (t ∉ N), Σ_i g_i(t) < ∞ (t ∉ N'), and μ_i({h = t}) = 0 for all i (t ∉ C). ∎

## Key steps

1. The failures of the predicates form a countable union of null sets.
2. Σ_i g_i has finite integral over (a, b), hence is finite a.e.
3. For each i, at most countably many level sets {h = t} carry μ_i-mass, because μ_i⌞{a < h < b} is finite.
4. (a, b) has positive measure, so some t avoids all exceptional sets.
