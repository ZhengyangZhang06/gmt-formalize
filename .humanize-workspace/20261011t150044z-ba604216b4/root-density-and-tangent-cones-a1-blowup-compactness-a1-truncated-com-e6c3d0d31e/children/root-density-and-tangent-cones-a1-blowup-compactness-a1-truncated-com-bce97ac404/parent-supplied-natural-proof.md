## Proof

Source: parent V13 (Simon Ch. 3, Theorem 1.6 ⇐ with ε := 2^{−1}16^{−n} instead of the printed 16^{−n}). The type is also that of the unaccepted DAG node cbr_rectifiable_of_approx_tangent, whose pieces cbrr_rectifiable_dim_zero, cbrr_tangent_cone_density_zero, cbrr_uniform_density_on_large_set, cbrr_projection_net, cbrr_cone_claim, cbrr_lipschitz_cover_of_cone_condition, cbrr_rectifiable_of_uniform_density are accepted. μ := Hⁿ⌞M, p_V := orthogonal projection onto V.
1. If Hⁿ(M) = 0 (countablyRectifiable_of_measure_zero), n = 0 (M finite, constant maps), n > P (Hⁿ = 0 on ℝ^P) or n = P (identity map) we are done. Let 1 ≤ n < P, ℓ := P − n, π_x := Q(x)^⊥, X_α(π, x) := {y : dist(y − x, π) < α|y − x|}.
2. At x with tangent space Q(x), testing the blow-up convergence against continuous approximations of 1_{B_1} and of the closed cone {dist(y, π_x) ≤ |y|/2} ∩ B̄_1 (which meets Q(x) only at 0) gives μ(B_ρ(x))/(ω_nρⁿ) → 1 and μ(X_{1/2}(π_x, x) ∩ B_ρ(x))/(ω_nρⁿ) → 0.
3. Fix ε' > 0 and ε := 2^{−1}16^{−n}. Lusin (applied to a Borel version of x ↦ p_{Q(x)}) and Egorov (applied to the Borel infima and suprema of these ratios over rational radii) give a compact E ⊆ M with μ(M ∖ E) < ε', on which x ↦ p_{Q(x)} is continuous, and δ > 0 with μ(B_ρ(x)) ≥ (1 − ε)ω_nρⁿ and μ(X_{1/2}(π_x, x) ∩ B_ρ(x)) ≤ εω_nρⁿ for x ∈ E, ρ < δ.
4. Choose ℓ-planes π_1, …, π_N with every ℓ-plane within 1/16 of some π_j (compactness of rank-ℓ projections), and E_j := {x ∈ E : ‖p_{π_j} − p_{π_x}‖ < 1/16}. Claim: X_{1/4}(π_j, x) ∩ E_j ∩ B_{δ/2}(x) = ∅ for x ∈ E_j. Otherwise for y in it, σ := |y − x|, we get B_{σ/8}(y) ⊆ X_{1/2}(π_x, x) ∩ B_{2σ}(x), so (1 − ε)ω_n(σ/8)ⁿ ≤ μ(B_{σ/8}(y)) ≤ εω_n(2σ)ⁿ, i.e. 1 − ε ≤ 16ⁿε = 1/2, a contradiction.
5. Hence on D := E_j ∩ B_{δ/4}(x₀), |p_{π_j^⊥}(y − x)| ≥ |y − x|/4, so D is the graph of a 4-Lipschitz map over π_j^⊥; its McShane extension (LipschitzOnWith.extend_real) yields a Lipschitz F : ℝⁿ → ℝ^P with D ⊆ F(ℝⁿ). Finitely many balls cover the compact E, so μ(M ∖ ⋃F_k(ℝⁿ)) < ε'.
6. Taking ε' = 1/m for all m, countably many Lipschitz images cover M up to an Hⁿ-null set: M is countably n-rectifiable. ∎
Note: Lusin (SimonGMT) is outside the import closure; accepted cbrr_uniform_density_on_large_set supplies step 3.
