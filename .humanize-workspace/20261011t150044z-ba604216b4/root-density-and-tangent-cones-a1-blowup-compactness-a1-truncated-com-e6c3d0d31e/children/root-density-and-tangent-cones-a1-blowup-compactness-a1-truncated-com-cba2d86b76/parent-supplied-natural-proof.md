1. Tools (Simon 2.17–2.29). For X with compact support and M(X) + M(∂X) < ∞ and Lipschitz F, F_#X := lim (F∗φ_σ)_#X exists (homotopy estimate), ∂F_#X = F_#∂X, M(F_#X) ≤ Lip(F)^kM(X), spt F_#X ⊆ F(spt X), and F_#X depends only on F|spt X. With ∂([[0,1]] × X) = {1}×X − {0}×X − [[0,1]]×∂X and h(t, x) := F(x) + t(G(x) − F(x)): G_#X − F_#X = ∂h_#([[0,1]]×X) + h_#([[0,1]]×∂X) and M(h_#([[0,1]]×X)) ≤ sup_{spt X}|G − F|(Lip F + Lip G)^kM(X).
2. Integrality (Simon 3.3–3.9). The carrier of an IM X is, up to an Hᵏ-null set, a disjoint union of bi-Lipschitz images G_i(A_i) of compact A_i ⊆ ℝᵏ (Rademacher; pieces on which G_i approximates an injective linear map). The area formula and approximate tangent planes on such pieces show that F_#X (F Lipschitz, or locally Lipschitz off a closed set with finite tangential Jacobian integral) is the integral current Φ_F with an integer multiplicity, oriented by the image tangent planes, hence IM; likewise [[0,1]] × X.
3. Faces. For u ∈ L¹((0,1)ⁿ) with divergence variation V: ∫|u − β| ≤ c_nV for every median β, M(∂(u[[(0,1)ⁿ]])) ≤ c_n(V + ∫|u|) (mollified Poincaré and trace inequalities), and if u is integer-valued there is an integer median β with |β| ≤ 2∫|u|, equal to u if V = 0.
4. Retraction (Simon 5.4). For a ∈ B_{1/4}(q), q the cube centre, the dual skeleton L*(a) = a + L_{ℓ−1} has distance ≥ 1/4 from the n-skeleton L_n (needs ℓ ≥ 1), and iterated radial projections from the face points a_F give ψ : ℝ^P ∖ L*(a) → L_n, ℤ^P-equivariant, = id on L_n, |ψ − id| ≤ √P, with pointwise Lipschitz constant ≤ c₁/dist(·, L*(a)) (induction on ℓ; printed 3/4 corrected to 1/4); so Lip ψ ≤ c₂/ρ on {dist(·, L*(a)) ≥ ρ}.
5. Unit scale (Simon 5.1). If T = 0 take Q = R = S = 0. Choose a by the 5r-covering lemma so that μ_T(L*(a; ρ)) ≤ Nβρ^{n+1}M(T) and μ_{∂T}(L*(a; ρ)) ≤ Nβρ^{n+1}M(∂T) for ρ ≤ 1/4. With f := dist(·, L*(a)), (SL), (MM) and Chebyshev give radii ρ*_ν ∈ (2^{−ν−3}, 2^{−ν−2}) with slice mass ≤ 4Nβ2^{−(ν+2)n}M(T) and μ_T{f = ρ*_ν} = μ_{∂T}{f = ρ*_ν} = 0. Push X_ν := T⌞{f ≥ ρ*_ν} by ψ and apply step 1; the shell estimates (Lip ψ ≤ c₂2^{i+4} on the i-th shell, whose μ_T-mass is ≤ Nβ2^{−(i+2)(n+1)}M(T)) make ψ_#X_ν and the homotopy terms mass-Cauchy, with limits Q₀, R₁, S₁: T − Q₀ = ∂R₁ + S₁, M(Q₀), M(R₁) ≤ cM(T), M(S₁), M(∂Q₀) ≤ cM(∂T). Q₀ = Φ_ψ(T) and Φ_h([[0,1]] × T) are IM by step 2 (finite Jacobian integrals by the shell estimates), so R₁ = 0 − Φ_h is IM by (IMC)(c). Q₀ is carried by the open n-faces F of the grid; on each, Q₀⌞F = u_F[[F]] with integer u_F and divergence variation V_F, ΣV_F ≤ M(∂Q₀). With integer medians β_F (step 3), P := Σβ_F[[F]] satisfies M(P) ≤ 2M(Q₀), M(Q₀ − P) ≤ c_nM(∂Q₀), M(∂P) ≤ cM(∂Q₀), P and ∂P are IM (integer face chains), and R := R₁, S := S₁ + (Q₀ − P) give T − P − S = ∂R with all supports within 2√P of spt T, resp. spt ∂T.
6. Scaling (Simon 5.3). Apply step 5 to δ_{ρ#}T, δ_ρ(x) := x/ρ (affinePushforward preserves IM and commutes with ∂), and push back: Q := Σβ_F[[ρF]] satisfies M(Q) ≤ cM(T), M(∂Q) ≤ cM(∂T), M(R) ≤ cρM(T), M(S) ≤ cρM(∂T), supports within 2√Pρ < 3√Pρ, and Q = 0 or M(Q) = ρⁿΣ|β_F| ≥ ρⁿ. This is (DTr), with c depending only on (P, m).
7. (Isor) (Simon 6.1). Let Z be an IM cycle with compact support and z := M(Z) < ∞. If z = 0 then Z = 0 (a current of mass 0 vanishes) and Y := 0. If z > 0, apply (DTr) with ρ := (2cz)^{1/(m+1)}: M(S) ≤ cρM(∂Z) = 0 gives S = 0, and M(Q) ≤ cz < 2cz = ρ^{m+1} gives Q = 0; so Z = ∂R and Y := R satisfies M(Y) ≤ cρz = c(2cz)^{1/(m+1)}z and spt Y ⊆ thickening(3√Pρ, spt Z). ∎
