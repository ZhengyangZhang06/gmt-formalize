## Proof

Source: the density-point argument behind parent Steps 3(a) and 3(c) (“there are y_k ∈ Y_j with y_k → y and (y_k − y)/|y_k − y| → e”).

1. Trivial case. If d = 0 there is no unit vector, so the claim is vacuous. Assume d ≥ 1, and fix v with |v| = 1.

2. A ball inside the cone. Let 0 < η ≤ 1 and r > 0, and put B := B_{ηr/4}(y + (r/2)v) (open ball). Write z − y = (r/2)v + w with |w| < ηr/4 for z ∈ B.
 (a) |z − y| ≤ r/2 + ηr/4 < r, so B ⊆ B̄_r(y).
 (b) |z − y| ≥ r/2 − ηr/4 ≥ r/4 > 0, so z ≠ y.
 (c) With s := r/2 and u := z − y = sv + w: ||u| − s| = ||sv + w| − |sv|| ≤ |w|. Hence
 |u/|u| − v| ≤ |u|·|1/|u| − 1/s| + |u/s − v| = ||u| − s|/s + |w|/s ≤ 2|w|/s < η.

3. Measure of the ball. By translation invariance and scaling of Lebesgue measure, L^d(B) = (η/4)^d L^d(B̄_r(y)), with 0 < L^d(B̄_r(y)) < ∞ (closed balls and open balls of the same radius have equal measure). [Lean: Measure.addHaar_ball / addHaar_closedBall; Nontrivial (Euclid d) follows from v ≠ 0. Only monotonicity of the outer measure and measure_diff for the measurable B are needed, so Z may be arbitrary.] Let κ := (η/4)^d ∈ (0, 1].

4. Hitting the ball. By the density hypothesis there is r₀ > 0 such that L^d(Z ∩ B̄_r(y)) > (1 − κ)L^d(B̄_r(y)) for all 0 < r < r₀. For such r, Z ∩ B ≠ ∅. Otherwise Z ∩ B̄_r(y) ⊆ B̄_r(y) ∖ B, and since B is measurable with B ⊆ B̄_r(y) (step 2(a)), L^d(Z ∩ B̄_r(y)) ≤ L^d(B̄_r(y)) − L^d(B) = (1 − κ)L^d(B̄_r(y)) (monotonicity of the outer measure), a contradiction.

5. The sequence. For i ≥ 1 apply step 4 with η := 1/i and some r = r_i < min(r₀(1/i), 1/i). Pick y_i ∈ Z ∩ B_{r_i/(4i)}(y + (r_i/2)v). By step 2: y_i ≠ y, |y_i − y| < r_i < 1/i, and |(y_i − y)/|y_i − y| − v| < 1/i. Hence y_i → y and (y_i − y)/|y_i − y| → v (index the sequence by i ∈ ℕ, e.g. using i + 1). ∎

## Key steps

1. d = 0 is vacuous; fix a unit v.
2. The ball B_{ηr/4}(y + (r/2)v) lies in B̄_r(y) ∖ {y}, inside the η-cone around v.
3. Its measure is the fixed fraction (η/4)^d of L^d(B̄_r(y)).
4. Density 1 forces Z to meet this ball for all small r.
5. Choose η = 1/i and r_i < min(r₀(η), 1/i) to get y_i → y with directions → v.
