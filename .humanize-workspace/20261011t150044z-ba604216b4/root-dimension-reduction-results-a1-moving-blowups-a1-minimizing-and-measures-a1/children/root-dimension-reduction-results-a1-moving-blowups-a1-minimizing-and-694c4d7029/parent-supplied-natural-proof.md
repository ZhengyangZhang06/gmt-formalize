## Proof

Source: Simon 7.2.4, (13) and the remark after it (chapter-07.txt lines 264–280: limsup μ_{T_j}(K) ≤ M_{dist(·,K)<ε}(T), then ε ↓ 0; "we can repeat the argument for a subsequence of any given subsequence, hence it holds for the original sequence"). This is the measure-theoretic core of step 3(b) of the parent proof.
1. Fix a compact K ⊆ ℝ^P and put ℓ := limsup_j μ_j(K) ∈ [0, ∞]. Claim: ℓ ≤ μ(thickening(ε, K)) for every ε > 0.
2. Suppose the claim fails for some ε > 0, i.e. μ(thickening(ε, K)) < ℓ. Since [0, ∞] is densely ordered, choose b with μ(thickening(ε, K)) < b < ℓ.
3. Since b < limsup_j μ_j(K), the inequality μ_j(K) > b holds for infinitely many j (otherwise μ_j(K) ≤ b for all large j, which would force ℓ ≤ b). Listing these j in increasing order gives a strictly increasing ψ : ℕ → ℕ with μ_{ψ(i)}(K) > b for every i (Mathlib extraction_of_frequently_atTop).
4. Apply (s) to K, ε and ψ: there are W with K ⊆ W ⊆ thickening(ε, K) and a strictly increasing φ' with limsup_i μ_{ψ(φ'(i))}(W) ≤ μ(W).
5. For every i, μ_{ψ(φ'(i))}(W) ≥ μ_{ψ(φ'(i))}(K) > b, by monotonicity of the measure μ_{ψ(φ'(i))} (K ⊆ W) and step 3 applied at the index φ'(i). A sequence that is ≥ b at every index has lim sup ≥ b, so b ≤ limsup_i μ_{ψ(φ'(i))}(W).
6. Hence b ≤ limsup_i μ_{ψ(φ'(i))}(W) ≤ μ(W) ≤ μ(thickening(ε, K)) < b, using step 4 and monotonicity of μ (W ⊆ thickening(ε, K)); this contradiction proves the claim.
7. K is compact, hence closed. The set cthickening(1, K) = {x : dist(x, K) ≤ 1} is closed and bounded in ℝ^P, hence compact, so by (a), μ(thickening(1, K)) ≤ μ(cthickening(1, K)) < ∞. For a closed set K with μ(thickening(R, K)) < ∞ for some R > 0, continuity of measure from above along the decreasing sets thickening(r, K), whose intersection over r > 0 is closure(K) = K, gives μ(thickening(r, K)) → μ(K) as r ↓ 0 (Mathlib tendsto_measure_thickening_of_isClosed).
8. By the claim, ℓ ≤ μ(thickening(r, K)) for every r > 0; letting r ↓ 0 and using step 7 yields ℓ = limsup_j μ_j(K) ≤ μ(K). ∎

## Key steps

1. For fixed ε > 0, if limsup_j μ_j(K) > b > μ(thickening(ε, K)), extract a strictly increasing ψ with μ_{ψ(i)}(K) > b for all i.
2. Hypothesis (s) gives W ⊇ K inside thickening(ε, K) and φ' with limsup_i μ_{ψ(φ'(i))}(W) ≤ μ(W) ≤ μ(thickening(ε, K)) < b, whereas μ_{ψ(φ'(i))}(W) ≥ μ_{ψ(φ'(i))}(K) > b for all i: contradiction.
3. Let ε ↓ 0: μ(thickening(ε, K)) → μ(K) since K is closed and μ(thickening(1, K)) ≤ μ(cthickening(1, K)) < ∞ by (a).
