## Proof

Source: the parent's step 4, case n − d = 2 (Simon 7.3.3(1), chapter-07.txt lines 497–510), uses that a 2-dimensional minimizing cone is a union of planes, citing [Whi82]; the book does not prove this. This child proves the local half of that structure: near a point where the density is constant on the support, the cone is a multiple of a plane. Regularity comes from the root result density_one_implies_regular (Simon 7.4.3, Allard's theorem) applied to C divided by its multiplicity. Planarity then follows from the first variation (Simon Ch. 4, 2.2–2.6) of the stationary cone along the rotation field of the tangent plane. Conventions. ℝ^P := Euclid P and B_ρ(x) is the open ball. For an integer multiplicity current A on an open set, μ_A denotes R.measure for any representation R of A (all representations have the same measure), M_W(A) = μ_A(W) for open W inside the domain of A, and spt A = {x in the domain : μ_A(B_ε(x)) > 0 for every ε > 0} (sibling results im_mass_measure (c), (a), (b), `Submission.dimred_im_mass_measure`); hence μ_A vanishes off spt A (Lindelöf). H² := μHE[2] and ω_2 := unitBallVolume 2. For a 2-dimensional subspace Q, H²⌞Q is the image of Lebesgue measure of ℝ² under a linear isometry (Mathlib `Isometry.euclideanHausdorffMeasure_image`, `EuclideanSpace.euclideanHausdorffMeasure_eq_volume`), so H²(Q ∩ B_ρ(y)) = ω_2ρ² for y ∈ Q. η_{y,λ}(w) := λ^{−1}(w − y) (Lean `dilation y λ`) and blowUp A y λ = η_{y,λ#}A. For 2-currents, M_{η_{y,λ}(W)}(η_{y,λ#}A) = λ^{−2}M_W(A) (accepted `Submission.dtc_blowUp_massOn_image`), η_{y,λ#}A has a representation with measure B ↦ λ^{−2}μ_A(η_{y,λ}^{−1}(B)) (accepted `Submission.dtc_blowUp_imrep`), and (η_{y,λ#}A)(ω) = λ^{−2}A(ω∘η_{y,λ}) (accepted `Submission.dtc_blowUp_testForm_corr`). Densities are unique: HasMassDensity A y θ and HasMassDensity A y θ' imply θ = θ' (both are ≥ 0 and ENNReal.ofReal is injective on [0, ∞)). (M) Monotonicity. Let C ∈ 𝒟_2(ℝ^P) be minimizing in ℝ^P with ∂C = 0. If P ≤ 1, every 2-covector on ℝ^P vanishes, so C = 0; hence P ≥ 2 whenever spt C ≠ ∅, and then we write P = 2 + k₀ to apply results stated in ℝ^{n+k}. ℝ^P = univ is an embedded C² P-dimensional submanifold (identity chart), closure ℝ^P ∖ ℝ^P = ∅ and spt C ⊆ ℝ^P, so the sibling result monotonicity (`Submission.dimred_minimizing_monotonicity`, with U = N = ℝ^P, n = 2, d = P) gives: ρ ↦ ρ^{−2}μ_C(B_ρ(y)) is nondecreasing on (0, ∞) for every y; Θ(y) := Θ²(μ_C, y) exists for every y (HasMassDensity C y Θ(y)) and Θ is upper semicontinuous; Θ ≥ 1 on spt C; hence μ_C(B_ρ(y)) ≥ ω_2ρ² for y ∈ spt C and ρ > 0; and Θ(y) = 0 for y ∉ spt C (a ball about y has μ_C-measure 0). (K) Cone facts. Let C ∈ 𝒟_2(ℝ^P) be a cone (IsConeCurrent C). For λ > 0 the domain of blowUp C 0 λ is η_{0,λ}(ℝ^P) = ℝ^P and currentEval(blowUp C 0 λ, ω) = C(ω), so blowUp C 0 λ = C; mass scaling gives M_{λ^{−1}W}(C) = λ^{−2}M_W(C), i.e. μ_C(sW) = s²μ_C(W) for open W and s > 0, hence for all Borel sets (outer regularity of the locally finite measure μ_C). Consequently spt C is invariant under x ↦ sx (s > 0), Θ(sx) = Θ(x), μ_C(B_ρ(0)) = ρ²μ_C(B_1(0)) for ρ > 0, and μ_C({0}) = 0.
1. (Normalization.) Since p ∈ spt C, k = Θ(p) ≥ 1 by (M) and uniqueness of densities, and P ≥ 2; write P = 2 + k₀. Hypothesis and conclusion are invariant under replacing (p, δ, δ') by (sp, sδ, sδ') for s > 0: by (K), spt C, Θ and μ := μ_C transform accordingly, the subspace Q is unchanged, and μ(sW) = s²μ(W), H²(sW ∩ Q) = s²H²(W ∩ Q). Hence we may assume |p| = 1 and, decreasing δ, δ < 1/4. Let R = (M, θ, ξ) represent C, so μ = R.measure.
2. (θ = k on B_δ(p).) μ(K) < ∞ for compact K, so by the sibling child density_eq_multiplicity_ae (n := 2, U := ℝ^P), for H²-a.e. x ∈ M the ratio μ(B_ρ(x))/(ω_2ρ²) tends to θ(x) ≥ 1. For such x, μ(B_ε(x)) > 0 for every ε > 0, so x ∈ spt C (im_mass_measure (b)); if moreover x ∈ B_δ(p), the hypothesis HasMassDensity C x k and uniqueness give θ(x) = k. So θ = k H²-a.e. on M ∩ B_δ(p).
3. (Dividing by k.) Put B := B_δ(p) and R_1 := (M ∩ B, 1, ξ). R_1 is an integer multiplicity triple in B: M ∩ B is Borel, countably 2-rectifiable and contained in B; the multiplicity 1 is measurable and positive; ∫_{M∩B∩K} 1 dH² ≤ μ(K) < ∞ for compact K; ξ is a.e. strongly measurable for H²⌞(M ∩ B); and at H²-a.e. x ∈ M ∩ B the approximate tangent space of M ∩ B at x equals that of M (accepted `Submission.dtc_approxTangent_of_null_diff` with V := B, since (M ∖ (M ∩ B)) ∩ B = ∅), which ξ(x) orients. Let C_1 ∈ 𝒟_2(B) be the current represented by R_1 (accepted `Submission.dtc_imrep_current`). By step 2, for every ω ∈ 𝒟²(B), C(ιω) = ∫_M θ·ξ(ω) dH² = k∫_{M∩B} ξ(ω) dH² = k·C_1(ω), where ι regards ω as an element of 𝒟²(ℝ^P). Consequently M_W(C) = k·M_W(C_1) for every W ⊆ B (the admissible forms for M_W in ℝ^P and in B correspond, and ofReal(k·x) = k·ofReal(x)), and spt C ∩ B = spt C_1 (since k ≥ 1, an open set with compact closure in B lies in the zero region of C iff it lies in that of C_1).
4. (Properties of C_1.) (a) C_1 is integer multiplicity. (b) ∂C_1 = 0 in B: for β ∈ 𝒟¹(B), C_1(dβ) = k^{−1}C(ι dβ) = k^{−1}(∂C)(ιβ) = 0. (c) M_{B_ρ(p)}(C_1) = k^{−1}M_{B_ρ(p)}(C) for 0 < ρ ≤ δ, so HasMassDensity C_1 p 1. (d) p ∈ spt C_1 by step 3. (e) M_W(C_1) ≤ k^{−1}μ(B) < ∞ for every W ⊆ B. (f) C_1 is minimizing in B: let W ⊆ ℝ^P be open with closure W compact and contained in B, let S_1 ∈ 𝒟_2(B) be integer multiplicity with ∂S_1 = ∂C_1 (= 0), and let spt(S_1 − C_1) be compact and contained in B ∩ W. Then D := S_1 − C_1 is integer multiplicity (accepted `Submission.dtc_isIntegerMultiplicity_sub`) with ∂D = 0. If R_D represents D, its measure vanishes off the compact set K := spt D ⊆ W (Lindelöf and im_mass_measure (b)), so H²(R_D.carrier ∖ K) = 0, and accepted `Submission.dtc_extend_by_zero` (U := ℝ^P, V := B) gives an integer multiplicity D̃ ∈ 𝒟_2(ℝ^P) whose restriction to B is D, with spt D̃ ⊆ K and ∂D̃ = 0. Define D_1 := D̃ and D_{i+1} := D_i − (0 − D̃), so that D_i(ω) = i·D̃(ω); all are integer multiplicity by dtc_isIntegerMultiplicity_sub (0 is represented by the empty triple). Put S := C − (0 − D_k), so S(ω) = C(ω) + k·D̃(ω). Then S is integer multiplicity, ∂S = ∂C, spt(S − C) = spt D̃ ⊆ K is compact and contained in ℝ^P ∩ W, and W ⊂⊂ ℝ^P. Minimality of C gives M_W(C) ≤ M_W(S). For ω ∈ 𝒟²(ℝ^P) with tsupport ω ⊆ W ⊆ B we have C(ω) = k·C_1(ω) and S(ω) = k·C_1(ω) + k·D(ω) = k·S_1(ω), ω being regarded as an element of 𝒟²(B). Hence M_W(C) = k·M_W(C_1), M_W(S) = k·M_W(S_1), and M_W(C_1) ≤ M_W(S_1).
5. (Regularity at p.) Apply density_one_implies_regular (`Submission.density_one_implies_regular`) with n := 2, k := ℓ := k₀, U := B, N := ℝ^P (identity chart; closure ℝ^P ∖ ℝ^P = ∅), T_i := C_1, T := C_1 and y_i := y := p. Its hypotheses hold by step 4: C_1 is minimizing in B ∩ ℝ^P = B, the supports lie in ℝ^P, ∂C_1 = 0, the masses are uniformly bounded, the constant sequence converges, p ∈ ℝ^P ∩ B, HasMassDensity C_1 p 1, and p ∈ spt C_1. Hence p ∈ reg C_1: there are ρ > 0 with B_ρ(p) ⊆ B, m_1 ∈ ℤ ∖ {0}, an embedded C¹ 2-dimensional submanifold M' ∋ p with an orientation ξ' (continuous on M', ξ'(y) = ±(α ↦ α(τ_1, τ_2)) for an orthonormal basis τ of T_yM'), H²(M' ∩ K) < ∞ for compact K ⊆ B_ρ(p), and C_1(ω) = m_1∫_{M'} ξ'(ω) dH² for ω ∈ 𝒟²(B) with tsupport ω ⊆ B_ρ(p). So C(ω) = k·m_1∫_{M'} ξ'(ω) dH² for every ω with tsupport ω ⊆ B_ρ(p).
6. (Local structure.) Let ψ : V_0 → W_0 be a chart of M' at p as in IsEmbeddedSubmanifold: V_0 ⊆ ℝ² and W_0 ∋ p are open, ψ is C¹ and injective with injective derivative, ψ(V_0) = W_0 ∩ M', and ψ^{−1}(K) is compact for every compact K ⊆ W_0. Then ψ is a homeomorphism of V_0 onto W_0 ∩ M' and W_0 ∩ M' is closed in W_0 (a continuous injective map with this properness is a closed embedding). For x ∈ M' let T_xM' be the subspace with (T_xM' : Set) = tangentSpace M' x provided by IsOrientation; it is 2-dimensional, since ξ'(x) = ±(α ↦ α(τ_1, τ_2)) for an orthonormal basis (τ_1, τ_2) of it. For every chart point v ∈ V_0, Dψ(v)(ℝ²) ⊆ tangentSpace M' ψ(v) (use the curves t ↦ ψ(v + εtw) for w ∈ ℝ² and small ε > 0, and that the tangent space is a subspace), and both are 2-dimensional (Dψ(v) is injective), so Dψ(v)(ℝ²) = T_{ψ(v)}M'. Fix ρ' ∈ (0, 1/2) with B_{ρ'}(p) ⊆ W_0 ∩ B_ρ(p). (a) spt C ∩ B_{ρ'}(p) = M' ∩ B_{ρ'}(p). If x ∈ B_{ρ'}(p) ∖ M', some ball about x misses M' (relative closedness), C vanishes on the forms supported in it, and x ∉ spt C. If x ∈ M' ∩ B_{ρ'}(p), let α_x be a 2-covector with ξ'(x)(α_x) = 1 (ξ'(x) ≠ 0), choose ε > 0 with B_ε(x) ⊆ B_{ρ'}(p) and ξ'(y)(α_x) > 1/2 for y ∈ M' ∩ B_ε(x) (continuity of ξ'), and g ∈ C^∞_c(B_ε(x)) with g ≥ 0 and g(x) > 0. Then C(g·α_x) = k·m_1∫_{M'} g·ξ'(α_x) dH² ≠ 0, because the integrand is ≥ g/2 ≥ 0 and positive on M' ∩ {g > 0}, a set of positive H²-measure (it contains the image under ψ of a nonempty open subset of V_0, and Dψ is injective). So x ∈ spt C. (b) For every x ∈ M' the approximate tangent space of M' at x exists and equals the tangent space T_xM' (classical: near x, M' is the graph over T_xM' of a C¹ map u with u(0) = 0 and Du(0) = 0; η_{x,r}(M') is near 0 the graph of u_r(z) := r^{−1}u(rz), u_r → 0 in C¹ on compact sets, and the area formula gives ∫_{η_{x,r}(M')} f dH² → ∫_{T_xM'} f dH² for f ∈ C_c(ℝ^P)). Hence R' := (M' ∩ B_{ρ'}(p), |k·m_1|, sign(k·m_1)·ξ') is an integer multiplicity triple in B_{ρ'}(p) representing the restriction of C to B_{ρ'}(p), and so does (M ∩ B_{ρ'}(p), θ, ξ). By im_mass_measure (c), θ·H²⌞(M ∩ B_{ρ'}(p)) = |k·m_1|·H²⌞(M' ∩ B_{ρ'}(p)). Since θ ≥ 1 on M, H²((M Δ M') ∩ B_{ρ'}(p)) = 0, and for H²-a.e. x ∈ M ∩ B_{ρ'}(p): x ∈ M', θ(x) = |k·m_1|, and approxTangentPlane 2 M x = T_xM'. For the last point apply dtc_approxTangent_of_null_diff to M ∩ M' ⊆ M and to M ∩ M' ⊆ M' with V := B_{ρ'}(p), and use the uniqueness of approximate tangent spaces.
7. (Coordinates.) Let Q := T_pM'. p ∈ Q: by (K), for small ε_0 > 0 the C¹ curve t ↦ (1 + ε_0t)p, t ∈ (−1, 1), lies in spt C ∩ B_{ρ'}(p) = M' ∩ B_{ρ'}(p) and has velocity ε_0p at t = 0, so ε_0p ∈ tangentSpace M' p = Q. Let e ∈ Q be a unit vector with e ⊥ p, let π be the orthogonal projection onto Q, and let A(x) := ⟨x, p⟩e − ⟨x, e⟩p. A is linear and antisymmetric (⟨Ax, y⟩ = −⟨x, Ay⟩), |Ax| = |πx|, Ap = e, and A = 0 on Q^⊥. On Ω := {x : ⟨x, p⟩ > 0} ⊇ B_{1/2}(p) put f(x) := arctan(⟨x, e⟩/⟨x, p⟩) ∈ (−π/2, π/2), so πx = |πx|(cos f(x)·p + sin f(x)·e). f is smooth on Ω, f(sx) = f(x) for s > 0, ∇f(x) = Ax/|πx|², ⟨∇f(x), x⟩ = 0 and f(p) = 0. Let F(x) := (|x|, f(x)) on Ω; then dF_p(p) = (1, 0) and dF_p(e) = (0, 1).
8. (Parametrization.) F∘ψ is C¹ near v_0 := ψ^{−1}(p), with invertible derivative dF_p∘Dψ(v_0), because Dψ(v_0) maps ℝ² onto T_pM' = Q (step 6) and dF_p restricted to Q is invertible (step 7). By the inverse function theorem there are s ∈ (0, 1/4) and an open V_1 ∋ v_0 such that F∘ψ maps V_1 C¹-diffeomorphically onto O := (1 − s, 1 + s) × (−s, s). Put G := ψ∘(F∘ψ|_{V_1})^{−1} : O → M'; it is C¹ and injective with injective derivative, and F∘G = id_O. N_1 := G(O) = ψ(V_1) is open in M', so N_1 = M' ∩ N for an open set N. Shrinking s we may assume N_1 ⊆ B_{ρ'/2}(p), and we replace N by N ∩ B_{ρ'}(p). Let γ(α) := G(1, α) for α ∈ (−s, s): γ is C¹, |γ(α)| = 1, f(γ(α)) = α, γ(0) = p. Claim: G(t, α) = tγ(α) on O. Fix α. The set I_α := {t ∈ (1 − s, 1 + s) : tγ(α) = G(t, α)} contains 1 and is closed in (1 − s, 1 + s) by continuity. It is open: if t ∈ I_α, then tγ(α) ∈ N; for t' close to t, t'γ(α) ∈ N, and t'γ(α) ∈ spt C by (K) (γ(α) ∈ M' ∩ B_{ρ'}(p) ⊆ spt C by 6(a)); so t'γ(α) ∈ spt C ∩ B_{ρ'}(p) ∩ N = M' ∩ N = G(O); since F(t'γ(α)) = (t', α) and F is injective on G(O), t'γ(α) = G(t', α). Hence I_α = (1 − s, 1 + s). Consequently T_{G(t,α)}M' = DG(t, α)(ℝ²) = span{∂_tG, ∂_αG} = span{γ(α), γ'(α)} (G = ψ∘(F∘ψ|_{V_1})^{−1} and step 6), where γ'(α) ≠ 0 and γ'(α) ⊥ γ(α).
9. (Conservation law.) minimizing_implies_stationary (`Submission.minimizing_implies_stationary`, with n := 2, k := ℓ := k₀, U = N = ℝ^P; spt C ⊆ ℝ^P and ∂C = 0) gives R.firstVariation X = 0 for every C¹ compactly supported X : ℝ^P → ℝ^P (every vector is tangent to ℝ^P). Let λ ∈ C^∞_c((1 − s, 1 + s)) with λ ≥ 0, λ ≢ 0, let ψ_0 ∈ C¹_c((−s, s)), let K_0 := G(spt λ × spt ψ_0) (compact, ⊆ N_1 ⊆ N), and let ζ ∈ C^∞_c(N) with ζ = 1 on a neighbourhood of K_0. Put X(x) := ψ_0(f(x))λ(|x|)ζ(x)Ax, extended by 0 off N; X is C¹ with compact support in N ⊆ B_{ρ'}(p) ⊆ Ω. By 6(b), 0 = R.firstVariation X = |k·m_1|∫_{M'∩B_{ρ'}(p)} tr(P_{T_xM'}∘DX(x)) dH²(x). With g := (ψ_0∘f)·λ(|·|)·ζ we have DX = g·A + (Ax) ⊗ ∇g, where (v ⊗ w)(u) := ⟨w, u⟩v. For a 2-plane T with orthonormal basis (u_1, u_2), tr(P_T A) = Σ_i ⟨Au_i, u_i⟩ = 0 (A antisymmetric) and tr(P_T∘((Ax) ⊗ ∇g)) = ⟨P_T∇g, Ax⟩. Let x ∈ M' ∩ B_{ρ'}(p) with x ∈ spt ζ ⊆ N. Then x ∈ M' ∩ N = G(O) and x = G(F(x)), so ψ_0(f(x))λ(|x|) ≠ 0 forces x ∈ K_0, where ∇ζ(x) = 0. Moreover, for x = G(t, α) we have x/|x| = γ(α) ∈ T_xM', hence ⟨P_{T_xM'}(x/|x|), Ax⟩ = ⟨x/|x|, Ax⟩ = 0. So the λ'-term and the ∇ζ-term vanish, and 0 = ∫_{G(O)} ψ_0'(f(x))λ(|x|)⟨P_{T_xM'}∇f(x), Ax⟩ dH²(x) = ∫_{G(O)} ψ_0'(f(x))λ(|x|)·|P_{T_xM'}Ax|²/|πx|² dH²(x).
10. (Change of variables.) At x = G(t, α) let τ(α) := γ'(α)/|γ'(α)|. Then |P_{T_xM'}Ax|² = ⟨γ(α), Ax⟩² + ⟨τ(α), Ax⟩² = t²⟨τ(α), Aγ(α)⟩² (⟨y, Ay⟩ = 0), |πx|² = t²|πγ(α)|², and the area Jacobian of G is J_G(t, α) = |∂_tG ∧ ∂_αG| = |γ ∧ tγ'| = t|γ'(α)|. Differentiating f(γ(α)) = α gives ⟨Aγ, γ'⟩ = |πγ|², so ⟨τ, Aγ⟩ = |πγ|²/|γ'|. By the area formula for the injective C¹ map G with injective derivative (SimonGMT `integral_area_formula_of_injective_derivative`, Chapter02/WeightedArea.lean; Simon Ch. 2, §3), 0 = ∫_O ψ_0'(α)λ(t)·t|πγ(α)|²/|γ'(α)| dt dα = (∫λ(t)t dt)·∫ψ_0'(α)κ(α) dα, where κ := |πγ|²/|γ'| is continuous on (−s, s). Since ∫λ(t)t dt > 0 and ψ_0 ∈ C¹_c((−s, s)) is arbitrary, ∫κψ_0' dα = 0 for every such ψ_0, i.e. κ has zero distributional derivative on (−s, s); transporting κ (extended by 0 off (−s, s)) along the volume-preserving linear isometry ℝ ≅ Euclid 1, this is exactly the hypothesis (for C¹ test functions with compact support in the image of (−s, s)) of SimonGMT `ae_eq_const_of_weak_coordinate_derivatives_zero` with n = 1, so κ is a.e. constant on (−s, s) and, being continuous, constant: κ ≡ κ(0) = |πp|²/|γ'(0)| = 1, because γ'(0) ∈ T_pM' ∩ p^⊥ = ℝe and ⟨∇f(p), γ'(0)⟩ = ⟨e, γ'(0)⟩ = 1 give γ'(0) = e.
11. (Planarity.) So |γ'| = |πγ|². By Cauchy–Schwarz, |πγ|² = ⟨Aγ, γ'⟩ ≤ |Aγ|·|γ'| = |πγ|³, so |πγ| ≥ 1 (πγ ≠ 0 on Ω), while |πγ| ≤ |γ| = 1. Hence γ(α) = πγ(α) ∈ Q, and since f(γ(α)) = α, γ(α) = cos α·p + sin α·e. Therefore G(O) = {t(cos α·p + sin α·e) : |t − 1| < s, |α| < s}, an open neighbourhood of p in Q. Choose δ' ∈ (0, δ) with B_{δ'}(p) ⊆ N and Q ∩ B_{δ'}(p) ⊆ G(O). Then spt C ∩ B_{δ'}(p) = M' ∩ N ∩ B_{δ'}(p) = G(O) ∩ B_{δ'}(p) = Q ∩ B_{δ'}(p), by 6(a) and N_1 = M' ∩ N.
12. (Mass.) Let C_{δ'} ∈ 𝒟_2(B_{δ'}(p)) be the restriction of C. It is integer multiplicity (accepted `Submission.dtc_restrictDomain_isIntegerMultiplicity`), ∂C_{δ'} = 0, spt C_{δ'} = spt C ∩ B_{δ'}(p) = Q ∩ B_{δ'}(p) ⊆ Q, and B_{δ'}(p) ∩ Q is convex, hence connected and nonempty. The sibling child planar_constancy (`Submission.idtp_planar_cycle_eq_const_mul`, with n := 2, V := B_{δ'}(p), τ := (p, e)) gives c ∈ ℤ with M_W(C_{δ'}) = |c|·H²(W ∩ Q) for every open W ⊆ B_{δ'}(p), and M_W(C) = M_W(C_{δ'}) for such W (accepted `Submission.dtc_massOn_eq_of_agreeOn`). Comparing densities at p (k by hypothesis; |c|·H²(B_ρ(p) ∩ Q)/(ω_2ρ²) = |c| from the formula) gives |c| = k. Hence M_W(C) = k·H²(W ∩ Q) for every open W ⊆ B_{δ'}(p). Together with step 11 (dim Q = 2, p ∈ Q), this proves the statement. ∎

## Key steps

1. θ = k a.e. near p (density_eq_multiplicity_ae), so C = k·C_1 on B_δ(p) with C_1 the multiplicity-one current of M ∩ B_δ(p); C_1 is an integer multiplicity minimizing cycle in B_δ(p) with density 1 at p (competitors scaled by k).
2. density_one_implies_regular gives p ∈ reg C_1: near p, spt C is an embedded C¹ surface M', C = k·m_1[[M']], and approximate tangent planes of the carrier are T_xM'.
3. The angle map F = (|x|, f) of the plane Q = T_pM' ∋ p parametrizes M' near p by G(t, α) = tγ(α), using that spt C is a cone.
4. Stationarity tested with X = ψ_0(f)λ(|x|)ζAx (A the rotation of Q) and the area formula give ∫ψ_0'κ = 0 with κ = |πγ|²/|γ'|, so κ ≡ 1 and γ ⊆ Q by Cauchy–Schwarz: spt C = Q near p.
5. planar_constancy on the restriction gives M_W(C) = k·H²(W ∩ Q) near p.
