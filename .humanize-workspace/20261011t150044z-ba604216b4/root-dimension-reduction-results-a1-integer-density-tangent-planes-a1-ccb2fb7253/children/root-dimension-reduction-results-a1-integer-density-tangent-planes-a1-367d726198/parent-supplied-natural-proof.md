## Proof

Source: steps 7 (support) and 8 (convergence) of the parent proof, with the Jacobian kept abstract. This is the density argument of Simon's proof of Ch. 3, Theorem 1.6 "⇒" (chapter-03.txt lines 109–143). In the parent: F = g, B = A, m = c, J = J_g = areaJacobianAt g with K = Λ^n = L^n (step 2(d)), (iii) is (γ) of step 5, (iv) is the density-point property (α) and (v) is the Lebesgue-point property (β).
Notation: λ := volume (Lebesgue measure) on ℝ^n and λ_ℝ(E) := λ(E) as a real number (toReal); L := DF(b) = fderiv ℝ F b; for r > 0, Φ_r(c) := r^{-1}(F(b + rc) − F(b)); X_r(c) := 1_B(b + rc)·J(b + rc)·f(Φ_r(c)) = B.indicator J (b + r•c)·f(Φ_r(c)); Y(c) := J(b)·f(Lc); I(r) := ∫_{ℝ^n} X_r dλ.
1. (Setup.) f is continuous with compact support, so there is R > 0 with f(w) = 0 whenever |w| ≥ R (HasCompactSupport.exists_pos_le_norm), and there is M with |f(w)| ≤ M for all w (Continuous.bounded_above_of_compact_support); M ≥ |f(0)| ≥ 0. From the hypothesis on J, 0 ≤ J(b) ≤ K, so K ≥ 0. Put D := B̄_{R/m}(0) ⊆ ℝ^n; D is a closed ball, so λ(D) < ∞ (measure_closedBall_lt_top).
2. (Localisation; parent step 7.) Let r > 0 and c ∉ D, i.e. |c| > R/m; since m > 0, R < m|c|.
(a) X_r(c) = 0. If b + rc ∉ B the indicator factor is 0. If b + rc ∈ B, hypothesis (i) with a := b + rc gives m·r|c| = m|(b + rc) − b| ≤ |F(b + rc) − F(b)|, so |Φ_r(c)| = r^{-1}|F(b + rc) − F(b)| ≥ m|c| > R, hence f(Φ_r(c)) = 0.
(b) Y(c) = 0. By (iii), |Lc| ≥ m|c| > R, so f(Lc) = 0.
Hence I(r) = ∫_D X_r dλ and ∫_{ℝ^n} Y dλ = ∫_D Y dλ (setIntegral_eq_integral_of_forall_compl_eq_zero), and ∫_{ℝ^n} Y dλ = J(b)·∫_{ℝ^n} f(Lc) dλ(c) (integral_const_mul).
3. (Measurability, bounds, integrability; fixed r > 0.) c ↦ b + rc is continuous and B.indicator J is Borel (B and J are Borel), so c ↦ B.indicator J (b + rc), g₁(c) := 1_{ℝ^n∖B}(b + rc) = Bᶜ.indicator 1 (b + rc) and g₂(c) := |J(b + rc) − J(b)| are Borel. Since F, f and L are continuous, c ↦ f(Φ_r(c)) and c ↦ f(Lc) are continuous, so X_r, Y and g₃(c) := |f(Φ_r(c)) − f(Lc)| are Borel. Bounds: |B.indicator J (b + rc)| ≤ K, hence |X_r| ≤ KM and |Y| ≤ KM; 0 ≤ g₁ ≤ 1; 0 ≤ g₂ ≤ K (both J-values lie in [0, K]); 0 ≤ g₃ ≤ 2M. A bounded Borel function is integrable on a set of finite measure (Measure.integrableOn_of_bounded), so X_r, Y, g₁, g₂, g₃ are integrable on D.
4. (Pointwise three-term estimate; parent step 8.) Fix r > 0 and c, and write u := f(Φ_r(c)), v := f(Lc), so |u| ≤ M and |v| ≤ M.
(a) If b + rc ∈ B: g₁(c) = 0 and X_r(c) − Y(c) = J(b + rc)u − J(b)v = (J(b + rc) − J(b))u + J(b)(u − v), so |X_r(c) − Y(c)| ≤ M·g₂(c) + J(b)·g₃(c) (using J(b) ≥ 0).
(b) If b + rc ∉ B: g₁(c) = 1 and X_r(c) = 0, so |X_r(c) − Y(c)| = J(b)|v| ≤ KM = KM·g₁(c).
Since all summands are nonnegative, in both cases |X_r(c) − Y(c)| ≤ G_r(c) := KM·g₁(c) + M·g₂(c) + J(b)·g₃(c).
5. (Integrated estimate.) For r > 0 put T₁(r) := ∫_D g₁ dλ = ∫_{B̄_{R/m}(0)} 1_{ℝ^n∖B}(b + rc) dλ(c), T₂(r) := ∫_D g₂ dλ = ∫_{B̄_{R/m}(0)} |J(b + rc) − J(b)| dλ(c) and T₃(r) := ∫_D g₃ dλ = ∫_{B̄_{R/m}(0)} |f(Φ_r(c)) − f(Lc)| dλ(c). By steps 2 and 3, I(r) − J(b)∫ f(Lc) dλ(c) = ∫_D X_r dλ − ∫_D Y dλ = ∫_D (X_r − Y) dλ (integral_sub). By step 4 and integrability of G_r on D, |∫_D (X_r − Y) dλ| ≤ ∫_D G_r dλ (norm_integral_le_of_norm_le), and by linearity (integral_add, integral_const_mul) ∫_D G_r dλ = KM·T₁(r) + M·T₂(r) + J(b)·T₃(r). Hence for every r > 0:
|I(r) − J(b)∫ f(Lc) dλ(c)| ≤ KM·T₁(r) + M·T₂(r) + J(b)·T₃(r).
6. (T₁(r) → 0 from the density point (iv).)
(a) Fix s > 0 and put C_s := B̄_s(b). C_s contains the nonempty open ball B_s(b), so λ(C_s) > 0 (measure_closedBall_pos), and C_s is compact, so λ(C_s) < ∞ (measure_closedBall_lt_top); thus λ_ℝ(C_s) > 0. As ℝ^n∖B is Borel, ∫_{C_s} 1_{ℝ^n∖B} dλ = λ_ℝ(C_s ∖ B) (setIntegral_indicator, setIntegral_const), and λ_ℝ(C_s ∩ B) + λ_ℝ(C_s ∖ B) = λ_ℝ(C_s) (measureReal_inter_add_sdiff). By setAverage_eq, ⨍_{C_s} 1_{ℝ^n∖B} dλ = λ_ℝ(C_s)^{-1}(λ_ℝ(C_s) − λ_ℝ(B ∩ C_s)) = 1 − λ_ℝ(B ∩ C_s)/λ_ℝ(C_s) = 1 − q(s).toReal, where q(s) := λ(B ∩ C_s)/λ(C_s) ∈ [0, ∞] and (x/y).toReal = x.toReal/y.toReal (ENNReal.toReal_div).
(b) By (iv), q(s) → 1 as s → 0⁺; toReal is continuous at 1 ≠ ∞ (ENNReal.tendsto_toReal), so 1 − q(s).toReal → 0. The identity of (a) holds on (0, ∞) ∈ 𝓝[>] 0 (self_mem_nhdsWithin), so ⨍_{B̄_s(b)} 1_{ℝ^n∖B} dλ → 0 as s → 0⁺ (Tendsto.congr').
(c) Apply the sibling pit_integral_closedBall_rescale_tendsto with h := 1_{ℝ^n∖B} = Bᶜ.indicator (fun _ => 1), the point b and the radius R/m > 0; its hypothesis is (b). It gives T₁(r) → 0 as r → 0⁺.
7. (T₂(r) → 0 from the Lebesgue point (v).) Apply the same sibling with h(a) := |J(a) − J(b)| = ‖J a − J b‖, the point b and the radius R/m > 0; its hypothesis is exactly (v). It gives T₂(r) → 0 as r → 0⁺.
8. (T₃(r) → 0 from differentiability (ii).) Let ε > 0; put V := λ_ℝ(D) ≥ 0, ε₁ := ε/(V + 1) > 0 and S := R/m + 1 > 0, so |c| ≤ R/m < S for c ∈ D.
(a) f is uniformly continuous (HasCompactSupport.uniformContinuous_of_continuous), so there is η > 0 with |f(w) − f(w')| < ε₁ whenever |w − w'| < η (Metric.uniformContinuous_iff).
(b) Put θ := η/(2S) > 0. By (ii), F(b + k) − F(b) − Lk = o(|k|) as k → 0 (hasFDerivAt_iff_isLittleO_nhds_zero), so there is δ₀ > 0 with |F(b + k) − F(b) − Lk| ≤ θ|k| whenever |k| < δ₀ (Metric.eventually_nhds_iff).
(c) Let 0 < r < δ₀/S and c ∈ D. Then |rc| = r|c| < rS < δ₀, and since L(rc) = rLc and r ≠ 0, Φ_r(c) − Lc = r^{-1}(F(b + rc) − F(b) − L(rc)); therefore |Φ_r(c) − Lc| ≤ r^{-1}θ|rc| = θ|c| ≤ θS = η/2 < η, and by (a) g₃(c) < ε₁.
(d) Hence for 0 < r < δ₀/S, 0 ≤ T₃(r) (integral_nonneg) and |T₃(r)| ≤ ε₁·V (norm_setIntegral_le_of_norm_le_const, λ(D) < ∞), so 0 ≤ T₃(r) ≤ εV/(V + 1) < ε. As ε > 0 was arbitrary, T₃(r) → 0 as r → 0⁺ (Metric.tendsto_nhdsWithin_nhds).
9. (Conclusion.) By steps 5–8, for every r > 0, 0 ≤ |I(r) − J(b)∫ f(Lc) dλ(c)| ≤ KM·T₁(r) + M·T₂(r) + J(b)·T₃(r), and the right side tends to KM·0 + M·0 + J(b)·0 = 0 as r → 0⁺. Hence |I(r) − J(b)∫ f(Lc) dλ(c)| → 0 (squeeze_zero' on 𝓝[>] 0, using that (0, ∞) ∈ 𝓝[>] 0), i.e. I(r) → J(b)·∫_{ℝ^n} f(Lc) dλ(c) as r → 0⁺ (tendsto_iff_norm_sub_tendsto_zero). This is the claim. 6. Squeeze: I(r) → J(b)·∫ f(Lc) dλ(c) as r → 0⁺.
