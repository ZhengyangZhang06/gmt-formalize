𝓑' is countable, since its members are disjoint and each has positive measure for the finite measure Hⁿ⌞(M ∩ A₂); enumerate it as B_j = B̄_{ρ_j}(x_j). Then Σ_jω_nρ_jⁿ ≤ τ₀⁻¹Σ_jHⁿ(M ∩ A₂ ∩ B_j) ≤ τ₀⁻¹Hⁿ(M ∩ A₂) < ∞. Simon 3.5: for every N, A₁∖⋃_{j≤N}B_j ⊆ ⋃_{j>N}B̄_{5ρ_j}(x_j) — indeed for x ∈ A₁∖⋃_{j≤N}B_j the complement of the closed set ⋃_{j≤N}B_j is a neighbourhood of x, so (fineness) some B ∈ 𝓑 contains x and is disjoint from B_1, …, B_N; the B' ∈ 𝓑' it meets with radius(B) ≤ 2·radius(B') is some B_j with j > N, and x ∈ B ⊆ B̂_j.
