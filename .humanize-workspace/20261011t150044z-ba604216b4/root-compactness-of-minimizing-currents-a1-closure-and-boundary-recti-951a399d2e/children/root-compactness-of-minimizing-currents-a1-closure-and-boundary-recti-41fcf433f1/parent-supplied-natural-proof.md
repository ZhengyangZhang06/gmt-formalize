2. (Extension of v to an orthonormal basis.) Define v' : Fin P → ℝ^P by v'(ι i) := v_i and v'(m) := 0 for m ∉ range ι, and s := range ι. The restriction s.domRestrict v' is v reindexed by the bijection Fin n ≃ s induced by ι, hence orthonormal. By Orthonormal.exists_orthonormalBasis_extension_of_card_eq (finrank (Euclid P) = P = card (Fin P)) there is f : OrthonormalBasis (Fin P) ℝ (Euclid P) with f(ι i) = v_i for all i ∈ Fin n.
3. (pL on the basis.) For i ∈ Fin n: (pL f(ι i))_k = ⟨v_k, v_i⟩ = δ_{ki}, so pL(f(ι i)) = e_i (ext on Euclid n). For m ∉ range ι, f_m is orthogonal to every f(ι k) = v_k (distinct members of an orthonormal basis), so (pL f_m)_k = ⟨v_k, f_m⟩ = 0 for all k, i.e. pL f_m = 0.
4. (Proof of (b).) Let α := γ∘pL ∈ Λ^l(ℝ^P). By (★) on ℝ^P with b := f: l!·|α|² = Σ_{j : Fin l → Fin P} γ(pL f_{j(1)}, …, pL f_{j(l)})². If some value j(k) ∉ range ι, the k-th argument pL f_{j(k)} is 0 and the term vanishes (multilinearity, ContinuousMultilinearMap.map_coord_zero). The remaining j are exactly ι∘j' with j' : Fin l → Fin n (bijectively, ι injective), and for them the term is γ(e∘j')² by step 3. Hence l!·|α|² = Σ_{j' : Fin l → Fin n} γ(e∘j')² = l!·|γ|² by (★) on ℝⁿ with the standard orthonormal basis EuclideanSpace.basisFun (Fin n) ℝ. Since l! > 0 and both norms are ≥ 0 (covectorEuclideanNorm_nonneg), |γ∘pL| = |γ|, in particular |γ∘pL| ≤ |γ|. (Formally: the sum over Fin l → Fin P splits as the sum over the image of j' ↦ ι∘j' (Finset.sum_image, injective) plus terms that are 0 (Finset.sum_subset).)
5. (Proof of (a).) By (★) on ℝ^P with b := f and l := n: n!·|β|² = Σ_{j : Fin n → Fin P} β(f∘j)². All terms are ≥ 0, and π ↦ ι∘π is an injective map Perm(Fin n) → (Fin n → Fin P), so the sum is ≥ Σ_{π ∈ Perm(Fin n)} β(f∘ι∘π)² (Finset.sum_le_sum_of_subset_of_nonneg after Finset.sum_image). For every π, f∘ι∘π = v∘π (step 2) and β(v∘π) = sign(π)·β(v) (AlternatingMap.map_perm applied to β.toAlternatingMap), so each of these n! terms equals β(v)². Hence n!·|β|² ≥ n!·β(v)², so β(v)² ≤ |β|² and, as |β| ≥ 0, |β(v)| ≤ |β| (abs_le_of_sq_le / sq_le_sq'). ∎

## Key steps

1. Orthonormality gives n ≤ P; extend v to an orthonormal basis f of ℝ^P with f∘castLE = v.
2. pL maps f(castLE i) to e_i and every other basis vector to 0.
3. Apply the identity Σ_j α(f∘j)² = l!|α|² to α = γ∘pL on ℝ^P and to γ on ℝⁿ: the sums coincide, so |γ∘pL| = |γ|.
4. For β on ℝ^P the n! permutation tuples v∘π each contribute β(v)², so n!|β|² ≥ n!β(v)² and |β(v)| ≤ |β|.
