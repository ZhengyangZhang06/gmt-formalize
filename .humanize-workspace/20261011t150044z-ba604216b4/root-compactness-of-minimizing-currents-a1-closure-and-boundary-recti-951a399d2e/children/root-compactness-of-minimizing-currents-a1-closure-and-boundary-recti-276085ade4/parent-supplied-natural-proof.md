Source: steps 0 and 1 of the parent proof (g := dist(·, V₀ + w), δ' := min_{j≠i₀}|w_j − w|/3, compactness of p⁻¹(B̄_{3R}) ∩ {δ' ≤ g ≤ 2δ'}).
1. (Orthogonal decomposition.) For x ∈ ℝ^P put Q(x) := x − Σ_j ⟨v_j, x⟩v_j. Q is linear, ⟨v_k, Q x⟩ = ⟨v_k, x⟩ − Σ_j ⟨v_j, x⟩⟨v_k, v_j⟩ = 0, and x = Σ_j ⟨v_j, x⟩v_j + Q x with orthogonal summands, so ‖x‖² = ‖Σ_j ⟨v_j, x⟩v_j‖² + ‖Q x‖² = ‖pL x‖² + ‖Q x‖² (Pythagoras, norm_add_sq_eq_norm_sq_add_norm_sq_of_inner_eq_zero; ‖Σ_j c_j v_j‖² = Σ_j c_j² = ‖pL x‖² for c_j = ⟨v_j, x⟩ = (pL x)_j). In particular ‖Q x‖ ≤ ‖x‖. If y ∈ V₀, y = Σ_j c_j v_j, then ⟨v_j, y⟩ = c_j and Q y = 0; if y ⊥ v_j for all j then Q y = y.
2. (Definition of g.) Let w := w_{i₀} and g(x) := ‖Q(x − w)‖ ≥ 0. Since Q is linear, |g x − g x'| ≤ ‖Q(x − x')‖ ≤ ‖x − x'‖ (abs_norm_sub_norm_le), so g is 1-Lipschitz (LipschitzWith.of_dist_le_mul), in particular continuous.
3. (Values on the planes.) Let y ∈ Π_j. Then Q(y − w) = Q(y − w_j) + Q(w_j − w) = 0 + (w_j − w), because y − w_j ∈ V₀ and w_j − w ⊥ v_k for all k (⟨w_j, v_k⟩ = ⟨w, v_k⟩ = 0). Hence g ≡ ‖w_j − w‖ on Π_j: g = 0 on Π_{i₀}, and g > 0 on Π_j for j ≠ i₀ (w injective).
4. (Choice of δ.) The finitely many numbers ‖w_j − w‖, j ≠ i₀, are positive. Let δ := (1/3)·min_{j ∈ Fin N} c_j with c_j := 1 if j = i₀ and c_j := ‖w_j − w‖ otherwise (Finset.univ.inf' over the nonempty Fin N, which contains i₀). Then δ > 0 and 3δ ≤ ‖w_j − w‖ for j ≠ i₀, so Π_j ∩ {g < 3δ} = ∅ for j ≠ i₀, while Π_{i₀} ⊆ {g = 0} ⊆ {g < 3δ}.
5. (The restriction.) {g < 3δ} is open, hence measurable. For a measurable set B: ν⌞{g<3δ}(B) = ν(B ∩ {g<3δ}) = Σ_i ofReal(α_i)·Hⁿ(B ∩ {g<3δ} ∩ Π_i) (Measure.restrict_apply, Measure.coe_finset_sum / Finset.sum_apply, Measure.smul_apply, Measure.restrict_apply). For i ≠ i₀ the set {g<3δ} ∩ Π_i is empty and the term is 0; for i = i₀, {g<3δ} ∩ Π_{i₀} = Π_{i₀}. Hence ν⌞{g<3δ}(B) = ofReal(α_{i₀})·Hⁿ(B ∩ Π_{i₀}) for every measurable B (Finset.sum_eq_single), i.e. ν⌞{g<3δ} = ofReal(α_{i₀})·Hⁿ⌞Π_{i₀} (Measure.ext).
6. (Compactness.) K_{t,r} := {g ≤ t} ∩ pL⁻¹(closedBall(0, r)) is closed (g and pL continuous). For x ∈ K_{t,r}, step 1 applied to x − w gives ‖x − w‖² = ‖pL x − pL w‖² + g(x)² ≤ (r + ‖pL w‖)² + max(t, 0)², so K_{t,r} is bounded; ℝ^P is proper, hence K_{t,r} is compact (Metric.isCompact_of_isClosed_isBounded). ∎
