## Proof

Source: step 11(a) of the parent proof ((u_k∗φ_{s₀})(x) = Y_k(φ_{s₀}(x − ·)dy) → θ₀α pointwise, equi-Lipschitz with constant Λ·Lip(φ_{s₀}), hence uniformly on the compact B̄_R).
1. (Regularity of φ.) tsupport φ ⊆ B_s(0) is closed and bounded, hence compact, so φ has compact support; φ is C¹, hence Lipschitz with some constant L_φ ≥ 0 (ContDiff.lipschitzWith_of_hasCompactSupport).
2. (Pointwise convergence.) Fix x ∈ closedBall(0, R) and b_x(y) := φ(x − y). b_x is smooth (composition with the affine map y ↦ x − y) and tsupport b_x = x − tsupport φ ⊆ {x − z : ‖z‖ < s} = B_s(x) ⊆ B_{R+s}(0) ⊆ B_{2R}(0) because s < R; it is compact (image of a compact set under a homeomorphism). Moreover ∫b_x = ∫φ(x − y)dy = ∫φ (integral_sub_left_eq_self: volume on Euclid n is an additive Haar measure, invariant under y ↦ x − y). By hypothesis w_k(x) = ∫_{B_{2R}}u_k b_x → c∫b_x = c∫φ.
3. (Equi-Lipschitz.) Let k be large enough that ∫_{B_{2R}}|u_k| ≤ Λ (then Λ ≥ 0). For all x, x': |w_k(x) − w_k(x')| ≤ ∫_{B_{2R}}|u_k(y)||φ(x − y) − φ(x' − y)|dy ≤ L_φ‖x − x'‖∫_{B_{2R}}|u_k| ≤ L_φΛ‖x − x'‖ (integral_sub, norm_integral_le_integral_norm, integral_mono with the Lipschitz bound; the integrands are integrable since u_k is integrable on B_{2R} and φ is bounded).
4. (Uniformity.) Let ε > 0 and η > 0 with (L_φ max(Λ, 0) + 1)η < ε/3. closedBall(0, R) is compact, so there are x_1, …, x_m ∈ closedBall(0, R) whose η-balls cover it (IsCompact.finite_cover_balls / totally bounded). By step 2 choose k₁ with |w_k(x_i) − c∫φ| < ε/3 for all i and k ≥ k₁, and by hypothesis k₂ such that the Λ-bound holds for k ≥ k₂. For k ≥ max(k₁, k₂) and x ∈ closedBall(0, R) pick i with ‖x − x_i‖ < η; by step 3, |w_k(x) − c∫φ| ≤ |w_k(x) − w_k(x_i)| + |w_k(x_i) − c∫φ| < ε/3 + ε/3 < ε. This is TendstoUniformlyOn (Metric.tendstoUniformlyOn_iff) of w_k to the constant c∫φ on closedBall(0, R). ∎

## Key steps

1. φ has compact support and is Lipschitz.
2. For x ∈ B̄_R, b_x = φ(x − ·) is a test function in B_{2R} with ∫b_x = ∫φ, so w_k(x) → c∫φ.
3. The w_k are eventually equi-Lipschitz with constant L_φΛ.
4. Pointwise convergence on a finite η-net of the compact B̄_R plus equicontinuity gives uniform convergence.
