1. (1) Let X ∈ NC_k(ℝ^N) and ω ∈ 𝒟^k(ℝ^N). Apply CHAR with Λ = 1, F = id (LipschitzWith 1 id), Fs_j := id (C^∞, ‖fderiv ℝ id x‖ = ‖ContinuousLinearMap.id‖ ≤ 1 =: Λ', a constant sequence equal to its limit converges uniformly) and ηs_j := ω (on W = univ, ω(x) = (ω(id x)).compContinuousLinearMap (ContinuousLinearMap.id) = ω(x)). The constant sequence X(ω) therefore converges to lpush N N k id X (ω), so lpush id X (ω) = X(ω) (tendsto_nhds_unique); GeometricCurrentOn.ext gives (1).
2. (2) Let F be Λ-Lipschitz and X, Y ∈ NC_k. By (NCD), X − Y ∈ NC_k and spt(X − Y) ⊆ spt X ∪ spt Y. Fix ω and take standard approximants with K := spt X ∪ spt Y. CHAR for X, Y and X − Y (all supports lie in W_j) gives X(η_j) → lpush F X ω, Y(η_j) → lpush F Y ω and (X − Y)(η_j) = X(η_j) − Y(η_j) → lpush F (X − Y) ω. Uniqueness of limits gives lpush F (X − Y) ω = lpush F X ω − lpush F Y ω = (lpush F X − lpush F Y)(ω); ext.
3. (3) Let F, G be Λ-Lipschitz with F = G on spt X. Take standard approximants (K = spt X). F_j → F uniformly on spt X, and since G = F there also F_j → G uniformly on spt X. CHAR for (F, F_j, η_j) and for (G, F_j, η_j) gives X(η_j) → lpush F X ω and X(η_j) → lpush G X ω; uniqueness of limits and ext give (3).
4. (4) Let F be Λ-Lipschitz and X ∈ NC_k.
4.1. Mass. Let ω and c satisfy |ω(y)| ≤ c for all y; take standard approximants (K = spt X). For x ∈ spt X ⊆ W_j, (L1) gives |η_j(x)| = |(ω(F_j x)).compContinuousLinearMap (DF_j x)| ≤ ‖DF_j(x)‖^k|ω(F_j x)| ≤ Λ^k c. By (A0), |X(η_j)| ≤ Λ^k c M(X).toReal; by CHAR and passage to the limit, |lpush F X ω| ≤ (Λ^k M(X).toReal)·c. By (MB), M(lpush F X) ≤ ofReal(Λ^k M(X).toReal) = (Λ : ℝ≥0∞)^k·M(X) (ENNReal.ofReal_mul, ENNReal.ofReal_pow, ENNReal.ofReal_coe_nnreal, ENNReal.ofReal_toReal since M(X) ≠ ∞).
4.2. Support. E := F '' spt X is compact, hence closed. By support_calculus (a) it suffices to show lpush F X ω = 0 whenever tsupport ω is disjoint from E. Then (tsupport ω)ᶜ is an open set containing the compact E, so IsCompact.exists_thickening_subset_open gives r > 0 with thickening r E ⊆ (tsupport ω)ᶜ. Choose j₀ with Λ/(j+1) < r for j ≥ j₀. For j ≥ j₀ and x ∈ spt X, dist(F_j x, F x) < r, so F_j(x) ∈ thickening r E and F_j(x) ∉ tsupport ω. Let V_j := W_j ∩ F_j⁻¹((tsupport ω)ᶜ), open and containing spt X. For x ∈ V_j, ω(F_j x) = 0 (image_eq_zero_of_notMem_tsupport), so η_j(x) = 0. By (LOC) with η' = 0, X(η_j) = X(0) = 0 for j ≥ j₀, and CHAR gives lpush F X ω = lim X(η_j) = 0. Hence spt(lpush F X) ⊆ F '' spt X.
5. (5) Let F be Λ-Lipschitz and X ∈ 𝒟_{k+1} with compact support, M(X) < ∞, M(∂X) < ∞; then X ∈ NC_{k+1} (boundaryMassOn X univ = M(∂X)) and, by (NCB), ∂X ∈ NC_k with spt ∂X ⊆ spt X. Fix ω ∈ 𝒟^k(ℝ^{N'}) and take standard approximants η_j (K = spt X) with η_j = F_j^#ω and dη_j = F_j^#(dω) on W_j. CHAR for X, the form dω and the test forms dη_j = exteriorDerivativeTestOn univ k η_j gives X(dη_j) → lpush F X (dω) = ∂(lpush F X)(ω) (boundary_apply). CHAR for ∂X, ω and η_j (W_j ⊇ spt X ⊇ spt ∂X) gives ∂X(η_j) → lpush F (∂X) ω. As ∂X(η_j) = X(dη_j), uniqueness of limits gives ∂(lpush F X)(ω) = lpush F (∂X)(ω); ext.
6. (6) Let F be Λ-Lipschitz and X ∈ NC_k. Take Fs := (F_j) from mollify: C^∞, Λ-Lipschitz, TendstoUniformly F_j F (dist ≤ Λ/(j+1) → 0 uniformly). Given ω, let η_j be standard approximants for K = spt X; η_j = F_j^#ω on the open W_j ⊇ spt X, and CHAR gives X(η_j) → lpush F X ω.
