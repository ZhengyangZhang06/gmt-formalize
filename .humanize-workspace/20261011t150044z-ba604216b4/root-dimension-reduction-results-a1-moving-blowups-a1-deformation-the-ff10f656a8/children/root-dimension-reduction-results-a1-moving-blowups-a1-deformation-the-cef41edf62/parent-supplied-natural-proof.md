## Proof

0. Common setup. Let F, G be Λ-Lipschitz, H L-Lipschitz and X a current of the relevant degree with compact support and finite mass such that H(ι(t,x)) = F(x) + t•(G(x) − F(x)) for x ∈ spt X, t ∈ [0,1]. S := S(X) is compact (continuous image of Icc 0 1 ×ˢ spt X). The sibling mollify gives C^∞ Λ-Lipschitz F_j, G_j with dist(F_j x, F x), dist(G_j x, G x) ≤ Λ/(j+1) and ‖DF_j‖, ‖DG_j‖ ≤ Λ; the sibling affine_homotopy (i) gives C^∞ H_j with H_j(ι(t,x)) = F_j(x) + t•(G_j(x) − F_j(x)) for all t, x. Since spt X is compact and G − F is continuous, there is D₀ ≥ 0 with ‖G(x) − F(x)‖ ≤ D₀ for x ∈ spt X (IsCompact.exists_bound_of_continuousOn).
0.1. Uniform convergence on S: for y = ι(t,x) ∈ S, H_j(y) − H(y) = (1 − t)(F_j x − F x) + t(G_j x − G x), so ‖H_j(y) − H(y)‖ ≤ (1 − t)Λ/(j+1) + tΛ/(j+1) = Λ/(j+1) → 0; hence H_j → H uniformly on S and on every subset.
0.2. Derivative bound on S: for y = ι(t,x) ∈ S, the norm part of affine_homotopy (ii) gives ‖DH_j(y)‖ ≤ ‖G_j x − F_j x‖ + ‖DF_j(x) + t•(DG_j(x) − DF_j(x))‖ ≤ (Λ/(j+1) + D₀ + Λ/(j+1)) + ((1 − t)Λ + tΛ) ≤ Λ' := D₀ + 3Λ.
0.3. For a test form β on ℝ^{N'} the sibling cutoff (H_j, β, K = S) gives θ_j(β) with θ_j(β) = H_j^#β on an open W_j ⊇ S. Consequently, for every NC current Y on ℝ^{N+1} with spt Y ⊆ S, CHAR (H L-Lipschitz, Fs := H_j, Λ' from 0.2, uniform convergence on spt Y from 0.1, ηs_j := θ_j(β)) gives Y(θ_j(β)) → lpush H Y β.
0.4. With ηF_j, ηG_j := cutoff pull-backs of ω by F_j, G_j near spt X, CHAR for F (Fs := F_j, Λ' := Λ) and for G gives X(ηF_j) → lpush F X ω and X(ηG_j) → lpush G X ω.
1. (10) Degree 0: X ∈ NC_0 (boundaryMassOn = 0 in degree 0). By (C1), cyl(X) ∈ NC_{0+1}(ℝ^{N+1}) (compact support, mass ≤ M(X) < ∞, boundary mass < ∞) with spt cyl(X) ⊆ S. Fix ω ∈ 𝒟^0(ℝ^{N'}). The sibling smooth_identity (degree 0) for F_j, G_j, H_j, C := cyl(X) (relation (C4)), ω, ηF_j, ηG_j and θ_j := θ_j(dω) gives X(ηG_j) − X(ηF_j) = cyl(X)(θ_j). By 0.4 the left side tends to lpush G X ω − lpush F X ω; by 0.3 the right side tends to lpush H (cyl X)(dω) = ∂(lpush H (cyl X))(ω). Uniqueness of limits and ext give (10).
2. (11) Degree k+1: X ∈ NC_{k+1} (boundaryMassOn X univ = M(∂X)); by the toolkit (NCB), ∂X ∈ NC_k with spt ∂X ⊆ spt X; by (C1), cyl(X) and cyl(∂X) are NC with supports in S(X) and S(∂X) ⊆ S. Fix ω ∈ 𝒟^{k+1}(ℝ^{N'}). smooth_identity (degree k+1) with C := cyl(X), C' := cyl(∂X) (relation (C5)), θ_j := θ_j(dω), θ'_j := θ_j(ω) gives X(ηG_j) − X(ηF_j) = cyl(X)(θ_j) + cyl(∂X)(θ'_j). Passing to the limit (0.4, and 0.3 for Y = cyl X and Y = cyl ∂X): lpush G X ω − lpush F X ω = ∂(lpush H (cyl X))(ω) + lpush H (cyl ∂X)(ω). Rearranging and ext give (11).
3. (12) Degree k: X ∈ NC_k and dist(F x, G x) ≤ δ on spt X. Put δ⁺ := max(δ, 0). Fix ω ∈ 𝒟^{k+1}(ℝ^{N'}) and c with |ω(y)| ≤ c for all y. For x ∈ spt X, dist(F_j x, G_j x) ≤ Λ/(j+1) + δ + Λ/(j+1) ≤ δ_j := δ⁺ + 2Λ/(j+1). smooth_mass with F_j, G_j, H_j, X, C := cyl(X) (relation (C3)), Λ, δ_j, b := c, β := ω and θ := θ_j(ω) (θ_j(ω)(ι(t,x)) = H_j^#ω(ι(t,x)) for t ∈ [0,1], x ∈ spt X, as ι(t,x) ∈ S ⊆ W_j) gives |cyl(X)(θ_j(ω))| ≤ δ_j Λ^k c M(X).toReal. By 0.3 (Y = cyl X) cyl(X)(θ_j(ω)) → lpush H (cyl X) ω, hence |lpush H (cyl X) ω| ≤ (δ⁺ Λ^k M(X).toReal)·c. The toolkit (MB) gives M(lpush H (cyl X)) ≤ ofReal(δ⁺ Λ^k M(X).toReal) = ofReal δ⁺ · (Λ:ℝ≥0∞)^k · M(X) = ofReal δ · Λ^k · M(X) ≤ ofReal δ · (2Λ)^k · M(X) (ENNReal.ofReal_mul with δ⁺ ≥ 0, ENNReal.ofReal_pow, ENNReal.ofReal_coe_nnreal, ENNReal.ofReal_toReal as M(X) < ∞, ofReal (max δ 0) = ofReal δ, and Λ^k ≤ (2Λ)^k in ℝ≥0∞ by pow_le_pow_left).

## Key steps
