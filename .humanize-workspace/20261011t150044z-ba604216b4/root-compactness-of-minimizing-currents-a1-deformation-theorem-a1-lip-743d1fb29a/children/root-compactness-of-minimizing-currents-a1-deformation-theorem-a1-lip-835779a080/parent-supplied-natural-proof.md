1. (Injectivity criterion.) For a continuous linear map T : ℝⁿ → ℝ^P, T is injective iff the family (Te_a)_{a ∈ Fin n} is linearly independent. If T is injective, (Te_a) is the image of the basis (e_a) under a linear map with zero kernel, hence linearly independent (LinearIndependent.map'). Conversely, if (Te_a) is linearly independent and Tw = 0, write w = Σ_a w_a e_a; then Σ_a w_a Te_a = 0, so every w_a = 0 and w = 0 (Mathlib LinearMap.injective_of_linearIndependent, using that the e_a span ℝⁿ).
2. (A⁺ is Borel.) A⁺ = A ∩ D ∩ I ∩ g⁻¹(ℤ ∖ {0}) with D := {u : H is differentiable at u} and I := {u : DH(u) is injective}. D is Borel (measurableSet_of_differentiableAt). The set O of injective continuous linear maps ℝⁿ → ℝ^P is open: by step 1 it is the preimage of the open set of linearly independent n-families in (ℝ^P)ⁿ (isOpen_setOfPred_linearIndependent) under the continuous map T ↦ (Te_a)_a. Since u ↦ DH(u) is Borel (measurable_fderiv) and O is open, I = DH⁻¹(O) is Borel. g⁻¹(ℤ ∖ {0}) is measurable because g is. Hence A⁺ is Borel. (This is the Borel condition named in the supplied proof; it is verified here through openness of injectivity rather than through the Gram determinant.)
3. (Ψ_ω is Borel.) The supplied proof obtains this from the Borel measurability of u ↦ DH(u) and the continuity of evaluation; concretely: for z ∈ (ℝ^P)ⁿ write z_{a,i} for the i-th coordinate of z_a, so z_a = Σ_i z_{a,i} e'_i. Multilinearity gives, for every n-covector β on ℝ^P, β(z) = Σ_{f : Fin n → Fin P} (∏_a z_{a,f(a)})·β(e'_{f(0)}, …, e'_{f(n−1)}). Apply it with β := ω(H(u)) and z := v(u). Each coefficient u ↦ ∏_a (f(a)-th coordinate of DH(u)e_a) is Borel (u ↦ DH(u)e_a is Borel by measurable_fderiv_apply_const, and coordinates are continuous linear), and u ↦ ω(H(u))(e'_{f(0)}, …, e'_{f(n−1)}) is continuous (ω and H are continuous, and evaluation at a fixed tuple is a continuous linear functional on covectors). So u ↦ ω(H(u))(v(u)) is a finite sum of Borel functions, and Ψ_ω = g·ω(H(·))(v(·)) is Borel.
4. (Bound and integrability.) ω is continuous with compact support, so C_ω := sup_y ‖ω(y)‖ < ∞ (operator norm; HasCompactSupport.exists_bound_of_continuous). For every u, ‖DH(u)‖ ≤ L (norm_fderiv_le_of_lipschitz; this also holds where H is not differentiable, DH(u) being 0 there), so |DH(u)e_a| ≤ ‖DH(u)‖·|e_a| ≤ L. By the operator-norm bound for continuous alternating maps (ContinuousAlternatingMap.le_opNorm), |ω(H(u))(v(u))| ≤ ‖ω(H(u))‖·∏_a |DH(u)e_a| ≤ C_ω·Lⁿ. Hence |Ψ_ω(u)| ≤ C_ω·Lⁿ·|g(u)| for every u. The right-hand side is integrable on A because g is, and Ψ_ω is measurable by step 3, so Ψ_ω is integrable on A (Integrable.mono').
5. (Ψ_ω vanishes a.e. on A ∖ A⁺.) By Rademacher's theorem (LipschitzWith.ae_differentiableAt), H is differentiable at λ-a.e. u ∈ ℝⁿ. Let u ∈ A ∖ A⁺ be such a point. Since u ∈ A and H is differentiable at u, u ∉ A⁺ means that g(u) = 0 or DH(u) is not injective. If g(u) = 0, then Ψ_ω(u) = 0. Otherwise v(u) is linearly dependent by step 1, and an alternating map vanishes on a linearly dependent family (AlternatingMap.map_linearDependent applied to ω(H(u))), so ω(H(u))(v(u)) = 0 and Ψ_ω(u) = 0.
6. (Conclusion.) A is measurable, A⁺ ⊆ A, and by step 5, for λ-a.e. u, u ∈ A ∖ A⁺ implies Ψ_ω(u) = 0. Hence ∫_A Ψ_ω dλ = ∫_{A⁺} Ψ_ω dλ (setIntegral_eq_of_subset_of_ae_sdiff_eq_zero). Together with steps 2 and 4 this proves the statement. ∎

## Key steps

1. T is injective iff (Te_a)_a is linearly independent; hence {u : DH(u) injective} is the Borel preimage of an open set under u ↦ DH(u), and A⁺ is Borel.
2. The coordinate expansion β(z) = Σ_f (∏_a z_{a,f(a)}) β(e'∘f) shows that Ψ_ω is Borel.
3. ‖ω‖ ≤ C_ω, ‖DH‖ ≤ L and the operator-norm bound give |Ψ_ω| ≤ C_ω Lⁿ |g|, so Ψ_ω is integrable on A.
4. Rademacher and the vanishing of alternating maps on dependent families give Ψ_ω = 0 a.e. on A ∖ A⁺, hence ∫_A Ψ_ω = ∫_{A⁺} Ψ_ω.
