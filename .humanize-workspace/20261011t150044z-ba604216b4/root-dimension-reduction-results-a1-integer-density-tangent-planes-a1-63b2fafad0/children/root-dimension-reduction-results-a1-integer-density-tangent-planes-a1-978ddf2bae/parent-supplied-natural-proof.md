## Proof

Role: this is steps 1 and 3 of the parent-supplied proof (smooth plateau functions and the dominated-convergence passage), stated for one fixed pair p, q and an arbitrary integrable g. No assumption p < q is needed.
1. (Smooth transition.) Let σ := Real.smoothTransition. It is C^∞ (Real.smoothTransition.contDiff), satisfies 0 ≤ σ(x) ≤ 1 for all x (Real.smoothTransition.nonneg, Real.smoothTransition.le_one), σ(x) = 0 for x ≤ 0 (Real.smoothTransition.zero_of_nonpos) and σ(x) = 1 for x ≥ 1 (Real.smoothTransition.one_of_one_le).
2. (Definition.) For k ∈ ℕ, regarded as a real number k ≥ 0, put χ_k(α) := σ(k(α − p))·σ(k(q − α)). We show that the sequence (χ_k) has the three required properties; the same sequence works for every g.
3. (C¹.) The maps α ↦ k(α − p) and α ↦ k(q − α) are affine, hence C^∞ (contDiff_const.mul (contDiff_id.sub contDiff_const), resp. contDiff_const.mul (contDiff_const.sub contDiff_id)). Composing with σ gives C¹ functions (ContDiff.comp), and their product χ_k is C¹ (ContDiff.mul). In particular χ_k is continuous. This proves the first conjunct.
4. (Vanishing off (p, q).) Let α ∉ (p, q); then α ≤ p or q ≤ α. If α ≤ p, then k(α − p) ≤ 0 (a product of k ≥ 0 and α − p ≤ 0), so σ(k(α − p)) = 0 and χ_k(α) = 0. If q ≤ α, then k(q − α) ≤ 0, so σ(k(q − α)) = 0 and χ_k(α) = 0. Hence support χ_k ⊆ (p, q) ⊆ [p, q]. Since [p, q] is closed, tsupport χ_k = closure(support χ_k) ⊆ [p, q] (closure_minimal, isClosed_Icc). This proves the second conjunct. (If q ≤ p, then χ_k ≡ 0 and tsupport χ_k = ∅.)
5. (Bound.) For all k and α, 0 ≤ χ_k(α) ≤ 1·1 = 1, a product of two numbers in [0, 1]. Hence |χ_k(α)·g(α)| ≤ |g(α)| for every function g and every α.
6. (Pointwise limit.) Let g : ℝ → ℝ be any function and fix α. If p < α < q, then α − p > 0 and q − α > 0; choose N ∈ ℕ with N ≥ max(1/(α − p), 1/(q − α)) (exists_nat_ge). For k ≥ N we get k(α − p) ≥ (1/(α − p))(α − p) = 1 and likewise k(q − α) ≥ 1, so χ_k(α) = 1·1 = 1 and χ_k(α)g(α) = g(α) = 1_{(p,q)}(α)g(α) for all k ≥ N. If α ∉ (p, q), then by step 4, χ_k(α)g(α) = 0 = 1_{(p,q)}(α)g(α) for all k. In both cases χ_k(α)g(α) → (1_{(p,q)}·g)(α) as k → ∞, where 1_{(p,q)}·g is the function equal to g on (p, q) and to 0 elsewhere (Set.indicator).
7. (Dominated convergence.) Now let g be integrable. Each χ_k·g is a.e.-strongly measurable (χ_k is continuous and g is a.e.-strongly measurable, being integrable); |χ_k·g| ≤ |g| everywhere (step 5) and |g| is integrable; and χ_k·g → 1_{(p,q)}·g at every point (step 6). By the dominated convergence theorem (tendsto_integral_of_dominated_convergence with bound |g|), ∫_ℝ χ_k(α)g(α) dα → ∫_ℝ (1_{(p,q)}·g)(α) dα as k → ∞. Since (p, q) is measurable, ∫_ℝ 1_{(p,q)}·g = ∫_{(p,q)} g (integral_indicator, measurableSet_Ioo). This proves the third conjunct. ∎

## Key steps

1. Define χ_k(α) = σ(k(α−p))·σ(k(q−α)) with σ = Real.smoothTransition; it is C¹ as a product of compositions of σ with affine maps.
2. If α ≤ p or α ≥ q one argument of σ is ≤ 0, so χ_k vanishes off (p,q) and tsupport χ_k ⊆ [p,q] by closure_minimal.
3. 0 ≤ χ_k ≤ 1, hence |χ_k g| ≤ |g|.
4. For p<α<q, χ_k(α) = 1 once k ≥ max(1/(α−p), 1/(q−α)); otherwise χ_k(α) = 0; so χ_k g → 1_{(p,q)} g pointwise.
5. Dominated convergence with bound |g| and integral_indicator give ∫ χ_k g → ∫_{(p,q)} g for every integrable g.
