## Proof

Source: parent proof, step 12 (polar coordinates in Q and continuity of the angle at p). Notation: p := r₀u, Q := span{u, e}, B_r(x) := ball x r, f(y) := arctan(⟨y,e⟩/⟨y,u⟩). Note ⟨p,u⟩ = r₀, ⟨p,e⟩ = 0 and ‖p‖ = r₀.
1. (Choice of δ.) f is continuous at p, because y ↦ ⟨y,e⟩/⟨y,u⟩ is continuous wherever ⟨y,u⟩ ≠ 0 and ⟨p,u⟩ = r₀ > 0; and f(p) = arctan 0 = 0. Choose δ₁ > 0 with |f(y)| < s for y ∈ B_{δ₁}(p), and δ₂ > 0 with B_{δ₂}(p) ⊆ N (N is open and p ∈ N). Let δ := min(s, δ₁, δ₂) > 0.
2. (M ∩ B_δ(p) ⊆ Q.) If y ∈ M ∩ B_δ(p), then y ∈ M ∩ N (as B_δ(p) ⊆ N), so y = t(cos α·u + sin α·e) for some t, α; this is a linear combination of u and e, so y ∈ Q.
3. (Q ∩ B_δ(p) ⊆ M.) Let y ∈ Q ∩ B_δ(p). Write y = x·u + z·e (Submodule.mem_span_pair); by orthonormality ⟨y,u⟩ = x and ⟨y,e⟩ = z. Then x = ⟨p,u⟩ + ⟨y − p, u⟩ ≥ r₀ − ‖y − p‖ > r₀ − δ ≥ r₀ − s > 0. Let t := ‖y‖ = √(x² + z²) > 0 and α := arctan(z/x) = f(y). Then |t − r₀| = |‖y‖ − ‖p‖| ≤ ‖y − p‖ < δ ≤ s, so t ∈ (r₀ − s, r₀ + s), and |α| = |f(y)| < s, so α ∈ (−s, s). Moreover √(1 + (z/x)²) = t/x, so cos α = 1/√(1 + (z/x)²) = x/t and sin α = (z/x)/√(1 + (z/x)²) = z/t (Real.cos_arctan, Real.sin_arctan), whence t(cos α·u + sin α·e) = x·u + z·e = y. Hence y lies in the image set, which equals M ∩ N, so y ∈ M; and y ∈ B_δ(p).
4. (Conclusion.) By steps 2–3, M ∩ B_δ(r₀u) = span{u, e} ∩ B_δ(r₀u) with δ > 0. ∎
