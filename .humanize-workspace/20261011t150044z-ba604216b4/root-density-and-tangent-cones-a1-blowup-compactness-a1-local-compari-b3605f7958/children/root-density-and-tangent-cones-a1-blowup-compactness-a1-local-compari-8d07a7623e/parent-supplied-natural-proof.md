## Proof

Source: step 7 of the parent proof ("ΛⁿDf(x) fixes ξ(x) = ±τ₁ ∧ ⋯ ∧ τₙ"), stated for an arbitrary unit orientation ξ of a subspace Q and an arbitrary continuous linear map L fixing Q pointwise. The parent applies it with ξ = R.orient x, Q = Q_x and L = Df(x).
Notation. For an n-covector α (a continuous alternating n-linear map (ℝ^P)ⁿ → ℝ, Covector (Euclid P) n) and L, α ∘ ΛⁿL := α.compContinuousLinearMap L is the n-covector (w₁, …, wₙ) ↦ α(Lw₁, …, Lwₙ). In Lean, (α.compContinuousLinearMap L)(m) = α(L ∘ m) for every m : Fin n → ℝ^P (ContinuousAlternatingMap.compContinuousLinearMap_apply, which holds by rfl).
1. Unpacking. By definition of IsUnitOrientationOf ξ Q there is a family τ = (τ₁, …, τₙ) : Fin n → ℝ^P, orthonormal, with span{τ₁, …, τₙ} = Q, and one of the two alternatives holds: (+) ξ(β) = β(τ) for every n-covector β, or (−) ξ(β) = −β(τ) for every n-covector β.
2. L fixes the frame. For each i, τᵢ ∈ span(range τ) = Q, so Lτᵢ = τᵢ by hypothesis. Hence L ∘ τ = τ as functions Fin n → ℝ^P.
3. The covector α ∘ ΛⁿL agrees with α on the frame. For every n-covector α, (α ∘ ΛⁿL)(τ) = α(L ∘ τ) = α(τ) by step 2.
4. Conclusion. Fix α. In case (+), ξ(α ∘ ΛⁿL) = (α ∘ ΛⁿL)(τ) = α(τ) = ξ(α), applying (+) once to β = α ∘ ΛⁿL and once to β = α. In case (−), ξ(α ∘ ΛⁿL) = −(α ∘ ΛⁿL)(τ) = −α(τ) = ξ(α) in the same way. Orthonormality of τ is not used. For n = 0, τ is the empty family and the same computation applies. ∎

## Key steps

1. Unpack IsUnitOrientationOf ξ Q: an orthonormal frame τ with span Q and a fixed sign σ ∈ {±1} with ξ(β) = σβ(τ) for all β.
2. Each τᵢ lies in Q, so L ∘ τ = τ.
3. (α ∘ ΛⁿL)(τ) = α(L ∘ τ) = α(τ), hence ξ(α ∘ ΛⁿL) = σα(τ) = ξ(α) in either sign case.
