## Proof

Source: the algebra (A0)–(A3) of the parent proof: (A2) A_#e = J_A·σ_# with σ_# a unit orientation of A(ℝⁿ), A_#e = 0 if A is not injective; (A0) |α(σ)| ≤ |α| for orthonormal σ; (A1) two unit orientations of one plane differ by a sign; (A3) J_{LA} ≤ ‖L‖ⁿJ_A. Here ‖α‖ is the operator norm of the covector, for which (A0) is immediate.
Notation: IsUnitOrientationOf ξ Q means: there is an orthonormal τ : Fin n → ℝ^P with span(range τ) = Q and either ξ(α) = α(τ) for all α or ξ(α) = −α(τ) for all α.
0. Non-injective A. If A is not injective, choose v ≠ 0 with Av = 0 and write v = Σ_j v_j e_j. Then Σ_j v_j·Ae_j = Av = 0 with some v_j ≠ 0, so the family Ae is linearly dependent, and α(Ae) = 0 for every alternating form α (Mathlib AlternatingMap.map_linearDependent). Moreover A*Av = 0, so A*A is not invertible and det(A*A) = 0, J_A = 0.
1. The normalized evaluation (parent (A2)). Let A be injective. By sibling inj_orientation, det(A*A) > 0, so J_A > 0. Let ζ_A ∈ Λ_n(ℝ^P) be the continuous linear functional α ↦ J_A⁻¹·α(Ae) (J_A⁻¹ times the evaluation map at Ae, Mathlib ContinuousAlternatingMap.apply; it is continuous since |α(Ae)| ≤ ‖α‖·∏_j|Ae_j|). Then α(Ae) = J_A·ζ_A(α) for every α, which is the hypothesis of the second part of inj_orientation; hence ζ_A is a unit orientation of range A: there is an orthonormal τ spanning range A with ζ_A(α) = α(τ) for all α, or ζ_A(α) = −α(τ) for all α.
2. Part (b) (parent (A0), (A2)). If A is not injective, |α(Ae)| = 0 ≤ J_A‖α‖ by step 0. If A is injective, by step 1, |α(Ae)| = J_A·|ζ_A(α)| = J_A·|α(τ)|, and |α(τ)| ≤ ‖α‖·∏_j|τ_j| = ‖α‖ (ContinuousAlternatingMap.le_opNorm; |τ_j| = 1 for an orthonormal family). Hence |α(Ae)| ≤ J_A‖α‖.
3. Part (c) (parent (A1)). Let A be injective and ξ a unit orientation of range A. By step 1, ζ_A is also a unit orientation of range A, so by sibling orientation_sign, ξ = ζ_A or ξ = −ζ_A. In the first case J_A·ξ(α) = J_A·ζ_A(α) = α(Ae), so s := 1 works; in the second case J_A·ξ(α) = −J_A·ζ_A(α) = −α(Ae), so s := −1 works.
4. Part (a) (parent (A3)). If A is not injective, then L∘A is not injective (LAv = 0 for the v of step 0), so by step 0 applied to L∘A, J_{LA} = 0 ≤ ‖L‖ⁿJ_A. Let A be injective. For a linear W : ℝⁿ → ℝ^P the matrix of W*W in the orthonormal basis e is the Gram matrix G_W := (⟨We_i, We_j⟩)_{ij}, so J_W² = det G_W. Let σ₁, …, σₙ be the Gram–Schmidt orthonormalization of Ae₁, …, Aeₙ: Ae_j = Σ_{i≤j} T_{ij}σ_i with T upper triangular, T_jj = dist(Ae_j, span(Ae₁, …, Ae_{j−1})) > 0. Let V : ℝⁿ → ℝ^P be the linear isometry Ve_i := σ_i and identify T with the linear map of ℝⁿ with matrix T, so that A = V∘T and L∘A = (L∘V)∘T. Then G_A = TᵀG_V T = TᵀT and G_{LA} = TᵀG_{LV}T, hence J_A = |det T| and J_{LA} = |det T|·J_{LV}. Finally J_{LV} ≤ ∏_i|Lσ_i| ≤ ‖L‖ⁿ by Hadamard's inequality for Gram determinants: for vectors w₁, …, wₙ, det(⟨w_i, w_j⟩) ≤ ∏_i|w_i|² (if the w_i are dependent the determinant is 0; otherwise Gram–Schmidt gives w_j = Σ_{i≤j}S_{ij}ρ_i with ρ orthonormal, det(⟨w_i, w_j⟩) = (det S)² = ∏_j S_jj² and S_jj = dist(w_j, span(w_{<j})) ≤ |w_j|). Therefore J_{LA} ≤ ‖L‖ⁿ·|det T| = ‖L‖ⁿJ_A.
4′. Equivalent measure-theoretic route for (a), used by the Lean reference implementation. With Hⁿ := μHE[n] (Lebesgue measure Lⁿ on ℝⁿ, EuclideanSpace.euclideanHausdorffMeasure_eq_volume) and S the open unit ball of ℝⁿ (0 < Lⁿ(S) < ∞): the linear area formula Hⁿ(W(S)) = normDet(W)·Hⁿ(S) (Mathlib LinearMap.euclideanHausdorffMeasure_image) with normDet(W) = J_W (ContinuousLinearMap.normDet_sq and normDet ≥ 0), applied to W = L∘A and W = A, and the Lipschitz image bound Hⁿ(L(E)) ≤ ‖L‖ⁿHⁿ(E) (LipschitzWith.hausdorffMeasure_image_le for the ‖L‖-Lipschitz map L, μHE[n] being a constant multiple of μH[n]) give J_{LA}Hⁿ(S) = Hⁿ(L(A(S))) ≤ ‖L‖ⁿHⁿ(A(S)) = ‖L‖ⁿJ_A Hⁿ(S); dividing by Hⁿ(S) ∈ (0, ∞) gives (a). ∎
For n = 0 the argument is unchanged (ℝ⁰ = {0}, det of the identity of the zero space is 1, J_A = 1, and A is injective).

2. Injective A: ζ_A := J_A⁻¹·(evaluation at Ae) satisfies α(Ae) = J_Aζ_A(α), so it is a unit orientation of range A (sibling inj_orientation).
