## Proof

Source: parent proof Step 0 (Φ is injective, Lipschitz and |v₁ − v₂| ≤ |Φ(v₁) − Φ(v₂)|), Step 1 (Hⁿ(Φ(N)) ≤ Lip(Φ)ⁿHⁿ(N) = 0) and Step 3 (F ∩ K ⊆ Φ(Bⁿ_m(0)) has finite Hⁿ-measure), here for an arbitrary base point b and with the non-sharp Lipschitz constant 1 + L (any finite constant suffices). Simon Ch. 2, Theorem 1.8(i) (chapter-02.txt lines 270–275: Hᵐ(f(A)) ≤ (Lip f)ᵐHᵐ(A)).
1. (Difference formula.) For u, u' ∈ ℝⁿ, Ψ(u) − Ψ(u') = ι(u − u') + ι'(g u − g u') by linearity of ι, ι'.
2. (Pythagoras; proves (i).) By hypothesis ⟨ι(u − u'), ι'(g u − g u')⟩ = 0, hence |Ψ(u) − Ψ(u')|² = |ι(u − u')|² + |ι'(g u − g u')|² = |u − u'|² + |g u − g u'|² (Mathlib `norm_add_sq_eq_norm_sq_add_norm_sq_real`; isometries preserve norms, `LinearIsometry.norm_map`). Thus |u − u'|² ≤ |Ψ(u) − Ψ(u')|², and since both numbers are nonnegative, |u − u'| ≤ |Ψ(u) − Ψ(u')|, i.e. dist(u, u') ≤ dist(Ψ(u), Ψ(u')).
3. (Proves (ii).) By Step 1 and the triangle inequality, |Ψ(u) − Ψ(u')| ≤ |ι(u − u')| + |ι'(g u − g u')| = |u − u'| + |g u − g u'| ≤ |u − u'| + L|u − u'| = (1 + L)|u − u'|.
4. (Proves (iii).) By (i), Ψ is antilipschitz with constant 1; by (ii) it is uniformly continuous; ℝⁿ is complete. Hence Ψ(ℝⁿ) is closed (Mathlib `AntilipschitzWith.isClosed_range`): if Ψ(u_j) → y then (Ψ(u_j)) is Cauchy, so (u_j) is Cauchy by (i), u_j → u, and y = Ψ(u) by continuity.
5. (Two facts about Hⁿ.) (a) On ℝⁿ = Euclid n one has μHE[n] = volume (Mathlib `InnerProductSpace.euclideanHausdorffMeasure_eq_volume` for V = Euclid n together with `finrank_euclideanSpace_fin`). (b) For every A ⊆ ℝⁿ, Hⁿ(Ψ(A)) ≤ (1 + L)ⁿ Hⁿ(A), because Ψ is (1 + L)-Lipschitz on A (SimonGMT `Poincare.SimonGMT.Chapter02.euclideanHausdorffMeasure_image_le_of_lipschitzOn`, which is in the import closure of the contract via Chapter02.Lipschitz).
6. (Proves (iv).) Let K ⊆ ℝ^{n+k} be compact. It is bounded, so K ⊆ closedBall(Ψ(0), m) for some m. If Ψ(u) ∈ K, then by (i) |u| = dist(u, 0) ≤ dist(Ψ(u), Ψ(0)) ≤ m. Hence Ψ(ℝⁿ) ∩ K ⊆ Ψ(closedBall(0, m)), and by Step 5, Hⁿ(Ψ(ℝⁿ) ∩ K) ≤ (1 + L)ⁿ·Lⁿ(closedBall(0, m)) < ∞, closed balls of ℝⁿ having finite Lebesgue measure.
7. (Proves (v).) If Lⁿ(N) = 0, then by Step 5 Hⁿ(Ψ(N)) ≤ (1 + L)ⁿHⁿ(N) = (1 + L)ⁿLⁿ(N) = 0. ∎
