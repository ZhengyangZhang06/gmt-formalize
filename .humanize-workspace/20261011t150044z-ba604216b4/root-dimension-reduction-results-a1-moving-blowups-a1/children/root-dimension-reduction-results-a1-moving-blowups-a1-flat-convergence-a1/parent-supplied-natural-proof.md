(IMC) foundations, conjunct (IMC): (b) Borel restrictions of IMReps are IMReps (of some current); (c) IM currents in an open set are closed under −, hence + (0 = X − X) and integer combinations; (d) |R.orient(x)(α)| ≤ |α| a.e. on the carrier of an IMRep R, so (R.measure, R.orient) is a representation for (SL). The zero current of any degree is IM: the IMRep with carrier ∅, multiplicity 0, orientation 0 represents it (countablyRectifiable_of_measure_zero; other fields vacuous as μHE⌞∅ = 0; integral over ∅ is 0). (CL), (BR) closure_and_boundary_rectifiability: weak limits of IM currents with locally bounded M + M∂ are IM; so are boundaries of IM currents with locally finite boundary mass. (SL) slicing. (VO) vanish_off_support: X(ω) = 0 if tsupport ω ∩ spt X = ∅. (DT) deformation_theorem.
0. If n > P, all n- and (n+1)-currents vanish: R_j := 0, S_j := 0. If W = ∅: R_j := 0, S_j := T − T_j (IM by (IMC)(c)); T − T_j − S_j = 0 = ∂0 and every M_∅ vanishes. Assume n ≤ P, W ≠ ∅.
1. For X ∈ 𝒟_n(U) let d_W(X) := inf{M_W(R) + M_W(S) : R ∈ 𝒟_{n+1}(U), S ∈ 𝒟_n(U) both IM, X − S = ∂R}; R = 0, S = T − T_j give d_W(T − T_j) ≤ M_W(T − T_j) < ∞ ((IMC), (MR)). If d_W(T − T_j) → 0, pairs with M_W(R_j) + M_W(S_j) ≤ d_W(T − T_j) + 2^{−j} prove the theorem; by the subsequence principle it suffices that each subsequence has a further subsequence (j_ℓ) with d_W(T − T_{j_ℓ}) → 0. Fix a subsequence, still called T_j (the hypotheses persist).
2. ∂T_j is IM by (BR), as M_G(∂T_j) < ∞ for G ⊂⊂ U; ∂T_j ⇀ ∂T (WeaklyConvergesOn.boundary), so M_G(T) + M_G(∂T) ≤ liminf_j (M_G(T_j) + M_G(∂T_j)) < ∞ for G ⊂⊂ U (WeaklyConvergesOn.massOn_le_liminf). Fix an IMRep R_T of T; μ_T := R_T.measure is finite on compacts of U; T⌞B is the IM restriction.
3. (Localization.) Take δ₀ > 0 with 3δ₀ < infDist(closure W, ℝ^P ∖ U) (δ₀ := 1 if U = ℝ^P), g := infDist(·, closure W) (1-Lipschitz; closure W ≠ ∅ compact), W₁ := {g < 5δ₀/2} ⊂⊂ U, Λ₀ := sup_j (M_{W₁}(T_j) + M_{W₁}(∂T_j)) < ∞. Let R_j, R'_j be IMReps of T_j, ∂T_j, μ_j := R_j.measure, μ'_j := R'_j.measure (finite on compacts of U). (SL) with f = g gives A_{j,s} = T_j⌞{g < s} (IM restriction), B_{j,s} = (∂T_j)⌞{g < s} and Z_{j,s} := ∂A_{j,s} − B_{j,s} with M(Z_{j,s}) ≤ liminf_{h↓0} h⁻¹μ_j({s − h < g < s}) for s ∈ (0, 2δ₀). The μ_j⌞K₀, K₀ := {g ≤ 2δ₀} ⊆ W₁ compact metrizable, have mass ≤ Λ₀, so (simon_theorem_4_16_compact_metrizable) along a subsequence (still T_j) μ_j⌞K₀ → ν weakly on K₀ (against C(K₀)), ν a finite Borel measure; the {g = s}, 0 < s < 2δ₀, are disjoint, so ν({g = s}) > 0 for at most countably many s (Measure.countable_meas_level_set_pos). F_j(s) := μ_j({0 < g < min(s, 2δ₀)}) is nondecreasing, F_j ≤ Λ₀; at each s ∈ (0, 2δ₀) where F_j is differentiable (a.e.), (SL) gives M(Z_{j,s}) ≤ F_j'(s), as μ_j({s − h < g < s}) ≤ F_j(s) − F_j(s − h); F_j' = deriv F_j is measurable and integrable on [0, 2δ₀] with ∫_0^{2δ₀} F_j' ≤ Λ₀ (F_j monotone; measurable_deriv, MonotoneOn.intervalIntegrable_deriv, MonotoneOn.intervalIntegral_deriv_mem_uIcc). By Fatou, ∫_0^{2δ₀} liminf_j F_j' ≤ Λ₀, so liminf_j F_j'(s) < ∞ for a.e. s. Fix s ∈ (δ₀, 2δ₀) with liminf_j F_j'(s) < ∞, every F_j differentiable at s and ν({g = s}) = 0, and pass to a further subsequence with Λ₁ := sup_j M(Z_{j,s}) < ∞ (weak convergence on K₀ persists). Put T'_j := A_{j,s}, G := {g < s} (open, W ⊆ G, closure G ⊆ K := {g ≤ s}, compact ⊆ W₁).
(a) T'_j is IM, spt T'_j ⊆ K (T'_j(ω) = 0 if ω vanishes on G, e.g. if tsupport ω ∩ K = ∅), M(T'_j) ≤ μ_j(G) ≤ Λ₀, ∂T'_j = B_{j,s} + Z_{j,s}, so M(∂T'_j) ≤ μ'_j(G) + Λ₁ ≤ Λ₀ + Λ₁ =: Λ, and ∂T'_j is IM by (BR).
(b) T'_j ⇀ T' := T⌞G: for ω ∈ 𝒟ⁿ(U), ε > 0 and χ_ε ∈ C_c^∞(G; [0, 1]) equal to 1 on {g < s − ε}, |T'_j(ω) − T_j(χ_εω)| ≤ |ω|_∞ μ_j({s − ε ≤ g < s}), where limsup_j μ_j({s − ε ≤ g ≤ s}) ≤ ν({s − ε ≤ g ≤ s}) (weak convergence, closed set) → ν({g = s}) = 0 as ε ↓ 0; |T'(ω) − T(χ_εω)| ≤ |ω|_∞ μ_T({s − ε ≤ g < s}) → 0; and T_j(χ_εω) → T(χ_εω). So T'_j(ω) → T'(ω).
(c) For a current X in U with spt X ⊆ K, X̂(ω) := X(ζω) (ω ∈ 𝒟ⁿ(ℝ^P); ζ ∈ C_c^∞(U; [0, 1]), ζ = 1 near K) is a current in ℝ^P, independent of ζ (VO), with the same masses on open sets and ∂X̂ = (∂X)^ (X(dζ ∧ ·) = 0 by (VO)); if X is IM with a carrier in K, X̂ is IM with the same IMRep. This applies to T'_j, T', and T̂'_j ⇀ T̂'. Conversely, restricting the domain of a current in ℝ^P to 𝒟(U) (restrictDomain) preserves IM-ness if a carrier lies in U and does not increase masses.
4. (Deformation.) Let c ≥ 1 be the (DT) constant for (P, m). Given η > 0 choose ρ ∈ (0, δ₀/(4√P)) with 2cρΛ < η (so 3√Pρ < 3δ₀/4). (DT) with (ρ, K, Λ) gives a finite 𝒬 and, for each j, T̂'_j − Q_j − S'_j = ∂R'_j with Q_j ∈ 𝒬, Q_j and R'_j IM, M(Q_j) ≤ cΛ, M(R'_j), M(S'_j) ≤ cρΛ, spt Q_j ∪ spt R'_j ⊆ thickening(3√Pρ, K) ⊆ K' := {g ≤ s + 3δ₀/4} (compact, ⊆ {g < 3δ₀} ⊆ U). M(∂R'_j) ≤ M(T̂'_j) + M(Q_j) + M(S'_j) < ∞, so ∂R'_j is IM by (BR) in ℝ^P, S'_j = T̂'_j − Q_j − ∂R'_j is IM by (IMC)(c), and spt S'_j ⊆ K' (spt ∂R'_j ⊆ spt R'_j). As 𝒬 is finite, some Q ∈ 𝒬 equals Q_j for infinitely many j; for two such j, l, T̂'_j − T̂'_l − (S'_j − S'_l) = ∂(R'_j − R'_l), with R'_j − R'_l, S'_j − S'_l IM, supported in K', and M(R'_j − R'_l) + M(S'_j − S'_l) ≤ 4cρΛ < 2η.
5. Step 4 with η = 2^{−r−1}, r = 1, 2, …, applied successively to nested infinite index sets gives j_1 < j_2 < ⋯ and IM R_r ∈ 𝒟_{n+1}(ℝ^P), S_r ∈ 𝒟_n(ℝ^P) supported in K' with T̂'_{j_{r+1}} − T̂'_{j_r} − S_r = ∂R_r, M(R_r) + M(S_r) ≤ 2^{−r}.
6. (Summation.) For ℓ < N let R^{(ℓ,N)} := Σ_{ℓ≤r<N} R_r, S^{(ℓ,N)} := Σ_{ℓ≤r<N} S_r (IM by (IMC)(c)); by step 5, T̂'_{j_N} − T̂'_{j_ℓ} − S^{(ℓ,N)} = ∂R^{(ℓ,N)}. R^{(ℓ)}(ω) := Σ_{r≥ℓ} R_r(ω), S^{(ℓ)}(ω) := Σ_{r≥ℓ} S_r(ω) converge absolutely (|R_r(ω)| ≤ |ω|_∞M(R_r): ±ω/|ω|_∞ is admissible for M) and define currents (sequentially continuous by the uniform bound |R^{(ℓ)}(ω)| ≤ 2^{1−ℓ}|ω|_∞) with M(R^{(ℓ)}) + M(S^{(ℓ)}) ≤ 2^{1−ℓ}, and R^{(ℓ,N)} ⇀ R^{(ℓ)}, S^{(ℓ,N)} ⇀ S^{(ℓ)} (N → ∞). They are IM by (CL) in ℝ^P: M(R^{(ℓ,N)}), M(S^{(ℓ,N)}) ≤ 2^{1−ℓ}, M(∂R^{(ℓ,N)}) = M(T̂'_{j_N} − T̂'_{j_ℓ} − S^{(ℓ,N)}) ≤ 2Λ₀ + 1, and M(∂S^{(ℓ,N)}) = M(∂T̂'_{j_N} − ∂T̂'_{j_ℓ}) ≤ 2Λ (∂∂ = 0). As N → ∞ (T̂'_{j_N} ⇀ T̂', ∂ weakly continuous), T̂' − T̂'_{j_ℓ} − S^{(ℓ)} = ∂R^{(ℓ)}, with spt R^{(ℓ)}, spt S^{(ℓ)} ⊆ K' ⊆ U.
7. (Back to U.) The restrictions (restrictDomain) of R^{(ℓ)}, S^{(ℓ)} to U are IM: the measures of their IMReps in ℝ^P vanish off the support ⊆ K' ⊆ U ((MR), (VO)), so intersecting the carriers with U ((IMC)(b)) does not change the currents and gives IMReps in U of the restrictions. In U, X = X⌞G + X⌞(ℝ^P ∖ G) for X = T, T_{j_ℓ} (additivity of integrals), and T⌞G, T_{j_ℓ}⌞G are the restrictions of T̂', T̂'_{j_ℓ}. So T − T_{j_ℓ} − S♯_ℓ = ∂R^{(ℓ)} in U with S♯_ℓ := S^{(ℓ)} + T⌞(ℝ^P ∖ G) − T_{j_ℓ}⌞(ℝ^P ∖ G), IM by (IMC) (T is IM). Forms admissible for M_W have tsupport ⊆ W ⊆ G, so the last two terms vanish on them: M_W(S♯_ℓ) ≤ M(S^{(ℓ)}), M_W(R^{(ℓ)}) ≤ M(R^{(ℓ)}). Thus d_W(T − T_{j_ℓ}) ≤ 2^{1−ℓ} → 0 along the sub-subsequence, and step 1 concludes. ∎

## Key steps

1. Reduce to d_W(T − T_j) → 0, and by the subsequence principle to sub-subsequences.
2. Localize to T'_j = T_j⌞{g < s} with bounded M + M∂ (slicing, Fatou, weak compactness on K₀, ν({g = s}) = 0); T'_j ⇀ T⌞G; extend to ℝ^P.
3. Deformation theorem: Q_j in a finite 𝒬, remainders IM by (BR); pigeonhole gives flat-close pairs.
4. Flat-Cauchy subsequence; sum the series; limits IM by (CL).
5. Back in U, absorb T⌞(ℝ^P ∖ G) − T_{j_ℓ}⌞(ℝ^P ∖ G) into S (no mass in W).
