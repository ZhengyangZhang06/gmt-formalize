G (gap lemma). For j ≥ 1, q ≥ 0 there is δ_G(j,q) ∈ (0,1/2) such that a minimizing integer multiplicity cone C ∈ 𝒟_j(ℝ^{j+q}), ∂C = 0, Θ_C(0) < 1 + δ_G(j,q), has Θ_C(0) ∈ {0,1}, and Θ_C(0) = 1 implies C = ±[[Π]].
