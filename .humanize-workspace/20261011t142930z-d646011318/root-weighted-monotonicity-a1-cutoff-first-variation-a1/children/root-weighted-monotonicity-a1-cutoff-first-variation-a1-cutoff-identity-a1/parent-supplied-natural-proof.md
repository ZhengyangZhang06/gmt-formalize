## Proof

Conventions. Notation is as in the statement. All integrals are Bochner integrals with respect to μ, with ∫_U taken with respect to μ restricted to U, and "integrable" means μ-integrable on E unless a set is named. Hypothesis (viii) is the first-variation identity tested with the radial field (h(x)φ(|x − ξ|/τ))(x − ξ); the proof only rewrites it.
1. (φ and φ'.) Since φ ∈ C¹, φ is differentiable (ContDiff.differentiable) and φ' is continuous (ContDiff.continuous_deriv). If t > c, then (c, ∞) is an open neighbourhood of t on which φ ≡ 0 by (vi), so φ'(t) = 0 (Filter.EventuallyEq.deriv_eq, deriv_const).
2. (Outside B.) If x ∉ B then r > R ≥ cτ by (vii), so r/τ > c since τ > 0. By (vi) and step 1, φ(r/τ) = 0 and φ'(r/τ) = 0.
3. (Chain rule.) Let s ∈ ℝ. The map t ↦ t/τ has derivative 1/τ at s, and φ is differentiable at s/τ. So t ↦ φ(t/τ) has derivative φ'(s/τ)·(1/τ) at s (HasDerivAt.comp), i.e. γ'(s) = φ'(s/τ)/τ. In particular r·γ'(r) = (r/τ)φ'(r/τ).
4. (Off tsupport h.) If x ∉ tsupport h then h(x) = 0 (image_eq_zero_of_notMem_tsupport) and g(x) = 0 by (ii).
5. (From U to E.) Let L(x) := h(x)(n·φ(r/τ) + r·γ'(r)·(1 − q(x))) + φ(r/τ)⟨x − ξ, g(x)⟩ and Q(x) := h(x)φ(r/τ)⟨x − ξ, H(x)⟩ be the two integrands of (viii). Let x ∉ U; by (i), x ∉ tsupport h or x ∉ B.
- If x ∉ tsupport h, then by step 4, L(x) = 0·(…) + φ(r/τ)⟨x − ξ, 0⟩ = 0 and Q(x) = 0.
- If x ∉ B, then by steps 2 and 3, φ(r/τ) = 0 and γ'(r) = φ'(r/τ)/τ = 0. So L(x) = h(x)(n·0 + r·0·(1 − q(x))) + 0 = 0 and Q(x) = h(x)·0·⟨x − ξ, H(x)⟩ = 0.
So both integrands vanish outside U, hence ∫_U L dμ = ∫_E L dμ and ∫_U Q dμ = ∫_E Q dμ (setIntegral_eq_integral_of_forall_compl_eq_zero; no measurability of U is needed). Now (viii) reads ∫L dμ = −∫Q dμ.
6. (Bounds on B.) μ(B) < ∞, since B is compact and μ is finite on compact sets. φ and φ' are continuous and [0, R/τ] is compact, so there are M₀, M₁ with |φ(t)| ≤ M₀ and |φ'(t)| ≤ M₁ for t ∈ [0, R/τ] (IsCompact.exists_bound_of_continuousOn). For x ∈ B we have 0 ≤ r ≤ R, hence r/τ ∈ [0, R/τ], R ≥ 0, |φ(r/τ)| ≤ M₀, |φ'(r/τ)| ≤ M₁ and |r/τ| ≤ R/τ. The functions x ↦ r/τ, x ↦ φ(r/τ) and x ↦ φ'(r/τ) are continuous, hence μ⌞B-a.e. strongly measurable.
7. (Integrability of the pieces.) Put T₁(x) := h(x)φ(r/τ), T₂(x) := h(x)(1 − q(x))·((r/τ)φ'(r/τ)), T₃(x) := φ(r/τ)⟨x − ξ, g(x)⟩ and T₄(x) := φ(r/τ)G(x). By step 2 each Tᵢ vanishes outside B.
- T₁ is μ⌞B-a.e. strongly measurable, as the product of h (by (iii)) and x ↦ φ(r/τ) (step 6). On B, |T₁| ≤ A·M₀ by (iv) and step 6 (A ≥ |h(x)| ≥ 0).
- T₂ is μ⌞B-a.e. strongly measurable, as the product of h and 1 − q (by (iii)) with x ↦ (r/τ)φ'(r/τ) (step 6). Since |1 − q(x)| ≤ 1 + |q(x)| ≤ 2 by (iv), |T₂| ≤ A·2·((R/τ)·M₁) on B.
- As μ(B) < ∞, T₁ and T₂ are μ-integrable on B (IntegrableOn.of_bound).
- T₃ and T₄ are the functions ⟨x − ξ, g⟩ and G, μ-integrable on B by (v), multiplied by φ(r/τ), which is μ⌞B-a.e. strongly measurable and bounded by M₀ μ⌞B-a.e. Hence T₃ and T₄ are μ-integrable on B (Integrable.bdd_mul).
A function that is μ-integrable on B and vanishes outside B is μ-integrable on E (IntegrableOn.integrable_of_forall_notMem_eq_zero). So T₁, T₂, T₃ and T₄ are integrable.
8. (Assembly.) By step 3, L(x) = n·T₁(x) + T₂(x) + T₃(x) pointwise: h(nφ(r/τ) + r(φ'(r/τ)/τ)(1 − q)) + φ(r/τ)⟨x − ξ, g⟩ = n·hφ(r/τ) + h(1 − q)((r/τ)φ'(r/τ)) + φ(r/τ)⟨x − ξ, g⟩ (ring). By linearity of the integral for integrable functions (integral_add, integral_const_mul), ∫L = n∫T₁ + ∫T₂ + ∫T₃. Also Q(x) = T₄(x) − T₃(x) pointwise, because ⟨x − ξ, g + hH⟩ = ⟨x − ξ, g⟩ + h⟨x − ξ, H⟩ (inner_add_right, inner_smul_right); hence ∫Q = ∫T₄ − ∫T₃ (integral_sub). Substituting into ∫L = −∫Q from step 5 gives n∫T₁ + ∫T₂ + ∫T₃ = −∫T₄ + ∫T₃, i.e. n∫T₁ + ∫T₂ + ∫T₄ = 0. This is the claimed identity n∫hφ(r/τ)dμ + ∫h(1 − q)((r/τ)φ'(r/τ))dμ + ∫φ(r/τ)G dμ = 0.

## Key steps

1. φ' is continuous and vanishes on (c, ∞); for x ∉ B_R(ξ), r/τ > c, so φ(r/τ) = φ'(r/τ) = 0
2. Chain rule: deriv(t ↦ φ(t/τ))(s) = φ'(s/τ)/τ, so r·γ'(r) = (r/τ)φ'(r/τ). Off tsupport h, h = 0 and g = 0
3. Both (RFV_τ) integrands vanish off U (off tsupport h, or off B_R(ξ)), so ∫_U = ∫_E
4. T₁ = hφ(r/τ) and T₂ = h(1 − q)(r/τ)φ'(r/τ) are measurable and bounded on B_R(ξ) (|1 − q| ≤ 2). T₃ = φ(r/τ)⟨x − ξ, g⟩ and T₄ = φ(r/τ)G are integrable on B_R(ξ) via a bounded multiplier. All four vanish outside B_R(ξ), so all are μ-integrable
5. Pointwise L = nT₁ + T₂ + T₃ and Q = T₄ − T₃; linearity turns ∫L = −∫Q into n∫T₁ + ∫T₂ + ∫T₄ = 0
