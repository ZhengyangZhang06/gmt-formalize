## Proof

Source and role. This is the choice of covers (1) in Simon's proof of Ch. 2, Theorem 1.9 (chapter-02.txt lines 366–370: for each i pick C_{i1}, C_{i2}, … with diam C_{ij} < 1/i, A ⊆ ⋃ⱼ C_{ij} and Σⱼ ω_{m+k}(diam C_{ij}/2)^{m+k} ≤ H^{m+k}_{1/i}(A) + 1/i), i.e. the existence part of Step 4 of the parent proof. It is stated for Mathlib's unnormalized Hausdorff measure (cost diam^d, normalizing constant 1), and the δ-content H_δ(s) is replaced by the larger number μH[d](s), which is all the parent uses (its Step 7 only needs H^{m+k}_{1/i}(A) ≤ H^{m+k}(A)). Closedness of the covering sets is not claimed: the parent takes closures of images instead.

Notation. diam T ∈ [0, ∞] is the extended diameter; c_d(T) := diam(T)^d if T ≠ ∅ and c_d(∅) := 0 (in Lean: ⨆ _ : T.Nonempty, Metric.ediam T ^ d). For ρ > 0 let
 I_ρ := inf { Σ_{n∈ℕ} c_d(tₙ) : (tₙ)_{n∈ℕ} subsets of X with s ⊆ ⋃ₙ tₙ and diam tₙ ≤ ρ for every n } ∈ [0, ∞]
(infimum in [0, ∞]; the infimum of the empty family is ∞).

Proof.
1. Formula. Mathlib's Hausdorff measure is the metric outer measure generated by the gauge t ↦ diam(t)^d, and for every set s, measurable or not, μH[d](s) = sup_{ρ>0} I_ρ (Mathlib: MeasureTheory.Measure.hausdorffMeasure_apply; the term of an empty tₙ is a supremum over a false proposition, i.e. 0).
2. Comparison. Because r > 0, the index ρ = r occurs in the supremum of step 1, so I_r ≤ μH[d](s).
3. Strict gap. Since μH[d](s) ≠ ∞ and ε ≠ 0, μH[d](s) < μH[d](s) + ε in [0, ∞]; with step 2, I_r < μH[d](s) + ε.
4. Witness. An infimum strictly below a number b has a member strictly below b. I_r is the triple infimum over a sequence t, over a proof of s ⊆ ⋃ₙ tₙ, and over a proof of ∀ n, diam tₙ ≤ r. Applying this fact to the three infima in step 3 gives a sequence (tₙ) with s ⊆ ⋃ₙ tₙ, diam tₙ ≤ r for every n, and Σₙ c_d(tₙ) < μH[d](s) + ε.
5. Conclusion. This sequence has the three required properties (the last in the weaker form ≤). ∎

Remarks. (i) Both hypotheses are used. r > 0 puts I_r below μH[d](s), and finiteness makes step 3 strict (in [0, ∞], ∞ < ∞ + ε is false). Without finiteness the statement fails: an uncountable set whose points are pairwise at distance 1 has no countable cover by sets of diameter ≤ 1/2. (ii) No measurability of s is used. (iii) d is an arbitrary real number; only the formula of step 1 is used.

Formalization notes. Measure.hausdorffMeasure_apply, le_iSup₂_of_le, ENNReal.lt_add_right, simp only [iInf_lt_iff], hsum.le.

theorem Submission.hausdorffMeasure_exists_cover_tsum_le_add : ∀ {X : Type} [EMetricSpace X] [MeasurableSpace X] [BorelSpace X] (d : ℝ) (s : Set X) (r ε : ℝ≥0∞), 0 < r → ε ≠ 0 → μH[d] s ≠ ∞ → ∃ t : ℕ → Set X, s ⊆ ⋃ n, t n ∧ (∀ n, Metric.ediam (t n) ≤ r) ∧ ∑' n, ⨆ _ : (t n).Nonempty, Metric.ediam (t n) ^ d ≤ μH[d] s + ε := by
  intro X _ _ _ d s r ε hr hε hs
  set I : ℝ≥0∞ := ⨅ (t : ℕ → Set X) (_ : s ⊆ ⋃ n, t n) (_ : ∀ n, Metric.ediam (t n) ≤ r),
          ∑' n, ⨆ _ : (t n).Nonempty, Metric.ediam (t n) ^ d with hI
  have hIle : I ≤ μH[d] s := by
    rw [Measure.hausdorffMeasure_apply]
    exact le_iSup₂_of_le r hr le_rfl
  have hIlt : I < μH[d] s + ε := lt_of_le_of_lt hIle (ENNReal.lt_add_right hs hε)
  rw [hI] at hIlt
  simp only [iInf_lt_iff] at hIlt
  obtain ⟨t, hst, htr, hsum⟩ := hIlt
  exact ⟨t, hst, htr, hsum.le⟩

## Key steps

1. μH[d](s) = sup_{ρ>0} I_ρ, where I_ρ is the infimum of Σₙ c_d(tₙ) over countable covers of s by sets of diameter ≤ ρ (hausdorffMeasure_apply).
2. r > 0 gives I_r ≤ μH[d](s).
3. μH[d](s) < ∞ and ε ≠ 0 give I_r < μH[d](s) + ε.
4. Unfold the triple infimum (iInf_lt_iff) to obtain a cover t with diam tₙ ≤ r and Σₙ c_d(tₙ) < μH[d](s) + ε.
