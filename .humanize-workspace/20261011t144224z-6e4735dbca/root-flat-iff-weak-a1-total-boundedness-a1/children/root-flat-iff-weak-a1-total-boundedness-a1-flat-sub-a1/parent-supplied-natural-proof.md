## Proof

Source: parent proof, Step 3 ("R := R_i − R_j and S := S_i − S_j are integer multiplicity (sibling im_lincomb with a = 1, b = −1), and M(R) + M(S) ≤ M(R_i) + M(R_j) + M(S_i) + M(S_j) (F2)"). LC is the frozen statement of the parent's sibling fiw_im_lincomb.

1. Difference current. For Z₁, Z₂ ∈ D_k(U), define Z₁ ⊖ Z₂ with underlying linear map Z₁.toCurrent − Z₂.toCurrent. It is sequentially continuous: if TestFormOnConverges ω_j 0, then Z₁(ω_j) → 0 and Z₂(ω_j) → 0, so Z₁(ω_j) − Z₂(ω_j) → 0 (Tendsto.sub). So Z₁ ⊖ Z₂ ∈ D_k(U) and (Z₁ ⊖ Z₂)(ω) = Z₁(ω) − Z₂(ω).
2. Put R := R₁ ⊖ R₂ ∈ D_{n+1}(U) and S := S₁ ⊖ S₂ ∈ D_n(U). Since R(ω) = 1·R₁(ω) + (−1)·R₂(ω) for every ω, LC (U open, T₁ := R₁, T₂ := R₂, a := 1, b := −1) shows that R is integer multiplicity; likewise S.
3. Boundary identity. For ω ∈ D^n(U), ∂R(ω) = R(dω) = R₁(dω) − R₂(dω) = ∂R₁(ω) − ∂R₂(ω) (GeometricCurrentOn.boundary_apply). Hence ∂R(ω) + S(ω) = (∂R₁(ω) − ∂R₂(ω)) + (S₁(ω) − S₂(ω)) = (∂R₁(ω) + S₁(ω)) − (∂R₂(ω) + S₂(ω)).
4. Mass subadditivity: M(Z₁ ⊖ Z₂) ≤ M(Z₁) + M(Z₂). Let ω ∈ massAdmissibleOn U k U. Then −ω is admissible as well (tsupport(−ω) = tsupport ω, covectorEuclideanNorm_neg), and Z₂(−ω) = −Z₂(ω). So ofReal(Z₁(ω) − Z₂(ω)) ≤ ofReal(Z₁(ω)) + ofReal(Z₂(−ω)) (ENNReal.ofReal_add_le) ≤ M(Z₁) + M(Z₂) (le_massOn twice). Take the supremum (sSup_le).
5. By step 4, M(R) + M(S) ≤ (M(R₁) + M(R₂)) + (M(S₁) + M(S₂)) = (M(R₁) + M(S₁)) + (M(R₂) + M(S₂)) (commutativity and associativity in [0, ∞]). ∎

## Key steps

1. The difference of two sequentially continuous currents is a current.
2. R := R₁ − R₂ and S := S₁ − S₂ are integer multiplicity by LC with a = 1, b = −1.
3. ∂(R₁ − R₂) = ∂R₁ − ∂R₂, which gives the boundary identity.
4. M(Z₁ − Z₂) ≤ M(Z₁) + M(Z₂), because −ω is admissible whenever ω is.
