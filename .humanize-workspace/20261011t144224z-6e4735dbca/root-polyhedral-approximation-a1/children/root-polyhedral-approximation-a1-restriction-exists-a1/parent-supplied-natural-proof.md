## Proof

This is the supplied proof's (P1) for the restriction X⌞A(ω) := ∫_A⟨ω, X⃗⟩ dμ_X (Simon 2.9), for an arbitrary representation (2.7).

Notation. For I ∈ SimonMultiIndex n P let dx^I := wedgeCovectors n (fun j => EuclideanSpace.proj (I j)), a fixed n-covector. For an n-covector α let α_I := euclideanCovectorCoordinate α I, let |α| := covectorEuclideanNorm α, and let ‖α‖ be its operator norm. Let N be the number of elements of SimonMultiIndex n P.

1. (Norm comparison.) For every α, |α_I| = |α(e_{I(0)},…,e_{I(n−1)})| ≤ ‖α‖·Π_j ‖e_{I(j)}‖ = ‖α‖. The sum defining |α|² has nonzero terms only for strictly increasing J : Fin n → Fin P, which correspond bijectively to SimonMultiIndex n P. Hence |α| ≤ √N·‖α‖.
2. (Cut-offs.) Let K ⊆ U be compact.
   - By IsCompact.exists_cthickening_subset_open choose r > 0 with cthickening (2r) K ⊆ U.
   - Apply the smooth Urysohn lemma (exists_contMDiffMap_zero_one_of_isClosed, model 𝓘(ℝ, ℝ^P), smoothness ∞) to the disjoint closed sets ℝ^P ∖ thickening r K and K. This gives a C^∞ function χ_K : ℝ^P → [0,1] with χ_K = 1 on K and χ_K = 0 off thickening r K.
   - Then tsupport χ_K ⊆ cthickening r K ⊆ U, which is compact.
   - For each I, the form x ↦ χ_K(x)·dx^I is C^∞ with compact support and tsupport ⊆ U, so it belongs to Dⁿ(U).
3. (Local integrability of coordinates.) Let (μ, v) be any representation of T and g^I(x) := v(x)(dx^I). Fix a compact K ⊆ U.
   - By the representation property, x ↦ v(x)(χ_K(x)·dx^I) = χ_K(x)·g^I(x) is μ-integrable.
   - This function coincides with g^I on the Borel (closed) set K, so g^I is μ-integrable on K.
   - Hence G := Σ_I |g^I| is μ-integrable on K.
4. (Pointwise bound.) By pairing_expansion, for all x and all n-covectors α, v(x)(α) = Σ_I α_I·g^I(x) and |α_I| ≤ |α|. Hence |v(x)(α)| ≤ |α|·G(x).
5. (Existence, (a).) Fix (μ, v) and a Borel set A. For ω ∈ Dⁿ(U) set S(ω) := ∫_A v(x)(ω(x)) dμ(x).
   - Linearity: each integrand is μ-integrable on ℝ^P, hence on A, so S is ℝ-linear (linearity of the integral and of each v(x)).
   - Sequential continuity: let ω_j → 0 in Dⁿ(U) (TestFormOnConverges ω_j 0). Then there is a compact K ⊆ U containing every tsupport ω_j, and the 0-th derivatives converge uniformly on K. Since ‖iteratedFDeriv ℝ 0 ω_j x‖ = ‖ω_j(x)‖ (norm_iteratedFDeriv_zero), ε_j := sup_{x∈K} ‖ω_j(x)‖ → 0. As ω_j = 0 off K, steps 1 and 4 give |S(ω_j)| ≤ ∫_K |v(x)(ω_j(x))| dμ ≤ √N·ε_j·∫_K G dμ → 0.
   - So S is a GeometricCurrentOn U n. IsRestriction T A S holds by construction: A is measurable and S(ω) = ∫_A ⟨ω,v⟩ dμ with the representation (μ, v).
6. (Finiteness, (b).) Suppose IsRestriction T A S. Then A is Borel and S(ω) = ∫_A v′(x)(ω(x)) dμ′(x) for some representation (μ′, v′) of T.
   - Let W ⊂⊂ U and K := closure W, compact with K ⊆ U. By step 3 for (μ′, v′), G′ := Σ_I |v′(·)(dx^I)| is μ′-integrable on K.
   - Let ω ∈ Dⁿ(U) be admissible for M_W, i.e. tsupport ω ⊆ W and |ω(x)| ≤ 1 for all x (massAdmissibleOn U n W).
   - Then v′(x)(ω(x)) = 0 for x ∉ K, and |v′(x)(ω(x))| ≤ G′(x) by step 4. Hence S(ω) ≤ ∫_A |v′(ω)| dμ′ ≤ ∫_K G′ dμ′ =: c_W < ∞.
   - Therefore M_W(S) = sup ofReal(S(ω)) ≤ ofReal(c_W) < ∞. ∎

## Key steps

1. Covector norm comparison: |α_I| ≤ ‖α‖, so covectorEuclideanNorm α ≤ √N ‖α‖.
2. Smooth cut-offs χ_K make χ_K·dx^I test forms; the coordinates v(·)(dx^I) are integrable on compact K ⊆ U.
3. pairing_expansion: |v(x)(α)| ≤ covectorEuclideanNorm(α)·Σ_I |v(x)(dx^I)|.
4. S(ω) := ∫_A ⟨ω,v⟩ dμ is linear and sequentially continuous, hence a current with IsRestriction T A S.
5. Any restriction satisfies S(ω) ≤ ∫_{closure W} Σ_I |v′^I| dμ′ for admissible ω, so M_W(S) < ∞.
