## Proof

Conventions. ℝⁿ = Eucl n = EuclideanSpace ℝ (Fin n). Lⁿ = volume, an additive Haar measure on the finite-dimensional space ℝⁿ. Dh(w) := fderiv ℝ h w, which is 0 where h is not differentiable. e_1, …, e_n is the standard orthonormal basis, e_i = EuclideanSpace.single i 1. For the field b, b_i := proj_i ∘ b, so b_i(x) is the i-th coordinate of b(x); here proj_i = EuclideanSpace.proj i is a continuous linear map, and b(x) = Σ_i b_i(x) e_i. All integrals are Bochner integrals for Lⁿ. Source: parent proof, steps 3–4; their argument uses only that b is C¹.
1. (Coordinates of b.) For each i, b_i = proj_i ∘ b is C¹, as the composition of the C¹ map b with a continuous linear map. Since proj_i(0) = 0, b_i has compact support (`HasCompactSupport.comp_left`) and tsupport b_i ⊆ tsupport b (`tsupport_comp_subset`). A C¹ function with compact support is globally Lipschitz: its derivative is continuous with compact support, hence bounded, and the mean value inequality applies (Mathlib `ContDiff.lipschitzWith_of_hasCompactSupport`, with n = 1 ≠ 0). Fix D_i ≥ 0 such that b_i is D_i-Lipschitz. Moreover b_i is differentiable everywhere and w ↦ Db_i(w) is continuous (`ContDiff.differentiable`, `ContDiff.continuous_fderiv`). Finally tsupport(Db_i) ⊆ tsupport b_i (`tsupport_fderiv_subset`), so Db_i(w) = 0 whenever w ∉ tsupport b.
2. (Definition of g.) Put g(w) := Σ_i Db_i(w)(e_i). Each summand is continuous in w, being the continuous map w ↦ Db_i(w) followed by evaluation at the fixed vector e_i; so g is continuous. By step 1, g(w) = 0 for w ∉ tsupport b. Since tsupport b is compact, g has compact support (`HasCompactSupport.intro`). Being continuous with compact support, g is Lⁿ-integrable on ℝⁿ (`Continuous.integrable_of_hasCompactSupport`). Also, since tsupport b ⊆ Ω, b(w) = 0 and g(w) = 0 for every w ∉ Ω. Now fix L ≥ 0 and f : ℝⁿ → ℝ that is L-Lipschitz on Ω. Note that g does not depend on L or f.
3. (McShane extension.) By McShane's extension theorem (Mathlib `LipschitzOnWith.extend_real`), there is F : ℝⁿ → ℝ which is L-Lipschitz on all of ℝⁿ and satisfies F = f on Ω. For w ∈ Ω, f and F agree on the neighbourhood Ω of w, so Df(w) = DF(w) (`Filter.EventuallyEq.fderiv_eq`).
4. (Claim (a).) F is continuous and g is continuous with compact support, so F·g is continuous with compact support. Hence F·g is integrable on ℝⁿ, and in particular on Ω. Since f·g = F·g on the measurable set Ω, f·g is integrable on Ω (`IntegrableOn.congr_fun`). This proves (a).
5. (Reduction to an identity on ℝⁿ.) By step 3, ∫_Ω Df(w)(b(w)) dw = ∫_Ω DF(w)(b(w)) dw (`setIntegral_congr_fun`). For w ∉ Ω we have DF(w)(b(w)) = DF(w)(0) = 0, so this equals ∫_{ℝⁿ} DF(w)(b(w)) dw (`setIntegral_eq_integral_of_forall_compl_eq_zero`). Likewise ∫_Ω f g = ∫_Ω F g = ∫_{ℝⁿ} F g, because F(w)g(w) = 0 for w ∉ Ω. Hence (b) is equivalent to the identity (★) ∫ DF(w)(b(w)) dw = −∫ F(w)g(w) dw over ℝⁿ.
6. (Expansion in coordinates.) For every w, b(w) = Σ_i b_i(w) e_i (expansion in the orthonormal basis `EuclideanSpace.basisFun`, `Basis.sum_repr`). By linearity, DF(w)(b(w)) = Σ_i DF(w)(e_i)·b_i(w). Each summand is integrable on ℝⁿ. Indeed, w ↦ DF(w)(e_i) is Borel measurable (`measurable_fderiv` followed by evaluation at e_i), and |DF(w)(e_i)| ≤ ‖DF(w)‖·|e_i| ≤ L for all w (`norm_fderiv_le_of_lipschitz`). Also b_i is continuous with compact support, hence integrable. A bounded measurable function times an integrable function is integrable (`Integrable.bdd_mul`). Therefore ∫ DF(w)(b(w)) dw = Σ_i ∫ DF(w)(e_i)·b_i(w) dw (`integral_finset_sum`).
7. (Rademacher and integration by parts in one coordinate.) Fix i. By Rademacher's theorem (Mathlib `LipschitzWith.ae_differentiableAt` for the Haar measure Lⁿ), F is differentiable at Lⁿ-a.e. w. At every such w, lineDeriv ℝ F w e_i = DF(w)(e_i) (`DifferentiableAt.lineDeriv_eq_fderiv`). Hence ∫ DF(w)(e_i)·b_i(w) dw = ∫ lineDeriv ℝ F w e_i · b_i(w) dw (`integral_congr_ae`). Apply the integration by parts formula for Lipschitz functions (Mathlib `LipschitzWith.integral_lineDeriv_mul_eq`) to F (L-Lipschitz), b_i (D_i-Lipschitz with compact support) and v = e_i; it applies because Lⁿ is an additive Haar measure on a finite-dimensional space. It gives ∫ lineDeriv ℝ F w e_i · b_i(w) dw = ∫ lineDeriv ℝ b_i w (−e_i) · F(w) dw. Since b_i is differentiable at every w, lineDeriv ℝ b_i w (−e_i) = Db_i(w)(−e_i) = −Db_i(w)(e_i). Therefore ∫ DF(w)(e_i)·b_i(w) dw = −∫ Db_i(w)(e_i)·F(w) dw (`integral_neg`).
8. (Summation.) For each i, w ↦ Db_i(w)(e_i)·F(w) is continuous and vanishes outside the compact set tsupport b (step 1), so it is integrable. Combining steps 6 and 7: ∫ DF(w)(b(w)) dw = Σ_i (−∫ Db_i(w)(e_i)·F(w) dw) = −∫ Σ_i Db_i(w)(e_i)·F(w) dw = −∫ F(w)g(w) dw (`integral_finset_sum`, `Finset.mul_sum`). This is (★), so by step 5 claim (b) holds. Together with step 2 (g is integrable) and step 4 (claim (a)), g has all the required properties, and it serves for every L and f. ∎

## Key steps

1. The coordinates b_i = proj_i ∘ b are C¹, have compact support and are Lipschitz (ContDiff.lipschitzWith_of_hasCompactSupport); Db_i = 0 outside tsupport b.
2. g := Σ_i Db_i(·)(e_i) is continuous with compact support inside tsupport b ⊆ Ω, hence integrable; g and b vanish off Ω.
3. McShane extension F of f: F is L-Lipschitz on ℝⁿ, F = f and DF = Df on Ω; f·g = F·g is integrable on Ω, and both integrals reduce to integrals over ℝⁿ with F.
4. DF(w)(b(w)) = Σ_i DF(w)(e_i)·b_i(w); each term is integrable because |DF(w)(e_i)| ≤ L and b_i is continuous with compact support.
5. By Rademacher, DF(w)(e_i) = lineDeriv ℝ F w e_i a.e.; LipschitzWith.integral_lineDeriv_mul_eq gives ∫ lineDeriv ℝ F w e_i · b_i = −∫ Db_i(w)(e_i)·F(w).
6. Summing over i gives ∫ DF(b) = −∫ F g, hence ∫_Ω Df(b) = −∫_Ω f g.
