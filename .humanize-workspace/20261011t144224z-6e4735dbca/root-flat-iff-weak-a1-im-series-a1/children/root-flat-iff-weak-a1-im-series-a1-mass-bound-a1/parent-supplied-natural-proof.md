## Proof

Notation: |α| := covectorEuclideanNorm α for a k-covector α; e_1, …, e_P is the standard basis (EuclideanSpace.basisFun).

1. (Homogeneity.) For a ∈ ℝ and a k-covector α, |a • α| = |a|·|α|.
   - (a • α)(v) = a·α(v) for every k-tuple v.
   - So each summand (α(e_{I_1}, …, e_{I_k}))² with I strictly increasing, in the sum under the square root defining covectorEuclideanNorm, is multiplied by a². The other summands are 0.
   - √(a²·s) = |a|·√s for s ≥ 0.

2. (Rescaled forms are admissible.) For s ∈ {1, −1} let η_s := (s·C⁻¹) • η, an element of the submodule TestFormOn U k.
   - Its underlying form is x ↦ s·C⁻¹·η(x), so its support lies in that of η, and tsupport η_s ⊆ tsupport η ⊆ V (tsupport_smul_subset_right).
   - By step 1, |η_s(x)| = C⁻¹·|η(x)| ≤ C⁻¹·C = 1 for every x.
   - Hence η_s ∈ massAdmissibleOn U k V.

3. (Definition of mass.)
   - By GeometricCurrentOn.le_massOn, ENNReal.ofReal(X(η_s)) ≤ M_V(X).
   - X.toCurrent is ℝ-linear (map_smul), so X(η_s) = s·C⁻¹·X(η).
   - Choose s := 1 if X(η) ≥ 0 and s := −1 otherwise. Then s·X(η) = |X(η)|, so ENNReal.ofReal(C⁻¹·|X(η)|) ≤ M_V(X).

4. (Undo the scaling.) Since C > 0 and C⁻¹·|X(η)| ≥ 0,
   ENNReal.ofReal|X(η)| = ENNReal.ofReal(C⁻¹·|X(η)|·C) = ENNReal.ofReal(C⁻¹·|X(η)|)·ENNReal.ofReal C   (ENNReal.ofReal_mul)
   ≤ M_V(X)·ENNReal.ofReal C   (multiplication is monotone in [0, ∞]). ∎

## Key steps

1. covectorEuclideanNorm is absolutely homogeneous: |a·α| = |a|·|α|
2. ±C⁻¹η lies in massAdmissibleOn U k V (tsupport ⊆ V, pointwise norm ≤ 1)
3. le_massOn and linearity give ofReal(C⁻¹|X(η)|) ≤ M_V(X)
4. multiply by ofReal C (C > 0)
