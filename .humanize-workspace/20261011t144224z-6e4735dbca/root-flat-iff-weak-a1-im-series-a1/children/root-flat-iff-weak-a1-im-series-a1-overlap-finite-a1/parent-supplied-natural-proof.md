## Proof

Notation: |c_r| := ((c_r).natAbs : ℝ≥0∞) and g_r := |c_r|·1_{M_r}·ofReal θ_r, so Θ = Σ'_r g_r.

1. (Measurability.) Fix W with CompactlyContainedOpen W U and fix r.
   - closure W is a compact subset of U, so θ_r is integrable, hence a.e.-strongly measurable, on M_r ∩ closure W, and therefore on M_r ∩ W.
   - W is open, hence measurable, so (H.restrict W).restrict M_r = H.restrict(M_r ∩ W) (Measure.restrict_restrict'). Also M_r is null-measurable for H.restrict W.
   - By aemeasurable_indicator_iff₀, 1_{M_r}·ofReal θ_r, and hence g_r, is AEMeasurable for H.restrict W.
   - So is Θ (AEMeasurable.ennreal_tsum).

2. (Integral over W.) By lintegral_tsum (using step 1), lintegral_const_mul' (|c_r| < ∞) and lintegral_indicator₀:
   ∫⁻_W Θ dH = Σ'_r |c_r|·∫⁻_W 1_{M_r}·ofReal θ_r dH = Σ'_r |c_r|·∫⁻_{M_r ∩ W} ofReal θ_r dH < ∞, by hypothesis.

3. (Conclusion (a).) Let K ⊆ U be compact.
   - ℝ^P is locally compact and regular, so exists_open_between_and_isCompact_closure gives an open W with K ⊆ W, closure W ⊆ U and closure W compact, i.e. CompactlyContainedOpen W U.
   - By lintegral_mono_set and step 2, ∫⁻_K Θ dH ≤ ∫⁻_W Θ dH < ∞.

4. (Θ < ∞ a.e. on U.) Let N := {x ∈ U : Θ(x) = ∞}.
   - For x ∈ N, the construction of step 3 with K := {x} gives W_x ⊂⊂ U with x ∈ W_x.
   - By steps 1–2, Θ is AEMeasurable for H.restrict W_x and has finite integral there, so Θ < ∞ H.restrict W_x-a.e. (ae_lt_top').
   - W_x is measurable, so ae_restrict_iff' gives H({y ∈ W_x : Θ(y) = ∞}) = 0, hence H(N ∩ W_x) = 0.
   - W_x is an open neighbourhood of x, so N ∩ W_x ∈ 𝓝[N] x.
   - ℝ^P is second countable, so measure_null_of_locally_null gives H(N) = 0.

5. (Conclusion (b).) Let x ∉ N and F(x) := {r : c_r ≠ 0, x ∈ M_r}.
   - If x ∉ U, then x ∉ M_r for every r (M_r ⊆ U), so F(x) = ∅.
   - If x ∈ U, then Θ(x) < ∞. For r ∈ F(x), |c_r| ≥ 1 (a nonzero integer) and 1_{M_r}(x)·ofReal θ_r(x) = ofReal θ_r(x) ≥ 1, so g_r(x) ≥ 1.
   - If F(x) were infinite, then for every m ∈ ℕ it would contain a finite subset F_m with m elements (Set.Infinite.exists_subset_card_eq). Then Θ(x) ≥ Σ_{r∈F_m} g_r(x) ≥ m for every m (ENNReal.sum_le_tsum), contradicting Θ(x) < ∞.
   - Hence F(x) is finite for every x ∉ N. Since H(N) = 0, F(x) is finite for H-a.e. x. ∎

## Key steps

1. each term |c_r| 1_{M_r} θ_r is AEMeasurable on W ⊂⊂ U (θ_r is integrable on M_r ∩ closure W)
2. lintegral_tsum: ∫⁻_W Θ = Σ|c_r| ∫⁻_{M_r∩W} θ_r < ∞, and every compact K ⊆ U lies in some W ⊂⊂ U
3. Θ < ∞ a.e. on each W_x, so measure_null_of_locally_null makes {x ∈ U : Θ(x) = ∞} null
4. each r with c_r ≠ 0 and x ∈ M_r contributes ≥ 1 to Θ(x), so a.e. only finitely many such r
