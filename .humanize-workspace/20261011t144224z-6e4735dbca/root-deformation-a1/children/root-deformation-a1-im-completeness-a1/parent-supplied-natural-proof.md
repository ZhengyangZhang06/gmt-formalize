## Proof

Source: Simon, Ch. 6, Lemma 3.13 (p. 149: “The set of integer multiplicity currents in D_n(U) is complete with respect to the topology given by the family {M_W}_{W⊂⊂U} of semi-norms”) and its printed proof (displays (1)–(3), pp. 149–150), as summarized in A4(f) of the parent proof (“if T_Q are integer multiplicity and Cauchy for M, then their M-limit is integer multiplicity”). Below the printed proof is written out with the details it leaves to the reader: the lower bound (1) for the mass of a difference, the passage to an a.e. convergent subsequence, and the identification of the approximate tangent spaces (Simon Ch. 3, 1.4–1.9, Remark 1.8(1), and the Upper Density Theorem Ch. 1, 3.6).

Setting. H^k = μHE[k], U = ℝ^N. T ∈ D_k(ℝ^N), T_j = τ(M_j, θ_j, ξ_j) with IsRectifiableTriple univ k M_j θ_j ξ_j and θ_j natural-valued on M_j, and (hypothesis) for every ε > 0 there is J such that M(D) < ε for every j ≥ J and every current D with D(ω) = T(ω) − T_j(ω) for all ω. Extend θ_j := 0 and ξ_j := 0 off M_j and put κ_j := θ_jξ_j. Conventions: for a k-vector w, w^γ := w(dx^γ) (γ increasing), |w| := (Σ_γ(w^γ)²)^{1/2}; for a k-covector α, |α| = covectorEuclideanNorm α; every covector is α = Σ_γα(e_γ)dx^γ, so |w(α)| ≤ |α||w|. Unit fact: if τ₁,…,τ_k are orthonormal then |simpleNVector τ| = 1, because its coordinates (simpleNVector τ)^γ = det(τ_i·e_{γ_j}) are the k×k minors of the matrix with columns τ₁,…,τ_k and, by the Cauchy–Binet formula, Σ_γ det(τ_i·e_{γ_j})² = det(τ_i·τ_j) = 1; consequently, whenever IsRectifiableTriple U k M θ ξ holds, |ξ| = 1 H^k-a.e. on M (orientation clause). Hence |ξ_j| = 1 H^k-a.e. on M_j and |κ_j| = θ_j H^k-a.e. Degenerate dimensions: if k > N, every k-covector on ℝ^N is 0, so T = 0 = τ(∅, 0, 0) is integer multiplicity; k = 0 and N = 0 need no change below. Since θ_j ≥ 1 on M_j and θ_j is integrable on M_j ∩ K for compact K, H^k⌞M_j is locally finite; M_∞ := ⋃_jM_j is countably k-rectifiable, H^k-null-measurable and σ-finite for H^k, and λ := H^k⌞M_∞. For each pair i, j the difference T_i − T_j is a current (difference of linear sequentially continuous functionals), with M(T_i − T_j) ≤ M(T − T_i) + M(T − T_j) (mass is subadditive: for admissible ω, (T_i − T_j)(ω) = (T − T_j)(ω) − (T − T_i)(ω)).

1. Subsequence. Choose j₁ < j₂ < ⋯ with M(T − T_{j_p}) < 2^{−p}; then M(T_{j_{p+1}} − T_{j_p}) < 2^{1−p}, so Σ_p M(T_{j_{p+1}} − T_{j_p}) < ∞. Relabel the subsequence as (T_j) (the conclusion concerns only T). In particular M(T − T_j) → 0 and M(T − T_j) < ∞ for all j.

2. Mass of a current with a locally integrable density (printed (1)). Lemma. Let λ′ be a locally finite Borel measure on ℝ^N and κ a k-vector field that is λ′-integrable on bounded sets, and let Y ∈ D_k(ℝ^N) satisfy Y(ω) = ∫⟨ω, κ⟩dλ′ for all test forms ω. Then M(Y) ≥ ∫|κ|dλ′ (in [0,∞]). Proof: fix R > 0 and ε > 0, let ν := |κ|λ′⌞B_R(0) (a finite Borel measure) and u := κ/|κ| on {κ ≠ 0}. By inner regularity choose a compact K ⊆ B_R(0) ∩ {κ ≠ 0} with ν(ℝ^N ∖ K) < ε, and by Lusin's theorem (Simon Ch. 1, 1.17) a compact K′ ⊆ K with ν(K ∖ K′) < ε and u|_{K′} continuous. Let u♭ := Σ_γu^γdx^γ (|u♭| = 1 and ⟨u♭, u⟩ = 1 on K′), extend u♭|_{K′} continuously to ℝ^N (Tietze), compose with y ↦ y/max{1,|y|} and multiply by a continuous χ with 0 ≤ χ ≤ 1, χ = 1 on K′ and compact support in B_R(0): this gives f ∈ C_c with |f| ≤ 1, spt f ⊆ B_R(0) and ∫⟨f, κ⟩dλ′ ≥ ν(K′) − ν(ℝ^N ∖ K′) ≥ ν(ℝ^N) − 4ε (|⟨α, w⟩| ≤ |α||w|). The mollifications f_δ are test forms with |f_δ| ≤ 1, supported in a fixed compact set and converging uniformly to f, so Y(f_δ) → ∫⟨f, κ⟩dλ′ by dominated convergence and M(Y) ≥ ∫_{B_R(0)}|κ|dλ′ − 4ε. Let ε ↓ 0 and R ↑ ∞.
 Applied to Y := T_i − T_j, λ′ := H^k⌞(M_i ∪ M_j) (locally finite) and κ := κ_i − κ_j (integrable on bounded sets, since θ_i, θ_j are), and noting that κ_i, κ_j vanish off M_i ∪ M_j: (1) ∫|κ_i − κ_j|dλ ≤ M(T_i − T_j).

3. Convergence of the densities (printed (2), (3)). By (1) and Step 1, Σ_j∫|κ_{j+1} − κ_j|dλ < ∞; since ||κ_{j+1}| − |κ_j|| ≤ |κ_{j+1} − κ_j| and |κ_j| = θ_j λ-a.e., also Σ_j∫|θ_{j+1} − θ_j|dλ < ∞. Hence the series κ₁ + Σ_j(κ_{j+1} − κ_j) and θ₁ + Σ_j(θ_{j+1} − θ_j) converge λ-a.e. (absolutely) to functions κ, θ, with ∫|κ_j − κ|dλ ≤ Σ_{i≥j}∫|κ_{i+1} − κ_i|dλ → 0 and likewise ∫|θ_j − θ|dλ → 0 (only the differences need to be integrable). θ is λ-a.e. a limit of non-negative integers, hence λ-a.e. an integer; changing θ on a λ-null set we take θ integer valued ≥ 0 and put M₊ := {x ∈ M_∞ : θ(x) > 0} = {θ ≥ 1}. Also |κ| = θ λ-a.e.; set ξ := κ/θ on M₊ and ξ := 0 elsewhere, so |ξ| = 1 λ-a.e. on M₊ and κ = θξ1_{M₊} λ-a.e.

4. T = τ(M₊, θ, ξ). For every test form ω, |T(ω) − T_j(ω)| ≤ M(T − T_j)‖ω‖ → 0, and |∫⟨ω, κ_j⟩dλ − ∫⟨ω, κ⟩dλ| ≤ ‖ω‖∫|κ_j − κ|dλ → 0; since T_j(ω) = ∫⟨ω, κ_j⟩dλ, T(ω) = ∫⟨ω, κ⟩dλ = ∫_{M₊}θ⟨ω, ξ⟩dH^k = tauAction k M₊ θ ξ ω.

5. Approximate tangent spaces (Simon Ch. 3, 1.4–1.9). Say a set E has approximate tangent space Π at x if finrank Π = k and ∫_{η_{x,r}(E)}f dH^k → ∫_Πf dH^k (r ↓ 0) for all f ∈ C_c(ℝ^N), where η_{x,r}(y) := r⁻¹(y − x) is a similarity of ratio 1/r (∫_{η_{x,r}(E)}g dH^k = r^{−k}∫_Eg∘η_{x,r}dH^k, x + r·η_{x,r}(z) = z); HasWATS(E, ϑ, x, Π) abbreviates HasWeightedApproximateTangentSpaceAt k E ϑ x Π.
 Lemma A (locality). If E ⊆ E′ are H^k-null-measurable, H^k⌞E′ is locally finite and ϑ is positive and locally integrable on E′, then for H^k-a.e. x ∈ E and every Π: E has approximate tangent space Π at x ⟺ E′ has; and HasWATS(E, ϑ, x, Π) ⟺ HasWATS(E′, ϑ, x, Π). Proof: by the Upper Density Theorem (Simon Ch. 1, 3.6 with Remark 3.7(2)), H^k⌞(E′∖E) and ϑH^k⌞(E′∖E) have k-density 0 at H^k-a.e. x ∉ E′ ∖ E; for such x and spt f ⊆ B_R(0), |∫_{η_{x,r}(E′∖E)}f| ≤ ‖f‖r^{−k}H^k((E′∖E) ∩ B_{Rr}(x)) → 0 and |∫_{η_{x,r}(E′∖E)}f(y)ϑ(x+ry)dH^k(y)| ≤ ‖f‖r^{−k}(ϑH^k)((E′∖E) ∩ B_{Rr}(x)) → 0.
 Lemma B (weights; Ch. 3, Remark 1.8(1)). If E is H^k-null-measurable with H^k⌞E locally finite and ϑ is positive, measurable and locally integrable on E, then for H^k-a.e. x ∈ E and every Π: HasWATS(E, ϑ, x, Π) ⟺ E has approximate tangent space Π at x. Proof: Lusin gives compact K₁ ⊆ K₂ ⊆ ⋯ ⊆ E with H^k(E ∖ ⋃K_i) = 0 and ϑ|_{K_i} continuous; at H^k-a.e. x ∈ K_i, H^k⌞(E∖K_i) and ϑH^k⌞(E∖K_i) have density 0 (as in Lemma A), so both defining integrals can be computed on η_{x,r}(K_i) up to o(1); on K_i ∩ B_{Rr}(x), |ϑ − ϑ(x)| ≤ ε(r) → 0, which makes the weighted integral equal to ϑ(x) times the unweighted one up to ε(r)‖f‖r^{−k}H^k(K_i ∩ B_{Rr}(x)); this quantity is bounded under either hypothesis (test with a continuous f ≥ 1_{B_R(0)}; under the weighted hypothesis use ϑ ≥ ϑ(x)/2 > 0 on K_i ∩ B_{Rr}(x) for small r), and ϑ(x) > 0; hence the two limits correspond.

6. The triple conditions for (M₊, θ, ξ). M₊ ⊆ univ; M₊ ⊆ M_∞ is countably k-rectifiable and H^k-null-measurable (θ is λ-measurable); θ is natural-valued and positive on M₊; for compact K, ∫_{M₊∩K}θ ≤ ∫_Kθ₁dλ + Σ_j∫|θ_{j+1} − θ_j|dλ < ∞, so θ is integrable on M₊ ∩ K and H^k⌞M₊ is locally finite (θ ≥ 1 on M₊); ξ is a.e. strongly measurable for H^k⌞M₊ (an a.e. limit of the measurable ξ_j = κ_j/θ_j, see below). Orientation: let N₀ be the λ-null set off which θ_j → θ and κ_j → κ; for each j let N_j be the H^k-null set off which the orientation clause of (M_j, θ_j, ξ_j) holds on M_j and the equivalences of Lemma B for (M_j, θ_j) and for (M₊, θ) and of Lemma A for M_j ∩ M₊ ⊆ M_j and M_j ∩ M₊ ⊆ M₊ hold on M_j ∩ M₊. Let x ∈ M₊ ∖ (N₀ ∪ ⋃_jN_j). Since θ_j(x) → θ(x) ≥ 1 and θ_j(x) ∈ ℕ, there is j(x) with θ_j(x) = θ(x) for j ≥ j(x); then x ∈ M_j (θ_j = 0 off M_j) and ξ_j(x) = κ_j(x)/θ_j(x) → κ(x)/θ(x) = ξ(x). For j ≥ j(x), ξ_j(x) = ±simpleNVector τ^j with τ^j orthonormal and HasWATS(M_j, θ_j, x, span τ^j); by Lemma B, Lemma A (twice) and Lemma B again, HasWATS(M₊, θ, x, span τ^j). As θ(x) ≠ 0, the weighted approximate tangent space of (M₊, θ) at x is unique (SimonGMT HasWeightedApproximateTangentSpaceAt.unique), so Π := span τ^j does not depend on j ≥ j(x). Fix an orthonormal basis τ of Π; any two orthonormal bases of Π have simple k-vectors differing by the determinant ±1 of the orthogonal change of basis, so ξ_j(x) ∈ {simpleNVector τ, −simpleNVector τ} for all j ≥ j(x); these two k-vectors are distinct (|simpleNVector τ| = 1), so the convergent sequence ξ_j(x) is eventually constant and ξ(x) = ±simpleNVector τ, with HasWATS(M₊, θ, x, span τ). Hence the orientation clause holds at H^k-a.e. x ∈ M₊.

7. Conclusion. IsRectifiableTriple univ k M₊ θ ξ holds, θ is natural-valued on M₊, and T(ω) = tauAction k M₊ θ ξ ω for every ω (Step 4): IsIntegerMultiplicity T. ∎

## Key steps

1. Pass to a subsequence with Σ_j M(T_{j+1} − T_j) < ∞.
2. Mass lower bound for densities (printed (1)): ∫|θ_iξ_i − θ_jξ_j| dH^k ≤ M(T_i − T_j) (Lusin/Tietze/mollification).
3. θ_j → θ (integer valued) and θ_jξ_j → κ = θξ in L¹ and a.e. (printed (2),(3)); T = τ({θ > 0}, θ, ξ).
4. Locality and weight lemmas for approximate tangent spaces (Upper Density Theorem, Ch. 3 Remark 1.8(1)).
5. At a.e. x ∈ M₊, eventually x ∈ M_j, θ_j(x) = θ(x), tangent spaces agree with that of (M₊, θ), ξ_j(x) = ±simpleNVector τ, so ξ(x) = ±simpleNVector τ: T is integer multiplicity.
