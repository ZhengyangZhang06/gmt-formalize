## Proof

Conventions. ℝ^P = Eucl P = EuclideanSpace ℝ (Fin P) with standard basis b_i = EuclideanSpace.single i 1 = EuclideanSpace.basisFun (Fin P) ℝ i (i ∈ Fin P). A k-covector is α ∈ Covector (Eucl P) k (a continuous alternating k-linear map ℝ^P → ℝ) with operator norm ‖α‖; |α| := covectorEuclideanNorm α = (Σ_{I : Fin k → Fin P strictly increasing} α(b_{I(0)},…,b_{I(k−1)})²)^{1/2}. A k-vector is w ∈ NVector (Eucl P) k, a continuous linear functional on k-covectors. D^k(U) = TestFormOn U k (smooth, compactly supported forms with tsupport ⊆ U), D_k(U) = GeometricCurrentOn U k, M_W(T) = T.massOn W = sup{ENNReal.ofReal(T(ω)) : ω ∈ D^k(U), tsupport ω ⊆ W, |ω(x)| ≤ 1 ∀x} (massAdmissibleOn). CF(U) := {φ : ℝ^P → Covector (Eucl P) k : φ continuous, HasCompactSupport φ, tsupport φ ⊆ U}. All measures are Borel measures on ℝ^P; ∫_A f dμ means ∫ x in A, f x ∂μ (integral for μ.restrict A). Source: Simon, Introduction to GMT, Ch. 6, 2.7–2.9 (pp. 136–137), with Ch. 1, 4.14 (Riesz) and 1.17 (Lusin); this argument is extracted from the parent proof of slicing_mass_representation (its steps are cited as P1–P7).

This is the mollification fact used in the parent proof (conventions paragraph and steps P2, P6(v)); the cutoff below keeps the support exactly inside V. Notation: M := #(Fin k → Fin P).

1. (Norm comparison.) For every covector α and every I : Fin k → Fin P, |α(b_{I(0)},…,b_{I(k−1)})| ≤ ‖α‖·∏_j ‖b_{I(j)}‖ = ‖α‖ (ContinuousAlternatingMap.le_opNorm and ‖b_i‖ = 1). Hence |α|² ≤ M‖α‖², i.e. |α| ≤ √M·‖α‖. Put c := √M + 1 > 0 and ε′ := ε/c > 0.
2. (Intermediate open set.) K := tsupport φ is compact (HasCompactSupport φ) and K ⊆ V. Choose an open V′ with K ⊆ V′, closure V′ compact and closure V′ ⊆ V (exists_open_between_and_isCompact_closure; ℝ^P is locally compact and regular).
3. (Cutoff.) Choose a C^∞ function χ : ℝ^P → [0,1] with support χ = V′ and χ(x) = 1 ⇔ x ∈ K (exists_contDiff_support_eq_eq_one_iff for the open set V′, the closed set K ⊆ V′, smoothness order ∞). Then tsupport χ = closure V′ ⊆ V, a compact set.
4. (Mollification.) φ is continuous with compact support, hence uniformly continuous; choose δ > 0 with ‖φ(x) − φ(y)‖ < ε′ whenever dist(x, y) < δ. Let ψ ≥ 0 be a C^∞ function with compact support contained in the ball B(0, δ) and ∫ψ = 1 (normalize a smooth bump given by exists_contDiff_tsupport_subset; its integral is positive). The convolution g := ψ ⋆ φ (Mathlib convolution with ContinuousLinearMap.lsmul ℝ ℝ and Lebesgue measure) is C^∞ (HasCompactSupport.contDiff_convolution_left; φ is locally integrable), and ‖g(x) − φ(x)‖ ≤ ε′ for every x, since g(x) is a ψ-weighted average of values φ(x − y) with |y| < δ (dist_convolution_le). (Equivalently one may invoke UniformContinuous.exists_contDiff_dist_le.)
5. (The test form.) Let η(x) := χ(x)·g(x). η is C^∞ (product of C^∞ maps); tsupport η ⊆ tsupport χ = closure V′ ⊆ V ⊆ U; tsupport η is compact, being a closed subset of the compact set closure V′. Hence η ∈ TestFormOn U k (smooth, compact support, tsupport ⊆ U) and tsupport η ⊆ V.
6. (Estimate.) If x ∈ K, then χ(x) = 1 and ‖φ(x) − η(x)‖ = ‖φ(x) − g(x)‖ ≤ ε′. If x ∉ K, then φ(x) = 0 and ‖φ(x) − η(x)‖ = χ(x)‖g(x)‖ ≤ ‖g(x)‖ = ‖g(x) − φ(x)‖ ≤ ε′ (0 ≤ χ ≤ 1). Thus ‖φ(x) − η(x)‖ ≤ ε′ for every x, and by step 1, covectorEuclideanNorm(φ(x) − η(x)) ≤ √M·ε′ = √M·ε/(√M + 1) ≤ ε. ∎

Formalization note (not part of the argument): an identical statement (with n for k) is kernel-checked as cmb_exists_testForm_uniform_approx in commit 26d9d850fd2374ebf1db98e6e929674fd089a6ad of this repository (another DAG branch); its proof follows exactly steps 1–6 and may be adapted.

## Key steps

1. Norm comparison |α| ≤ √M‖α‖ with M = #(Fin k → Fin P).
2. Open V′ with tsupport φ ⊆ V′ ⊆ closure V′ ⊆ V, closure V′ compact.
3. Smooth cutoff χ ∈ [0,1], support χ = V′, χ = 1 exactly on tsupport φ.
4. Mollify: g = ψ ⋆ φ smooth with ‖g − φ‖ ≤ ε/(√M+1).
5. η := χ·g ∈ TestFormOn U k, tsupport η ⊆ V, and |φ − η| ≤ ε pointwise.
