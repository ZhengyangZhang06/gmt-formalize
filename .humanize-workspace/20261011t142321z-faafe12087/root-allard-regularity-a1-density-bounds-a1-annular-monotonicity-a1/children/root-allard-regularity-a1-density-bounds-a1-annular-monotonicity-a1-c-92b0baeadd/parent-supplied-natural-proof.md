## Proof

Source: step 9 of the parent proof (existence of the density at the centre; Simon, Ch. 4, 4.8-4.9 and the argument of Section 3), stated for an abstract measure mu.

Notation: B_r := closedBall y r, m(r) := mu(B_r).toReal, Phi(r) := F(r)(r^n)^(-1) m(r) + F(r) - 1, omega := unitBallVolume n.

1. Finiteness. For r in (0, R):
 - mu(B_r) <= mu(B_R) < infinity, so mu(B_r) = ofReal(m(r)) and m(r) >= 0;
 - F(r) >= exp(-Lambda) > 0.

2. F(r) -> 1 as r -> 0+.
 - Since R > 0 there is some r_0 in (0, R). Then 0 <= |F(r_0) - 1| <= Lambda (r_0/R)^alpha with (r_0/R)^alpha > 0, so Lambda >= 0.
 - As alpha > 0, (r/R)^alpha -> 0^alpha = 0 as r -> 0+.
 - So |F(r) - 1| <= Lambda (r/R)^alpha -> 0 for r in (0, R).

3. Limit of Phi.
 - For r in (0, R): Phi(r) = F(r)(1 + m(r)/r^n) - 1 >= F(r) - 1 >= exp(-Lambda) - 1.
 - So Phi is nondecreasing (H2) and bounded below on (0, R).
 - Hence L := inf over (0, R) of Phi is a real number, Phi(r) -> L as r -> 0+, and L <= Phi(r) for all r in (0, R).

4. Limit of the mass ratio.
 - For r in (0, R), m(r)/r^n = (Phi(r) + 1)/F(r) - 1, which tends to (L + 1)/1 - 1 = L by steps 2 and 3.
 - Since m(r)/r^n >= 0, L >= 0.

5. Positivity of omega. omega = pi^(n/2)/Gamma(n/2 + 1) > 0, because pi^(n/2) > 0 and Gamma is positive on (0, infinity).

6. The density. Put t := L/omega >= 0.
 - For r in (0, R), omega r^n > 0, so mu(B_r)/ofReal(omega r^n) = ofReal(m(r))/ofReal(omega r^n) = ofReal(m(r)/(omega r^n)) = ofReal((m(r)/r^n)/omega).
 - As r -> 0+, (m(r)/r^n)/omega -> L/omega = t by step 4. By continuity of ofReal, ofReal((m(r)/r^n)/omega) -> ofReal(t).
 - The two functions of r agree on (0, R), which belongs to the filter of right neighbourhoods of 0. Hence mu(B_r)/ofReal(omega r^n) -> ofReal(t) as r -> 0+.

7. Finally, omega t = L <= Phi(r) for every r in (0, R), by step 3.

## Key steps

1. mu(B_r) is finite and F > 0 on (0, R); F -> 1 as r -> 0+ because alpha > 0.
2. Phi is nondecreasing and bounded below by exp(-Lambda) - 1, so L = inf Phi = lim_{r -> 0+} Phi.
3. m(r)/r^n = (Phi + 1)/F - 1 -> L, and L >= 0.
4. omega_n > 0. With t := L/omega_n, mu(B_r)/ofReal(omega_n r^n) = ofReal(m(r)/(omega_n r^n)) -> ofReal(t).
5. omega_n t = L <= Phi(r).
