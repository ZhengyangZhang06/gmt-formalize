## Proof

Source: Steps 2(b) and 5 of the parent proof ('F is C^1 on the open set O, hence Lipschitz on a compact neighbourhood of each compact set, which gives an alpha-Hoelder bound (short distances by the Lipschitz bound, long distances by 2 sup|F|/delta^alpha)'), stated for D^m h.
1. Setup. Put g := iteratedFDeriv R m h. Since V is open, iteratedFDeriv R j h = iteratedFDerivWithin R j h V on V for j <= m+1 (iteratedFDerivWithin_of_isOpen). As h is C^{m+1} on V, g is differentiable on V and, by the linear isometry of iteratedFDeriv_succ_eq_comp_left, ||Dg(x)|| = ||iteratedFDeriv R (m+1) h x||; the latter is continuous on V (ContDiffOn.continuousOn_iteratedFDerivWithin). So g and x -> ||Dg(x)|| are continuous on V.
2. If K is empty take C = 0. Otherwise, for each z in K choose r_z > 0 with B(z, 2 r_z) contained in V and ||Dg|| <= L_z := ||Dg(z)|| + 1 on B(z, 2 r_z) (continuity at z). By the mean value inequality on the convex ball (Convex.norm_image_sub_le_of_norm_hasFDerivWithin_le), ||g(x) - g(y)|| <= L_z ||x - y|| for x, y in B(z, 2 r_z).
3. Compactness: choose z_1..z_N in K with K contained in the union of the B(z_i, r_{z_i}); put L* := max_i L_{z_i}, r* := min_i r_{z_i} > 0 and S := sup_{x in K} ||g(x)|| < infinity (g continuous on the compact K).
4. Lipschitz bound on K. Let x, y in K. If ||x - y|| < r*, then x is in some B(z_i, r_{z_i}) and y in B(z_i, r_{z_i} + r*), contained in B(z_i, 2 r_{z_i}), so ||g(x) - g(y)|| <= L* ||x - y||. If ||x - y|| >= r*, then ||g(x) - g(y)|| <= 2S <= (2S/r*) ||x - y||. Hence ||g(x) - g(y)|| <= L' ||x - y|| on K with L' := max(L*, 2S/r*).
5. Hoelder bound. Let D := max(1, sup_{x,y in K} ||x - y||) < infinity. For x, y in K, since 0 < alpha <= 1, ||x - y|| = ||x - y||^{1-alpha} ||x - y||^alpha <= D^{1-alpha} ||x - y||^alpha (both sides are 0 if x = y, as 0^alpha = 0). Therefore ||g(x) - g(y)|| <= C ||x - y||^alpha with C := L' D^{1-alpha}. QED

## Key steps

1. D(iteratedFDeriv m h) is continuous on V (isometry with iteratedFDeriv (m+1) h)
2. local Lipschitz bounds on balls by the mean value inequality
3. finite subcover; short distances by local Lipschitz, long distances by 2 sup ||g||
4. Lipschitz on bounded K implies alpha-Hoelder with constant L' max(1, diam K)^{1-alpha}
