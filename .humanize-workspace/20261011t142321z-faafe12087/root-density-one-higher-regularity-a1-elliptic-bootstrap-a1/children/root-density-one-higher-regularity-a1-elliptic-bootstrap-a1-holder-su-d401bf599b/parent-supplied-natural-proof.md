## Proof

Source: the bookkeeping 'u in C^{m+1,alpha}_loc means Du in C^{m,alpha}_loc', 'v = D_k u ... for every direction k, i.e. u in C^{m+2,alpha}_loc' used in Steps 4-5 of the parent proof.
1. C^k part. On the open set U, ContDiffOn R (m+1) f U is equivalent to (DifferentiableOn R f U and ContDiffOn R m (fderiv R f) U) (contDiffOn_succ_iff_fderiv_of_isOpen; the analyticity clause is vacuous for finite m). Since 1 <= m+1, ContDiffOn (m+1) implies C^1; and C^1 implies DifferentiableOn. Since R^n is finite-dimensional, ContDiffOn R m (fderiv R f) U holds iff for every v the map x -> Df(x) v is C^m on U (contDiffOn_clm_apply); by linearity in v it suffices to take v in {e_1,...,e_n}, because Df(x) = sum_k iota_k(D_k f(x)) where iota_k : E ->L L(R^n, E), iota_k(w) := (h -> <e_k, h> w), is a fixed continuous linear map, so Df is C^m whenever all D_k f are.
2. Isometry between D^{m+1} f and D^m(Df). For every x, iteratedFDeriv R (m+1) f x = Psi(iteratedFDeriv R m (fderiv R f) x) where Psi is a linear isometric equivalence (Mathlib iteratedFDeriv_succ_eq_comp_right, valid for all x). Hence ||D^{m+1}f(x) - D^{m+1}f(y)|| = ||D^m(Df)(x) - D^m(Df)(y)|| for all x, y, so the Hoelder clauses of (A) and (B) are literally equivalent (same constants). With step 1 this proves (A <-> B).
3. Components. Let ev_k : L(R^n, E) ->L E, T -> T e_k (norm <= 1). On the open set U, wherever Df is C^m: D^m(D_k f)(x) = ev_k o D^m(Df)(x) (iteratedFDeriv of a continuous linear map composed with a C^m map, ContinuousLinearMap.iteratedFDerivWithin_comp_left with iteratedFDerivWithin_of_isOpen), so ||D^m(D_k f)(x) - D^m(D_k f)(y)|| <= ||D^m(Df)(x) - D^m(Df)(y)||. Conversely, wherever all D_k f are C^m: D^m(Df)(x) = sum_k iota_k o D^m(D_k f)(x) (iteratedFDeriv of a finite sum and of continuous linear images; ||iota_k|| <= 1), so ||D^m(Df)(x) - D^m(Df)(y)|| <= sum_k ||D^m(D_k f)(x) - D^m(D_k f)(y)||.
4. (B -> C): by step 1 each D_k f is C^m on U; for a compact K the constant of (B) works for every D_k f by step 3. (C -> B): Df is C^m on U by step 1, and for a compact K the sum over k of the constants of the D_k f works by step 3. Hence (B <-> C), and with step 2, (A <-> C). (For n = 0 all sums are empty and Df = 0; the argument is unchanged.) QED
