## Proof

Source: step B2 of the parent proof of Simon 8.5.9 (canonical representation of a varifold with tangent planes a.e., the tangent-point facts from Def. 8.1.1, and Ch. 1 Theorem 3.3); it is used for the limit varifold V and for the blow-ups W_k. Notation: G := Grassmannian N n (compact); μ_V := V.weight; B_ρ(x) := closedBall x ρ; H^n := μHE[n]; ω_n := unitBallVolume n ∈ (0,∞) (ω_0 = 1); V_{x,t} := rescaledMeasure V x t, so ∫ f dV_{x,t} = t^{-n}∫ f(t^{-1}(z − x), S) dV(z,S); v(T) := planeVarifoldMeasure T; M := {x ∈ spt μ_V : ∃ T θ', HasTangentPlane V x T θ'}.

1. Tangent planes a.e. By the hypothesis AllardRectifiabilityTheorem (its second conclusion) applied to V, which has locally bounded first variation and Θ^n(μ_V, x) > 0 for μ_V-a.e. x: for μ_V-a.e. x there are T ∈ G and θ' ∈ ℝ with HasTangentPlane V x T θ'.

2. Canonical representation. By the hypothesis FirstRectifiabilityTheorem applied to V and step 1, there is θ : ℝ^N → ℝ such that every x ∈ M has some T ∈ G with HasTangentPlane V x T (θ(x)), and IsVarifoldOf V M θ. This is (i) and the first half of (ii). In particular M ⊆ U and θ > 0 on M.

3. Tangent-point density fact. Claim: if HasTangentPlane V x T θ_1 (so x ∈ U, θ_1 > 0, and ∫ f dV_{x,t} → θ_1 ∫ f dv(T) as t ↓ 0 for every f ∈ C_c(ℝ^N × G)), then HasDensity n μ_V x (ofReal θ_1). Proof: for g ∈ C_c(ℝ^N) the function f(z,S) := g(z) lies in C_c(ℝ^N × G) because G is compact; ∫ f dV_{x,t} = t^{-n}∫ g(t^{-1}(z − x)) dμ_V(z) (definitions of rescaledMeasure and of μ_V = π_#V), and ∫ f dv(T) = ∫_{T.plane} g dH^n. For κ ∈ (0,1) choose continuous g_1, g_2 : ℝ^N → [0,1] with 1_{B_κ(0)} ≤ g_1 ≤ 1_{B_1(0)} ≤ g_2 ≤ 1_{B_{1/κ}(0)}. For t so small that B_{t/κ}(x) is a compact subset of U (x ∈ U, U open), the functions z ↦ g_i(t^{-1}(z−x)) are bounded with support in B_{t/κ}(x), hence μ_V-integrable (μ_V is finite on compact subsets of U), so the Bochner integrals equal the corresponding lintegrals and t^{-n}∫ g_1(t^{-1}(z−x)) dμ_V ≤ t^{-n}μ_V(B_t(x)) ≤ t^{-n}∫ g_2(t^{-1}(z−x)) dμ_V, and H^n(T.plane ∩ B_s(0)) = ω_n s^n for s > 0 (T.plane is an n-dimensional subspace, isometric to ℝ^n, on which μHE[n] is Lebesgue measure: Isometry.euclideanHausdorffMeasure_image, EuclideanSpace.euclideanHausdorffMeasure_eq_volume; for n = 0, T.plane = {0}, H^0 is counting measure and ω_0 = 1). Letting t ↓ 0: θ_1 ω_n κ^n ≤ liminf_{t↓0} t^{-n}μ_V(B_t(x)) ≤ limsup_{t↓0} t^{-n}μ_V(B_t(x)) ≤ θ_1 ω_n κ^{-n}. Letting κ ↑ 1 and dividing by ω_n ∈ (0,∞): densityRatio n μ_V x t → θ_1, i.e. HasDensity n μ_V x (ofReal θ_1). Applied with θ_1 := θ(x) for x ∈ M (step 2), this is the second half of (ii).

4. μ_V-null subsets of M are H^n-null. Let Z ⊆ M with μ_V(Z) = 0. If U = ∅ then Z = ∅. Otherwise let K_p (p ∈ ℕ) be compact with K_p ⊆ interior K_{p+1} and ⋃_p K_p = U (U is open), and O_p := interior K_{p+1}, an open set with μ_V(O_p) ≤ μ_V(K_{p+1}) < ∞. Fix p and k ≥ 1 and put Z_{p,k} := {x ∈ Z ∩ K_p : θ(x) ≥ 1/k}; Z_{p,k} ⊆ O_p. Let η > 0. The finite Borel measure μ_V⌞O_p on the metric space ℝ^N is outer regular and (μ_V⌞O_p)(Z_{p,k}) ≤ μ_V(Z) = 0, so there is an open O'' ⊇ Z_{p,k} with μ_V(O'' ∩ O_p) < η; then O := O'' ∩ O_p is open, Z_{p,k} ⊆ O, μ_V(O) < η. For x ∈ Z_{p,k} and 0 < ρ < dist(x, ℝ^N ∖ O) we have (μ_V⌞O)(B_ρ(x)) = μ_V(B_ρ(x)), so by step 3 the upper n-density of the finite measure μ_V⌞O at x equals θ(x) ≥ 1/k. By Simon Ch. 1 Theorem 3.3 (SimonGMT Chapter01.simon_theorem_3_3 / mul_simonHausdorff_le_of_le_dimensionalUpperDensity, applied to the Borel regular outer measure of μ_V⌞O with A_1 := Z_{p,k} and A_2 := ℝ^N; Simon's Hausdorff measure and density normalisation agree with H^n = μHE[n] and ω_n up to fixed positive finite factors, so it yields C·(1/k)·H^n(Z_{p,k}) ≤ (μ_V⌞O)(ℝ^N) for a constant C = C(n) ∈ (0,∞); in fact C = 1, since simonHausdorffMeasureReal n = μHE[n] by SimonGMT Chapter02.simonHausdorffMeasureReal_nat_eq_euclideanHausdorffMeasure and the outer measure of μ_V⌞O is Borel regular by Chapter01.measure_toOuterMeasure_isBorelRegular), we get C(1/k)H^n(Z_{p,k}) ≤ μ_V(O) < η. Since η > 0 is arbitrary, H^n(Z_{p,k}) = 0. As θ > 0 on Z ⊆ M ⊆ U = ⋃_p K_p, Z = ⋃_{p,k} Z_{p,k}, hence H^n(Z) = 0. This is (iii). ∎

## Key steps

1. AllardRectifiabilityTheorem gives tangent planes μ_V-a.e.
2. FirstRectifiabilityTheorem gives θ with IsVarifoldOf V M θ and a tangent plane of multiplicity θ(x) at every x ∈ M.
3. Tangent-point fact (Def. 8.1.1 tested with radial cut-offs, H^n(T ∩ B_s) = ω_n s^n): HasTangentPlane V x T θ₁ ⇒ Θ^n(μ_V,x) = θ₁.
4. Null transfer: for Z ⊆ M μ_V-null, outer regularity gives small open O ⊇ Z_{p,k}, and Ch. 1 Theorem 3.3 gives (1/k)H^n(Z_{p,k}) ≲ μ_V(O); hence H^n(Z) = 0.
