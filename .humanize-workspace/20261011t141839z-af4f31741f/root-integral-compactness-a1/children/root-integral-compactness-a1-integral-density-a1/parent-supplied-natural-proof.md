## Proof

Source: Simon Ch. 8, Remark 5.9 ("the hypothesis Θ^n(μ_{V_j},x) ≥ 1 on U ∖ A_j is automatically satisfied with μ_{V_j}(A_j) = 0"), proved with Ch. 3 Remark 1.8(2) and the upper density theorem Ch. 1, 3.6. This is step B0 of the parent proof of 5.9, for one integral varifold. Notation: G := Grassmannian N n; μ_V := V.weight; B_ρ(x) := closedBall x ρ; H^n := μHE[n]; ω_n := unitBallVolume n ∈ (0,∞) (ω_0 = 1); Θ^n(μ,x) = c means HasDensity n μ x c, i.e. μ(B_ρ(x))/(ω_n ρ^n) → c as ρ ↓ 0.

1. Data. By IsIntegral V choose M, θ with IsVarifoldOf V M θ and θ(x) ∈ ℕ for (H^n⌞M)-a.e. x. Thus M ⊆ U is H^n-null-measurable, θ > 0 on M, θ is H^n-integrable on M ∩ K for every compact K ⊆ U, and for every Borel A ⊆ ℝ^N × G: V(A) = ∫⁻ over {x ∈ M : ∃ S ∈ G, HasWeightedApproximateTangentSpaceAt n M θ x S.plane ∧ (x,S) ∈ A} of ofReal θ dH^n. U is open (Varifold.isOpen_domain). If U = ∅ then μ_V(ℝ^N) = V(U^c × G) = 0 and there is nothing to prove; otherwise fix compact K_p ⊆ U (p ∈ ℕ) with K_p ⊆ interior K_{p+1} and ⋃_p K_p = U. Put M* := {x ∈ M : ∃ S ∈ G, HasWeightedApproximateTangentSpaceAt n M θ x S.plane} and ν := (H^n⌞M).withDensity(ofReal θ), so ν(B) = ∫⁻_{M∩B} θ dH^n for Borel B and ν(K_p) < ∞.

2. H^n⌞M is σ-finite. For each p choose a Borel θ_p equal to θ H^n-a.e. on M ∩ K_p (θ is a.e.-strongly measurable there) and a Borel H^n-null Z_p ⊇ {x ∈ M ∩ K_p : θ(x) ≠ θ_p(x)}. The Borel sets U^c, Z_p, K_p ∩ {θ_p ≤ 0} and S_{p,k} := K_p ∩ {θ_p ≥ 1/k} (p ∈ ℕ, k ≥ 1) cover ℝ^N, and (H^n⌞M)(U^c) = 0 (M ⊆ U), (H^n⌞M)(Z_p) = 0, (H^n⌞M)(K_p ∩ {θ_p ≤ 0}) ≤ H^n(Z_p) = 0 (θ_p = θ > 0 on (M ∩ K_p) ∖ Z_p), (H^n⌞M)(S_{p,k}) ≤ k ∫_{M∩K_p} θ dH^n < ∞. Hence H^n⌞M is σ-finite, in particular s-finite.

3. Measurable hull of M*. Let M' := M ∩ toMeasurable_{H^n⌞M}(M*). Then M* ⊆ M' ⊆ M, M' is H^n-null-measurable, and (Measure.restrict_toMeasurable_of_sFinite, Measure.measure_toMeasurable_inter_of_sFinite, for the s-finite measure H^n⌞M) (H^n⌞M)⌞M' = (H^n⌞M)⌞M*; in particular H^n(B ∩ M') = H^n(B ∩ M*) (outer measure on the right) for every Borel B. Taking A = B × G (B Borel) in the defining identity: μ_V(B) = V(B × G) = ∫⁻_{M*∩B} θ dH^n = ∫⁻_B θ d((H^n⌞M)⌞M*) = ∫⁻_B θ d((H^n⌞M)⌞M') = ν(B ∩ M') (H^n⌞(M*∩B) = ((H^n⌞M)⌞M*)⌞B by Measure.restrict_restrict_of_subset, which needs no measurability, and Measure.restrict_restrict for the Borel set B). Choose a Borel M'_B ⊆ M' with H^n(M' ∖ M'_B) = 0; then μ_V(ℝ^N ∖ M'_B) = ν((ℝ^N ∖ M'_B) ∩ M') = 0 (ν ≪ H^n), so μ_V is carried by the Borel set M'_B; and μ_V(Y) = 0 for every H^n-null Y (μ_V ≤ ν ≪ H^n, applied to a Borel H^n-null superset of Y).

4. Density of ν at approximate tangent points (Ch. 3 Remark 1.8(2)). Let x ∈ M* with HasWeightedApproximateTangentSpaceAt n M θ x P (P = S.plane, dim P = n): for every f ∈ C_c(ℝ^N), ∫_{η_{x,r}(M)} f(y) θ(x + r y) dH^n(y) → θ(x) ∫_P f dH^n as r ↓ 0, where η_{x,r}(z) = r^{-1}(z − x) (blowUpMap). Since H^n(x + rA) = r^n H^n(A) for all A (translation invariance and Mathlib MeasureTheory.Measure.euclideanHausdorffMeasure_smul₀ / euclideanHausdorffMeasure_homothety_image), the left side equals r^{-n} ∫_M f(r^{-1}(z − x)) θ(z) dH^n(z): for an arbitrary set M one has H^n⌞η_{x,r}(M) = r^{-n}·(η_{x,r})_#(H^n⌞M) as measures (on Borel B both sides equal H^n(B ∩ η_{x,r}(M)) = r^{-n}H^n(η_{x,r}^{-1}(B) ∩ M)), and one applies MeasureTheory.lintegral_map_equiv / integral_map_equiv for the measurable equivalence η_{x,r}. For κ ∈ (0,1) choose continuous f_1, f_2 : ℝ^N → [0,1] with 1_{B_κ(0)} ≤ f_1 ≤ 1_{B_1(0)} ≤ f_2 ≤ 1_{B_{1/κ}(0)}. Let p be such that x ∈ K_p; for r so small that B_{r/κ}(x) ⊆ K_{p+1}, the functions z ↦ f_i(r^{-1}(z−x))θ(z) are H^n-integrable on M (bounded by θ·1_{M∩K_{p+1}}, θ ≥ 0 a.e.-strongly measurable and integrable there), so the Bochner integrals in Definition 1.7 coincide with the corresponding lintegrals and r^{-n}∫_M f_1(r^{-1}(z−x))θ dH^n ≤ r^{-n}ν(B_r(x)) ≤ r^{-n}∫_M f_2(r^{-1}(z−x))θ dH^n, and H^n(P ∩ B_s(0)) = ω_n s^n (P is isometric to ℝ^n, on which μHE[n] is Lebesgue measure: Isometry.euclideanHausdorffMeasure_image, EuclideanSpace.euclideanHausdorffMeasure_eq_volume; for n = 0, P = {0}, H^0 is counting measure and ω_0 = 1). Hence θ(x) ω_n κ^n ≤ liminf_{r↓0} r^{-n}ν(B_r(x)) ≤ limsup_{r↓0} r^{-n}ν(B_r(x)) ≤ θ(x) ω_n κ^{-n}; letting κ ↑ 1, ν(B_r(x))/(ω_n r^n) → θ(x).

5. M ∖ M' has zero density at H^n-a.e. point of M' (Ch. 1, 3.6). Fix p. ν_p := ν⌞K_{p+1} is a finite Borel measure and A_p := (M ∖ M') ∩ K_{p+1} is ν_p-null-measurable (M, M' are H^n-null-measurable and ν ≪ H^n), hence Carathéodory measurable for the outer measure of ν_p (split any test set with Mathlib measure_inter_add_sdiff₀), and ν_p(A_p) < ∞. By the upper density theorem (SimonGMT Chapter01.simon_theorem_3_6 for the outer measure of ν_p, which is Borel regular by SimonGMT Chapter01.measure_toOuterMeasure_isBorelRegular; its Hausdorff measure is Simon's simonHausdorffOuterMeasureReal n, equal to μHE[n] by SimonGMT Chapter02.simonHausdorffMeasureReal_nat_eq_euclideanHausdorffMeasure, and its density quotient uses realUnitBallVolume n and rpow, which agree with ω_n and ρ^n for ρ > 0 up to at most a fixed positive finite factor, irrelevant for zero densities), for H^n-a.e. x ∉ A_p: limsup_{ρ↓0} ν_p(A_p ∩ B_ρ(x))/(ω_nρ^n) = 0. For x ∈ M' ∩ K_p (so x ∉ A_p) and small ρ, B_ρ(x) ⊆ K_{p+1}, hence ν((M∖M') ∩ B_ρ(x)) = ν_p(A_p ∩ B_ρ(x)). Taking the union over p of the exceptional sets: for H^n-a.e. x ∈ M', limsup_{ρ↓0} ν((M ∖ M') ∩ B_ρ(x))/(ω_nρ^n) = 0.

6. Integer values. Since θ > 0 on M and θ ∈ ℕ (H^n⌞M)-a.e. (M null-measurable), θ(x) ∈ {1,2,3,…} for H^n-a.e. x ∈ M. Let N_0 be the H^n-null set of points x ∈ M* at which the conclusion of step 5 or this property fails.

7. Pointwise density. Let x ∈ M* ∖ N_0 and p with x ∈ K_p. For small ρ > 0, B_ρ(x) ⊆ K_{p+1}, all quantities below are finite, and, because ν is carried by M ⊇ M' and M' is ν-null-measurable, μ_V(B_ρ(x)) = ν(B_ρ(x) ∩ M') = ν(B_ρ(x)) − ν((M ∖ M') ∩ B_ρ(x)). Dividing by ω_nρ^n and using steps 4 and 5, μ_V(B_ρ(x))/(ω_nρ^n) → θ(x) = m with m ∈ ℕ, m ≥ 1; i.e. HasDensity n μ_V x (ofReal θ(x)) and θ(x) ∈ {1,2,…}.

8. Measurability of the exceptional set. Let F := {x ∈ U : ¬(HasDensity n μ_V x (ofReal θ(x)) ∧ ∃ m ∈ ℕ, 1 ≤ m ∧ θ(x) = m)} and F_p := F ∩ K_p. For x ∈ K_p and small ρ the density ratios of μ_V and of the finite measure μ_p := μ_V⌞interior(K_{p+1}) coincide, and in [0,∞] the ratio tends to c iff its limsup and liminf as ρ ↓ 0 both equal c. The upper and lower densities of the finite Borel measure μ_p are Borel functions of x (SimonGMT Chapter01.measurable_dimensionalUpperDensity / measurable_dimensionalLowerDensity; their normalising constant differs from ω_n by a fixed positive finite factor), and θ = θ_p H^n-a.e. on M ∩ K_p with θ_p Borel (step 2). Choose also a Borel M_B ⊆ M with H^n(M ∖ M_B) = 0 (NullMeasurableSet.exists_measurable_subset_ae_eq). Then F_p ∩ M_B ∩ {θ = θ_p} is the intersection of M_B ∩ K_p with a set defined by Borel conditions on x, up to the H^n-null set Z_p; therefore F_p ∩ M = B_p ∪ Y_p with B_p ⊆ F_p ∩ M Borel and H^n(Y_p) = 0 (Y_p ⊆ (M ∖ M_B) ∪ Z_p).

9. Conclusion. By step 7, F ∩ M* ⊆ N_0. For each p: μ_V(F_p) ≤ μ_V(F_p ∩ M'_B) (μ_V is carried by M'_B, step 3) ≤ μ_V(B_p ∩ M'_B) + μ_V(Y_p) (because F_p ∩ M'_B ⊆ F_p ∩ M = B_p ∪ Y_p), and μ_V(Y_p) = 0 by step 3. As B_p ∩ M'_B is Borel, μ_V(B_p ∩ M'_B) = ∫⁻_{B_p ∩ M'_B} θ d((H^n⌞M)⌞M*) ≤ ∫⁻_{B_p} θ d((H^n⌞M)⌞M*), and ((H^n⌞M)⌞M*)(B_p) = H^n(B_p ∩ M*) ≤ H^n(F ∩ M*) ≤ H^n(N_0) = 0, so this integral is 0. Hence μ_V(F_p) = 0 for every p and μ_V(F) = 0 (F ⊆ U = ⋃_p K_p); moreover μ_V(U^c) = V(U^c × G) = 0 (Varifold.supported, Varifold.weight_apply). So μ_V-a.e. x lies in U ∖ F, i.e. HasDensity n μ_V x (ofReal θ(x)) with θ(x) = m ∈ ℕ, m ≥ 1, and ofReal θ(x) = (m : ℝ≥0∞). Taking k := m gives ∃ k : ℕ, 1 ≤ k ∧ HasDensity n μ_V x k for μ_V-a.e. x. ∎

## Key steps

1. Fix the integral representation V = v(M,θ) and a compact exhaustion K_p of U; ν := θH^n⌞M; H^n⌞M is σ-finite.
2. Measurable hull M' of the approximate-tangent set M*: μ_V = ν⌞M' on Borel sets, μ_V is carried by a Borel subset of M' and μ_V ≪ H^n.
3. At x ∈ M*: ν(B_r(x))/(ω_n r^n) → θ(x) (Ch. 3 Remark 1.8(2), homothety scaling of H^n).
4. Upper density theorem 3.6: ν⌞(M∖M') has zero density at H^n-a.e. point of M'; θ ∈ ℕ_{≥1} H^n-a.e. on M.
5. Hence Θ^n(μ_V,x) = θ(x) ∈ ℕ_{≥1} at every x ∈ M* off an H^n-null set N_0.
6. The exceptional set F is null-measurable (Borel densities, Borel version of θ); by the hull identity μ_V(F) ≤ ∫_{F∩M*}θ = 0 and μ_V(U^c) = 0.
