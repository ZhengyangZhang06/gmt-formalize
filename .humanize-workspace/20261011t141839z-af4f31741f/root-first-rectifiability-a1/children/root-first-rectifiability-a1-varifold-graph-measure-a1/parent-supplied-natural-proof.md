## Proof

Source: Simon, Ch. 8, printed proof of Theorem 1.2 (p. 208), second paragraph: "if x ∈ M is one of the μ_V-almost all points such that η_V^(x) exists, and if β is a non-negative continuous function on G(n + ℓ, n), then we evidently have η_V^(x)(β) = θ(x)β(T_x) and hence by the second part of 1.3 we have (1) ∫_{Gₙ(A)} β(S) dV(x, S) = ∫_{M∩A} β(T_x) dμ_V(x) for any Borel set A ⊆ U. From the arbitrariness of A and β it then easily follows that (2) ∫ f(x, S) dV(x, S) = ∫_M f(x, T_x) dμ_V(x) for any non-negative f ∈ C_c(Gₙ(U))." ERRATUM (documented in the parent proof): the printed "η_V^(x)(β) = θ(x)β(T_x)" must read "η_V^(x)(β) = β(T_x)"; the averages in Lemma 1.3 are normalised by μ_V(B_ρ(x)), so the multiplicity cancels, and the printed (1) is consistent only with the corrected value. The details below are Step 8 of the parent proof. Notation: μ := V.weight; G := Grassmannian N n (a compact metrizable space; we use the Frobenius distance d(S, S') := (Σ_{a,b} (S_{ab} − S'_{ab})²)^{1/2} of the matrices, which induces its topology); B_ρ(y) := closedBall y ρ; Gₙ(A) := A ×ˢ univ; ω := unitBallVolume n ∈ (0, ∞); H^n := μHE[n]; for continuous β on G and ρ > 0, avg_ρ^x(β) := (∫_{Gₙ(B_ρ(x))} β(S) dV) / μ(B_ρ(x)).toReal (the quotient in the hypothesis).

0. Degenerate case. If G = ∅ (n > N), then {x : ∃ T θ, HasTangentPlane V x T θ} = ∅ and the a.e. hypothesis gives μ(ℝ^N) = 0; moreover ℝ^N × G is empty, so V.measure = 0. Then every set is μ-null-measurable and V(A) = 0 = μ(S_A). Assume G ≠ ∅ and fix S₀ ∈ G.

1. Tangent data. By frt_tangent_plane_unique, at a tangent point x the plane and multiplicity are unique; write T(x), θ(x) (θ(x) > 0). Let X be the set of tangent points x at which the first clause of the hypothesis on η holds (η(x) is a probability measure and avg_ρ^x(β) → ∫ β dη(x) for all β ∈ C(G)). Both clauses hold μ-a.e., so μ(ℝ^N ∖ X) = 0.

2. Averages at a tangent point. Let x be a tangent point with plane T and multiplicity θ > 0. Claim: avg_ρ^x(β) → β(T) as ρ ↓ 0, for every β ∈ C(G).
 (a) Denominator: by frt_tangent_plane_hasDensity, μ(B_ρ(x))/(ω ρ^n) → θ, so ρ^{−n} μ(B_ρ(x)).toReal → θ ω.toReal > 0 (and μ(B_ρ(x)) ∈ (0, ∞) for small ρ; x ∈ U and U is open, so closedBall x (2ρ) ⊆ U is compact and V(B_{2ρ}(x) × G) = μ(B_{2ρ}(x)) < ∞ for small ρ).
 (b) Numerator for β ≥ 0: for χ ∈ C_c(ℝ^N) with 0 ≤ χ ≤ 1, the function f_χ(y, S) := χ(y) β(S) lies in C_c(ℝ^N × G) (G compact). For ρ > 0, rescaledMeasure V x ρ = ENNReal.ofReal(ρ⁻¹ ^ n) • V.measure.map φ_ρ with φ_ρ(y, S) := (ρ⁻¹ • (y − x), S) continuous, so by integral_smul_measure ((ENNReal.ofReal(ρ⁻¹ ^ n)).toReal = ρ⁻¹ ^ n) and integral_map (f_χ continuous), ∫ f_χ d(rescaledMeasure V x ρ) = ρ⁻¹ ^ n ∫ χ(ρ⁻¹ • (y − x)) β(S) dV(y, S); and planeVarifoldMeasure T = (H^n.restrict T.plane).map (y ↦ (y, T)), so by integral_map, ∫ f_χ d(planeVarifoldMeasure T) = ∫_{T.plane} χ(y) β(T) dH^n(y) = β(T) ∫_{T.plane} χ dH^n. By HasTangentPlane, ρ^{−n} ∫ χ(ρ⁻¹ • (y − x)) β(S) dV → θ β(T) ∫_{T.plane} χ dH^n. Use the cutoffs χ_{a,b}(y) := max(0, min(1, (b − |y|)/(b − a))) for 0 < a < b (continuous, 0 ≤ χ_{a,b} ≤ 1, χ_{a,b} = 1 on B_a(0), χ_{a,b} = 0 outside ball 0 b, so χ_{a,b} ∈ C_c(ℝ^N)). For κ ∈ (0, 1): χ_{1−κ,1}(ρ⁻¹ • (y − x)) ≤ 1_{B_ρ(x)}(y) ≤ χ_{1,1+κ}(ρ⁻¹ • (y − x)) for all y, so (β ≥ 0; all integrals are finite for small ρ, the integrands being bounded and supported in B_{2ρ}(x) × G)
 ρ^{−n} ∫ χ_{1−κ,1}(ρ⁻¹(y − x)) β(S) dV ≤ ρ^{−n} ∫_{Gₙ(B_ρ(x))} β dV ≤ ρ^{−n} ∫ χ_{1,1+κ}(ρ⁻¹(y − x)) β(S) dV.
 The outer terms tend to θβ(T)∫_{T.plane} χ_{1−κ,1} dH^n ≥ θ β(T) ω.toReal (1 − κ)^n and to θβ(T)∫_{T.plane} χ_{1,1+κ} dH^n ≤ θ β(T) ω.toReal (1 + κ)^n respectively, using 1_{B_{1−κ}(0)} ≤ χ_{1−κ,1}, χ_{1,1+κ} ≤ 1_{B_{1+κ}(0)}, β(T) ≥ 0 and H^n(T.plane ∩ B_s(0)) = ω s^n for s > 0 (via a linear isometry ℝ^n → T.plane: Isometry.euclideanHausdorffMeasure_image, EuclideanSpace.euclideanHausdorffMeasure_eq_volume, Measure.addHaar_closedBall; for n = 0 both sides equal 1). Hence θβ(T)ω.toReal(1 − κ)^n ≤ liminf_{ρ↓0} ρ^{−n} ∫_{Gₙ(B_ρ(x))} β dV ≤ limsup_{ρ↓0} ρ^{−n} ∫_{Gₙ(B_ρ(x))} β dV ≤ θβ(T)ω.toReal(1 + κ)^n for every κ ∈ (0, 1); letting κ → 0 gives ρ^{−n} ∫_{Gₙ(B_ρ(x))} β dV → θ ω.toReal β(T).
 (c) General β ∈ C(G): β = β⁺ − β⁻ with β^± := max(±β, 0) ∈ C(G), β^± ≥ 0; by linearity of the (finite) integrals, ρ^{−n} ∫_{Gₙ(B_ρ(x))} β dV → θ ω.toReal β(T).
 (d) Dividing (c) by (a): avg_ρ^x(β) → θ ω.toReal β(T)/(θ ω.toReal) = β(T). (This is the corrected printed claim η_V^(x)(β) = β(T_x).)

3. η is Dirac. For x ∈ X, by the hypothesis and 2, ∫ β dη(x) = β(T(x)) for every β ∈ C(G) (uniqueness of limits along 𝓝[>] 0). η(x) and the Dirac measure δ_{T(x)} are finite Borel measures on the compact metrizable space G with equal integrals of all continuous functions, hence equal (both are regular, and Measure.ext_of_integral_eq_on_compactlySupported applies since C_c(G) = C(G)). In particular ∫⁻ ENNReal.ofReal β dη(x) = ENNReal.ofReal (β(T(x))) for β ≥ 0.

4. A Borel version of T. For matrix indices a, b let e_{ab}(S) := S.1 a b, a continuous function on G. For k ≥ 1 the function a_k^{ab}(x) := (∫_{Gₙ(B_{1/k}(x))} e_{ab}(S) dV) / μ(B_{1/k}(x)).toReal is Borel in x: x ↦ μ(B_{1/k}(x)) is Borel (Mathlib measurable_measure_prodMk_left for the s-finite μ and the closed set {(x, y) : dist y x ≤ 1/k}, whose section at x is B_{1/k}(x)), and x ↦ ∫ 1_{|y − x| ≤ 1/k} e_{ab}(S) dV(y, S) is Borel by measurability of parametric integrals of jointly Borel functions for the σ-finite measure V.measure (Varifold.measure.instSigmaFinite; e.g. MeasureTheory.StronglyMeasurable.integral_prod_right' applied to (x, (y, S)) ↦ 1_{dist y x ≤ 1/k} e_{ab}(S), the set {dist y x ≤ 1/k} being closed). For x ∈ X, a_k^{ab}(x) → ∫ e_{ab} dη(x) = T(x).1 a b as k → ∞ (hypothesis along ρ = 1/k → 0⁺, and 3). Let Y be the Borel set of x at which every sequence (a_k^{ab}(x))_k converges and the matrix of limits is symmetric, idempotent and has trace n (i.e. lies in G, a closed set of matrices); put T̃(x) := that matrix for x ∈ Y and T̃(x) := S₀ otherwise. Then T̃ : ℝ^N → G is Borel, X ⊆ Y and T̃ = T on X; so T̃(x) = T(x) for μ-a.e. x.

5. Identity (1). For Borel A' ⊆ ℝ^N and β ∈ C(G) with β ≥ 0, by the second hypothesis on η, 3 and 4,
 ∫⁻_{Gₙ(A')} ENNReal.ofReal β(S) dV = ∫⁻_{A'} ∫⁻ ENNReal.ofReal β dη(x) dμ(x) = ∫⁻_{A'} ENNReal.ofReal β(T̃(x)) dμ(x),
 the integrands agreeing on the full-measure set X (lintegral_congr_ae).

6. Rectangles. Let ν := μ.map (x ↦ (x, T̃(x))) (a Borel map), so ν(A' × B) = μ(A' ∩ T̃⁻¹(B)) for Borel A', B. Let K_m (m ≥ 1) be a compact exhaustion of U: K_m := closedBall 0 m if U = ℝ^N, and otherwise K_m := {x : |x| ≤ m and infDist(x, ℝ^N ∖ U) ≥ 1/m}; each K_m is compact, K_m ⊆ K_{m+1} ⊆ U and ⋃_m K_m = U (for x ∈ U, infDist(x, ℝ^N ∖ U) > 0 as ℝ^N ∖ U is closed). G carries no MetricSpace instance, so fix explicitly the Frobenius distance d(S, S') := (Σ_{a,b} (S.1 a b − S'.1 a b)²)^{1/2}, a continuous function on G × G inducing the subspace topology of G (alternatively, any metric given by TopologicalSpace.metrizableSpaceMetric). Let A' ⊆ K_m be Borel and F ⊆ G closed. If F = ∅ then V(A' × F) = 0 = ν(A' × F). Otherwise d_F(S) := inf_{S' ∈ F} d(S, S') is continuous and, F being compact, d_F(S) = 0 ⟺ S ∈ F; put β_j(S) := max(0, 1 − j · d_F(S)). Then β_j ∈ C(G), 0 ≤ β_j ≤ 1 and β_j ↓ 1_F pointwise. By 5, ∫⁻_{Gₙ(A')} β_j(S) dV = ∫⁻_{A'} β_j(T̃(x)) dμ(x); both sides are bounded by V(K_m × G) = μ(K_m) < ∞, so letting j → ∞ (monotone convergence for decreasing sequences with finite integrals, or dominated convergence) gives V(A' × F) = μ(A' ∩ T̃⁻¹(F)) = ν(A' × F). For fixed A', B ↦ V(A' × B) and B ↦ ν(A' × B) are finite Borel measures on G that agree on the closed sets, a π-system generating the Borel σ-algebra of G and containing G itself; hence they agree on every Borel B ⊆ G (MeasureTheory.ext_of_generate_finite). For Borel A' ⊆ ℝ^N ∖ U: V(A' × B) ≤ V(Uᶜ × G) = 0 (V.supported) and ν(A' × B) ≤ μ(A') ≤ μ(Uᶜ) = V(Uᶜ × G) = 0 (Varifold.weight_apply).

7. V = ν (printed (2)). Let 𝓒 be the family of rectangles A' × B with B ⊆ G Borel and A' ⊆ ℝ^N Borel such that A' ⊆ K_m for some m or A' ⊆ ℝ^N ∖ U. 𝓒 is closed under finite intersections (a π-system). Every Borel rectangle A' × B is the countable union ((A' ∖ U) × B) ∪ ⋃_m ((A' ∩ K_m) × B) of members of 𝓒, and Borel rectangles generate the Borel σ-algebra of ℝ^N × G (both factors are second countable: Prod.borelSpace / generateFrom_prod), so 𝓒 generates it as well. By 6, V.measure and ν agree on 𝓒, and the sets K_m × G (finite V- and ν-measure, V(K_m × G) = μ(K_m) = ν(K_m × G)) together with (ℝ^N ∖ U) × G (measure 0) form a countable cover of ℝ^N × G by members of 𝓒 of finite measure. By Measure.ext_of_generateFrom_of_iUnion (Mathlib MeasureTheory/Measure/Restrict.lean:491), V.measure = ν.

8. Conclusion. Let A ⊆ ℝ^N × G be Borel and Ã := {x : (x, T̃(x)) ∈ A}, a Borel set. By 7 and Measure.map_apply, V(A) = ν(A) = μ(Ã). For x ∈ X we have x ∈ S_A ⟺ x ∈ Ã: if HasTangentPlane V x T θ and (x, T) ∈ A then T = T(x) = T̃(x) by frt_tangent_plane_unique and 4; conversely, if (x, T̃(x)) ∈ A then HasTangentPlane V x T(x) θ(x) with T(x) = T̃(x) and (x, T(x)) ∈ A. Hence S_A and Ã differ only inside the μ-null set ℝ^N ∖ X, i.e. S_A =ᵐ[μ] Ã; so S_A is μ-null-measurable and μ(S_A) = μ(Ã) = V(A). ∎

## Key steps

1. G = ∅ is trivial; otherwise X = {tangent points where Lemma 1.3(i) holds} has full μ_V-measure.
2. At a tangent point, cutoff squeezes give (∫_{Gₙ(B_ρ(x))} β dV)/μ_V(B_ρ(x)) → β(T_x) (corrected η_V^(x)(β) = β(T_x)).
3. Hence η(x) = δ_{T(x)} on X, and Lemma 1.3(ii) gives (1): ∫_{Gₙ(A')} β dV = ∫_{A'} β(T̃(x)) dμ_V with a Borel T̃ = T μ_V-a.e. built from averages of matrix entries.
4. V and ν := μ_V.map(x ↦ (x, T̃ x)) agree on rectangles A' × B (closed B by approximation, then all Borel B).
5. π-system of rectangles over the compact exhaustion and Uᶜ: V = ν (printed (2)).
6. V(A) = μ_V{x : (x,T̃x) ∈ A}, which equals μ_V(S_A) because S_A =ᵐ that Borel set (uniqueness of tangent planes).
